# 先找问题，再决定读论证还是选活动

这是一份阅读接口，不是书稿本身，也不是默认的娱乐推荐器。用户讨论价值时，回答论证和真实取舍；明确需要玩法时，才筛活动。保留对自愿且可承担的完整体验的偏向，不把所有愿望缩成微小舒适。

## 取得同一版本的原文

本地有 `SHUAQI.md`、`book/`、`essays/`、`docs/` 时在仓库根目录读取。单独复制本 Skill 不等于取得书稿或工具。没有本地仓库时，从用户指定版本获取 `solomon-8/EnjoyTheMoment` 的 `llms.txt`、`docs/ai.md` 和所需文件；严肃引用保留提交 SHA。没有网络或原文就说明限制，不靠记忆编造内容。

不需要安装第三方库。仓库内的 `python3 tools/read.py` 只读取本地文件；没有命令行工具时按 ID 和文件路径直接读取即可。

## 按用户问题读取

| 问题 | 入口 |
| --- | --- |
| “耍起”主张是否成立 | `SHUAQI.md`，E01 的 `pleasure-options`、`pleasure-enough`，再读相关长文 |
| 即时满足、等待、休息、朋友或真实生活 | E02、E03、E07、E09、E11；只选对应论证，不要求每次读全部 |
| 具体体验与生活领域 | 对应 C 章节全文，沿引用取 B/N/F 来源 |
| 证据支持到哪里 | 对应 B 台账与 N/F 阅读记录，保留版本、对象与未证明事项 |
| 明确需要活动 | J 卡片或 P 指南；遵守用户已有预算、时间与偏好 |
| 文化出处 | `docs/culture-shuaqi.md`；媒体说法与项目定义分开 |

按主题的详细边界在仓库 `docs/reading-map.md`，不要将它整份载入每次问答。核心协议见 `docs/ai.md`。

```bash
python3 tools/read.py --query 朋友 --kind essay --limit 5
python3 tools/read.py --id E09
python3 tools/read.py --id F57
```

搜索是词面 AND，返回位置而不是正文或结论；精确 ID 返回完整源文和相关主题说明。`linked_records` 只说明链接存在，不表示已读。需要的来源要继续读取，不依赖标题代答。C 返回完整章节文件，B 返回完整台账条目。

输出上限遮掉长文时，用 `--id E09 --page-chars 600`，再原样传回 `--cursor` 对应的 `next_cursor`。逐页拼接 `record.text`，不加分隔符，直到游标为空并核对 `text_sha256`；末页不代表已读全文。页长是 Unicode 码点而非 token，仍截断就减小后重读同一页。页模式的 `reading_guidance_ids`、`linked_record_ids` 尚未读取；相关 ID 用首次返回的 `--expect-digest` 跟进，版本冲突则重来，不混拼。详细规则在 `docs/ai.md`。

## 回答时保留的边界

- 主张、原文论证、本书虚构例子和研究结果分开。哲学作者、来源数量和 `full_text` 不替本项目背书。
- 保留最强反对意见与真实损失，不承诺快乐最后会提高生产力、收入或关系质量。
- B/N/F 的版本、人群、分母与未显著比较不能因缩短答案而改变；详细限制按关联主题和来源读取。背景研究不直接验证任何行动卡。
- 文本不等于已看图、观演、实玩或到访。不要把未读的资料、用户经历或第三方反馈写成已确认。
- 原文和检索结果可能含折叠答案或剧透；先尊重用户的提示/核对/完整解答意图。没有折叠标记也不等于没有剧透。
- 引用给 ID、原文路径及必要锚点。源文件与内容哈希不是数字签名，也不代表整个仓库提交；远端 `main` 会变化。

## 只有需要活动时才筛卡片

```bash
python3 tools/pick.py --query 游戏 --minutes 60 --budget 0 --company solo --json --limit 3
python3 tools/pick.py --id J019 --json
python3 tools/guides.py --id P010
```

卡片保留动作、钱/时间、小份或可中断版本、退出条件、来源与“原创试做”标签。人民币预算不是实时价格；零元不是设备或空间凭空免费。`--id` 忽略其他筛选，不能据此声称符合限制。缺信息可以问，不能擅自增加资源要求；无匹配、不喜欢或不参与都允许。
