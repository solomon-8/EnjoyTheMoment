# E02 · 有些快乐，值得占用一整个晚上

<a id="e02--想要更刺激不等于想把自己弄坏"></a>

**有些快乐值得占用整晚，不只配塞进缝隙。** 想要紧张、投入、热烈，不必先改口说自己只是想放松，也不必靠更贵、更猛、更失控来证明认真。

赢一局的兴奋、第一次上台的紧张、现场跟着节奏动起来的投入，都可能是想亲自经历的生活。我们要问的是：愿不愿意为它留位置，愿付什么代价，哪些代价其实没有得到同意？

从[为什么愿意留出整晚](#excitement-costs)和[“完整”究竟保住什么](#excitement-whole)开始，再看[刺激究竟来自什么](#excitement-information)、[知道结局以后还剩什么](#excitement-spoilers)、[为什么不舒服也可能被喜欢](#excitement-mixed-feelings)、[代价由谁决定](#excitement-boundaries)，最后谈[为什么尽兴不等于刷新纪录](#excitement-scoreboard)。

本文的分类与假想用于展开价值争论，不是神经科学模型或诊断；不测多巴胺，不用研究替个人划刺激阈值。

<a id="excitement-costs"></a>

<a id="另一个反对你是不是只肯为刺激付很小的代价"></a>

## 为什么想要完整的刺激，总被劝成五分钟？

如果本书每次遇到一个强烈愿望，都只回答“做个五分钟版本”，那这个批评成立。它虽然容易安排，却可能已经换掉了读者想要的东西。

设想小梁想去看一场完整的即兴演出。来回交通和演出会占掉整个晚上，也要放弃同一时间另一件想做的事。他知道演出可能有冷场，不保证每分钟精彩，仍想坐在那里，和其他观众一起等事情发生。把手机上的几个精彩片段发给他，不是自动找到了同一愿望的高性价比解法。

这个晚上真正需要讨论的，是他愿不愿意把这段时间交给它，以及这笔费用是否在自己能够支配的范围里。不是先把愿望缩到不妨碍任何其他安排，再称赞他会生活。**有些快乐值得占地方，不只值得塞进缝隙。**

我们愿意承认的代价包括：准备和往返的麻烦、另一个选项的放弃、一场并非每段都精彩的演出、公开尝试时的一点笨拙，以及结果未必符合期待。不是每一种都值得付，但也不是只要存在，就自动否决体验。

最难的不是找出完全没代价的刺激，而是接受选择之后仍可能只觉得一般。小梁散场后可以说“不太值”，不必因为自己主张及时享乐，就强迫这晚成为一次精彩人生的证据。他也可以觉得值得，理由只是某几次临场转折确实让自己投入，而不是它给他留下了技能、素材或人脉。

这并不授权把代价转给别人。一个人的“尽兴”，若靠同行者默默照料、替他付账或被迫熬完，便还没有说明这些人是否愿意。你可以请求别人共同投入，不能用“难得一次”替他们完成决定。

还有一类读者真正想要的是带有现实风险的活动，不只是作品和游戏中的悬念。不能假装一部电影与它完全等价。承认愿望不同，不等于本书能提供专业活动指导，更不等于用“活得精彩”证明风险越高越好。我们不把未掌握的技术和条件编造成廉价建议，也不把不愿承担某种后果的人降为不够会玩。

<a id="excitement-whole"></a>

### 完整，不是把能加的全部加上

“给我一个完整晚上”不必意味着节目最多、位置最贵、结束最晚。它需要回答一个更具体的问题：**哪些东西一旦被删掉，留下的就不再是我想经历的那件事？**

继续小梁的即兴演出，另设一段虚构表演：开头，两个人说一张空椅子要留给迟到的朋友；中间，第三个人几次想坐，都被他们用不同借口拦住；最后朋友终于来了，守椅子的人却习惯性地说“这里有人”，把他也挡在外面。一个短剪辑只保留最后那句和笑声。它可以很有趣，却没有让观看者经历“这个留下来的位置，怎么反而把要等的人拦住了”。

这不是实际演出的记录，也不是证明哪种剪辑更受欢迎。它要说明：前面的部分未必每秒都好笑，却可能构成后面转折的来处。想保留这种展开，不等于只愿忍受无聊、等未来发奖；等待、猜测、发现自己猜错，也可以就在过程中成为喜欢的内容。反过来，如果小梁只喜欢最后那个动作，短片并不因此低级。

**完整保护的是想经历的关系，不是已经列在节目单上的全部。** 若小梁想要的是这段演出从建立情境到散场的过程，追加一场自己并不想去的聚会，不会自动让它更完整；换到更贵的位置，也未必增加他在意的部分。若他本来就想在演出后和朋友聊到尽兴，那一段相处当然可以算进去。范围来自愿望，不由“都出来了”“都花钱了”自动扩张。

因此，完整可能需要长时间，但不能只用时长定义。几十分钟不能随意兑换成一个连续晚上，见[时间章对连续性与决定权的区分](../book/21-free-time.md)；先试一点是否真的接触到了想要的部分，见[消费章关于试一次的条件](../book/06-spending.md#spending-learning)。这里不重复它们的全部论证，只守住一点：**不能因为一种安排更省事，就先把愿望改小；也不能为了显得更完整，就替愿望不断加码。**

最强的反对是：“想要完整，难道不该答应看完？”事前留出整晚，与事中必须熬到最后，不是同一项承诺。可以接受某些平淡，等待仍然在意的展开；也可以发现这一次已经不想继续。喜欢完整结构，不要求给每个段落补写喜欢，更不让票钱成为强制忍耐的理由。实际离开仍要顾及约定与现场安排，不把退出说成没有代价。

<a id="excitement-information"></a>

## 刺激不是一个旋钮，也是一段事情怎样发生

设想两段虚构的现场：第一段从头到尾都很响，灯光不断变化，表演者每隔一会儿就要求大家欢呼。第二段有一小段安静，台上的人刚说出一个不完整的想法，搭档接住了它，事情突然往另一个方向走，全场在同一刻明白了那个转折。

两段都可能有人喜欢。这里想指出的不是安静胜过热闹，而是第二段的带劲不只来自感觉更强：它来自你听懂了前面什么、等待后面什么，以及变化发生时你和现场的关系。只把响度再提高，不能替代这些内容。

同样，一场比赛最后两分钟会不会让你屏住呼吸，可能取决于你是否在意某个队、理解比分和时间，而不仅是现场气氛。你可以只喜欢人群的节奏，不懂战术也有自己的乐趣；但如果已经看懂一个局面，接下来很小的变化就可能获得很大的分量。[观赛章节](../book/28-watching-sport.md)展开这些具体关系。

所以“我需要更刺激”，有时不是要求更多东西进入感官，而是要求正在发生的事对自己有更明确的意义——这里的意义只是“我在意这一刻接下来怎样”，不必是人生使命。

这也解释了为什么不能把旁观一律看低。看一场悬念正在展开的电影，不等于被动消耗；亲手做一个自己不感兴趣的东西，也不自动更投入。**参与感不按动了多少次手计算。** 观看者也会辨认、期待、误判、改想法；亲自上场则多出影响过程的可能，二者有差别，却不是谁更有资格享乐。

我们对更有刺激的生活的一个主张是：让一些事情真正占住注意，而不是只让更多事情经过眼前。这不要求每天都深度体验。只是当你渴望一个完整的晚上时，不能用“已经看过很多内容了”来证明愿望已被满足。

<a id="excitement-paths"></a>

### 四种不同的刺激，别只剩强度一条路

**悬念**可以来自不知道接下来怎样：一局有输赢但不下注的游戏，一个还不知道结尾的故事，一场双方都有可能翻盘的比赛。把结果留到最后，可能比把声音调大更接近你要的感觉。但不知道结果不是全部解释，知道结局也不能直接判定一段体验已经失效。

**亲自影响过程**是另一种愿望：从看别人画改成一起画，从旁听讨论改成提出一个问题，从看教程改成做一个小版本。这里特指获得行动和改变进程的机会，不是否认观看也有参与感；产出多好不是唯一标准。

**陌生**来自原先没有接触过的东西：新题材、不同表达方式、不同角色。它不必发生在远方，也不必与熟悉生活彻底断裂。你喜欢某种音乐，可以从相邻风格开始，而不是为证明开放一次跳进完全不想听的内容。

**强烈感官**也可以是真实愿望：更浓的味道、更热闹的现场、更鲜明的色彩。但强度需要适合身体和环境，不能把不适当成“终于真实”的凭证。具体活动的专业安全要求应另行核实，本篇不会用热情替代它们。

四种描述可以重合，不是等级，也不要求每次同时拥有。若你想亲自影响过程，却只换成更响的旁观内容，愿望可能仍未回应；若你想看的正是好故事，就不必被劝上台。

<a id="excitement-spoilers"></a>
### 知道结局，还能带劲吗？先别让一句研究替你剧透

设想一个原创小场景：台上两人等一通电话。你已经知道电话最终会来，却仍在看第二个人怎样一再伸手、又把手收回，第一人何时发现他的动作，以及铃声落在哪一次沉默后面。结局的信息没有增加，眼前的动作和等待仍在发生。

这里至少有三个问题：**不知道最终结果；在意过程怎样展开；愿不愿意再经历一次。** 它们有关联，不是同一件事。知道最后一球谁赢，可能减少对胜负的未知，却不等于已经看见那一球怎样打出来；反过来，有人要的恰好是首次揭晓，知道以后确实不想看了，也不必被教育成不懂作品。这个例子用于拆开问题，不是对观众通常怎样反应的测量。

<a id="excitement-spoiler-study"></a>
#### 一项实验没有发现平均差异，不等于每个人都不受影响

Levine与Raines在2025年发表的一项实验中，让326名大学生各读三篇短篇小说。每人经历三种条件：只给题名；先给一种可能的主题解释；先透露关键情节和结局。材料来自六篇有转折结局的故事，并不是每人把同一篇分别读三遍。[B45核读](../docs/evidence/B45-spoilers-and-experience.md)

看完每篇后，他们用1—10分评价享受程度，也回答悬念、好玩、感动等问题。享受评分的剧透条件差异没有达到统计显著，论文报告p = .29；悬念评分也没有发现显著的条件差异。**这不是“剧透有29%的概率无害”，也没有证明三种安排等效。** 不显著并不保证差别为零，更不能给某个具体读者开一张“不许介意”的证明。

这项结果也限制了另一种过强说法：不能把“我已经知道结局”直接当作“接下来必然不再享受”的同义句。研究没有测量同一个人对同一故事的两种反事实体验，更没有比较朋友未经同意的爆料与本人主动查结局。它检验的是指定短文与信息安排下的平均评分，而不是谁有权决定信息何时出现。

这里还有一个容易漏掉的范围：原本978次人—故事观察，剔除已读故事和异常阅读时长后，主要分析留下877次，不是877位读者；已经读过的故事恰恰被排除，因此不能将其说成重读效果实验。具体模型、个别交互结果及论文摘要与结果段的表述张力，留在核读记录中，不用一句“研究证明剧透没影响”盖过去。

<a id="excitement-spoiler-choice"></a>
#### 即使后来仍然喜欢，也不等于别人可以替你先知道

再把问题往前推一步。原创假想：小满明确说想先自己读完，阿岑却告诉她结局，理由是“有研究说不影响快乐”。读完以后，小满仍然很喜欢这个故事。我们是否只能在她评分下降时，才承认原来的约定值得尊重？

本书的回答是否定的。她可以同时说“故事很好”和“我想自己决定什么时候知道”。**享受多少，与按谁同意的方式经历，是两笔不能互相冲销的账。** 不必为了维护那份选择，反过来宣布整篇故事已被毁掉；别人也不能拿后来喜欢的事实，补写一份事先并不存在的同意。

这不是要求每场讨论永远不能讲结局。可以预先说明含剧透，另开一段深入讨论，或者约定某个时间以后再谈；愿意讨论的人不欠所有人无限期沉默。重点是范围与约定，而不是任何人都能单方面决定全部交流。已经明确选择进入含结局的讨论，也不能再要求它同时保持完全不知情。

有时读者反而想先知道某类情节是否出现，再决定要不要进入作品。可以询问需要哪一层信息：只回答有没有，还是连过程与结果一起说；这是一种沟通选择，不承诺任何提示一定足够，也不把提前了解贬为“浪费了刺激”。想保留未知和想先弄清，都可能是当事人认真想要的体验条件。

这件事不能完全交给“先试，不喜欢就退出”：暂停阅读可以停止继续接收信息，却不能把一次已经说出的结局当作从未告知。因而“过程退得出”之外，有些关键选择需要发生在开始之前。**耍起不是替人增加未知，而是让他有机会决定：这一次，我想知道到哪里。**

作品怎样安排线索与重看，另见[电影章](../book/12-film.md)、[阅读章](../book/22-reading.md)与[主动选择的害怕](../book/31-recreational-fear.md)。本节不把短篇小说实验推广成这些媒介的通用处方，也不把同意的论证说成实验结论。

<a id="excitement-not-fun"></a>
<a id="四种没劲可能要四个不同的出口"></a>

### “没劲”说出了不满，还没说出想要什么

“内容很多但都一样”“看了很久却不想只是观看”“气氛热闹却不是自己选的”“一开始喜欢、后来只剩惯性”，指向的可能是变化、参与方式、决定权或继续的理由。它们都是待核对的解释，不是从一句抱怨就能作出的诊断。

前面的四类刺激是在描述可能想要的东西；这几种不满是在说明现在缺了什么。两者没有一一对应的处方。觉得内容重复，不表示必须去陌生地方；看了很久，也不证明亲自上场就更合意。先听懂缺的是什么，比先发一张更长的活动单重要。

<a id="excitement-evening"></a>
<a id="情境刷了一小时想做点真正带劲的"></a>

### 刷了一小时以后，不必先完成三个微行动

以下仍是假想，不是读者反馈。同样有一个空闲晚上，同样刷了很久短视频却不满足，小梁可能已经很清楚：想去的就是前面那场演出，自己能支配的时间、费用与实际参与条件也已经核实。此时再要求他先换一段内容、玩个小关卡、走条短支线，不是在帮助发现愿望，而是在已知愿望前面又安了一道门槛。

在这个条件下，本书愿意直接支持他把晚上交给演出，不要求先选一个对其他安排影响最小的版本。准备、往返与可能失望的代价仍然存在；正因为不是免费得到，我们才需要明确说：**有些愿望值得直接认真对待，不必先被改造成一个更容易完成的小任务。**

但如果他只知道不满足，还不知道想看什么、想和谁一起、是否仍想继续娱乐，那么换内容、换参与方式或换环境，可以成为自愿的探索。不是三步流程，也不要求把它们全试完；探索可能无效，最后想休息也不是失败。这里的区别不是大版比小版高贵，而是：**探索未定的愿望，与批准已经明确的愿望，不是同一件工作。**

还有第三种情况：愿望明确，今晚的条件却不成立。小梁可以承认这晚去不了，另选真正喜欢的活动，或为下一次安排资源；不必把替代品说成已经充分满足，也不必把整个晚上判成作废。关于[等待会改变什么](03-now-or-later.md#waiting-different-goods)，以及[为了省掉准备反而没玩成](03-now-or-later.md#waiting-pleasure-procrastination)，时间长文已经展开。暂时做不到，不需要靠假装“其实小份完全一样”来安慰。

<a id="excitement-mixed-feelings"></a>

## 我想好好难过一会儿，不是等难过以后才快乐

“及时享乐”容易被想成只有轻松、顺滑、不断得到好消息。但你可能主动选一首悲伤的歌，愿意让一个故事把心情带得低一点，也可能喜欢明知是表演仍感到紧张的片刻。

需要分清三种情况。以下是本书的分析，不是给情绪分型：

- **忍受不喜欢的部分，以换取之后喜欢的部分。** 比如你不喜欢排队，但想看演出。队伍本身不必因此变好玩。
- **事情正在发生时，就喜欢其中带来的复杂感受。** 一段歌并没有把你逗乐，但你想继续听，不是仅仅等待它结束。
- **当时不喜欢，事后认为值得。** 一次辛苦经历带来了别的收获，也不必倒推当时其实很享受。

这三种不能互相代领评价。说“后来回想起来不错”，不能替代“过程中是否喜欢”；说“正在哭”，也不足以替别人宣布这段体验没有价值。

一个虚构例子：小何听一张熟悉的专辑，其中一首歌会让他想起一段已经结束的相处。他不想立刻切到欢快的歌，愿意听完那一段。这可以是他的选择。另一位听众在同一首歌中只感到被拖回不想碰的记忆，决定关掉，也没有少懂一层人生。

我们不需要把前者解释成“借悲伤提升情绪”，才能允许这份感受存在；也不能拿前者的选择要求后者继续。尤其不能从娱乐中的悲伤，推到现实损失都值得享受。**喜欢作品带来的难过，不等于同意别人真的让你难过。**

在这个意义上，享受当下不是要求此刻只剩一种明亮表情。它也可以是愿意进入一种复杂的感受，不急着把它加工成振奋、成长或一个好结局。

下面两节分别看[关于不适偏好的问卷](#excitement-study)和[丰富性与快乐的区别](#excitement-richness)，不把不同问题合成一种“更高级的享受”。

<a id="excitement-study"></a>

### 一项研究：喜欢某种不适，不等于把极限当目标

Rozin等人让243名大学生和147名网络受访者评价一组通常带有负面感受的活动。他们询问喜欢程度，并没有让这390人现场吃辣、看悲剧、坐过山车，再逐级调高强度。这是偏好问卷，不是刺激剂量实验。[B24](../docs/research.md#b24)

作者把某些负面体验也能被喜欢的现象，放在“良性受虐”（benign masochism）的解释下讨论：人知道某种威胁不是真正要发生在自己身上，却仍体验到身体或情绪反应。这里是论文术语，不是临床诊断；“良性”更不是本仓库对某项活动出具的安全证明。

有一个结果很容易被引用成相反的意思。66名网络受访者还回答了类似“我最喜欢的是刚好还能承受的最强那档”这样的陈述。每题先排除明确不喜欢该活动的人，留下48—58个回答。过山车那题59%赞同；悲伤音乐那题37%赞同。再只看相关喜欢评分高于50的人，相应比例升到82%和56%。分母变了，不能把82%说成所有受访者都希望被推到极限。

更重要的是：这些人在回答自己如何描述偏好，并没有实际展示一条“调高到这里就最好”的个人曲线。研究没有给出谁该吃多辣、承受多大惊吓的建议，不能把接近承受极限设成娱乐目标。比例、量表处理和原文表格疑点见[核读记录](../docs/evidence/B24-hedonic-reversals.md)。

它对本书的启发很有限，也很有用：不能仅凭一种感受通常令人回避，就断言没有人会主动喜欢它。但是否喜欢、喜欢哪一部分、想要多强，仍然需要分开。

反过来，无论“心理丰富性”还是“良性受虐”，这些研究概念也不能成为更高级的娱乐许可证。有人只是喜欢明快的歌、熟悉的味道、知道结尾的故事，并不欠研究者或本书一种更复杂的偏好。

<a id="excitement-richness"></a>

### 为什么不把舒适、新奇、意义混成一个分数？

一个晚上可以很舒服但不新鲜，一次体验可以很新奇却并不愉快，一项有意义的事情也可能相当辛苦。

Oishi 与 Westgate 提出把“心理丰富性”作为幸福和意义之外的一个维度。我们核读的作者托管页校样讨论了有趣且改变视角的体验；它**不是**对冒险或强刺激的统一推荐，也没有检验即时满足比延迟更好。[研究 B03](../docs/research.md#b03)

其中有一项对我们很重要的挑战：图形实验中，参与者觉得体验更丰富，却没有相应的积极情绪差异。九国样本的强制选择中，幸福是最多人的选择，丰富人生不是多数人的首选。不能只引用“多一种好生活”，就把论文拿来替“人人都该更刺激”站台。版本、实验与调查的区别见[详细阅读记录](../docs/evidence/B03-richness.md)。

这让我们更愿意把问题留给具体愿望，而不是宣布“没去冒险，就没真正活过”。一段新奇经历也许增长见识却十分不舒服，一场熟悉的相聚也许毫无新意却正合心意。前者不自动更高级；一顿熟悉的饭、一首听过很多次的歌，也不需要靠改变世界观或促进成长重新申请资格。

“这会成为很好的故事”是一个可能的理由，不是强迫你经历不想经历之事的通行证。别人会感兴趣的叙述，与自己愿意付出的经历，必须分开考虑。

<a id="excitement-boundaries"></a>

## 愿意付代价，不等于别人可以替你决定

小梁愿意接受冷场，不等于答应临时加价；愿意等一个未知的转折，也不等于同意别人瞒着参与条件。想弄清的不是怎样消除全部不确定，而是哪些不确定属于自己想经历的部分。

这里区分[悬念与隐瞒](#excitement-uncertainty)、[几种不同的害怕](#excitement-fear)，再回应[边界是否扫兴](#excitement-check-before)与[怎样安排完整体验](#excitement-arrange)。

<a id="excitement-uncertainty"></a>

### 有些不确定值得接受，有些只是在转嫁代价

一场即兴表演可能不是每个片段都好笑；一局游戏可能会输；一次初学尝试可能十分笨拙。你付出的有一部分就是不知道结果的机会。只要本人愿意，不能仅因“没有保证”就把它们全部赶出生活。

但主办方不肯说明费用、朋友拒绝接受你退出、活动需要隐瞒信息，这些不确定不是乐趣所必需。不要把别人不愿负责的部分浪漫化成冒险。

可以问：“如果把这个不确定去掉，体验会失去什么？”提前知道游戏结果，悬念可能没了；提前知道收费项目，游戏本身通常不会因此不好玩。这个区分是我们的分析建议，不代替对具体活动的事实核查。

<a id="excitement-fear"></a>

### 怕输、怕丢脸、怕身体不适，不是一种怕

我们不把所有害怕都回答成“勇敢一点”。

**怕输**：如果你本人愿意参加有输赢的活动，输可能就是玩法的一部分。可以选不影响基本生活、不牵涉金钱赌注的局，事先约定输了不追加惩罚，也不把水平差异上升成人的价值。

**怕丢脸**：公开表演、陌生社交和新爱好可能涉及被看见。可以先选允许旁观、搭档或退出的版本，问清是否录像，不用直接把自己推到最难的位置。但如果你愿意接受一点笨拙来换一次上场，那也值得，不必等到练得完美才出现。

**怕身体不适或环境不明**：这可能包含重要信息，不能用“突破舒适区”覆盖。活动要求不清楚、资质与保障无法核实、过程无法退出时，先停止判断。寻求合适的专业说明，不从本仓库拿一张“勇敢许可证”。

一个人可以接受失败，却拒绝受伤；可以愿意出丑，却不愿公开影像。这些不是互相矛盾的胆量，而是不同代价的选择。

<a id="excitement-check-before"></a>

### 最强的反对意见：设这么多边界，还能尽兴吗？

如果每一分钟都在检查自己是否合规，当然会扫兴。但没有边界也未必带来自由：不知道总价、不清楚怎么回家、不确定同伴是否愿意、害怕一旦开始就不能停，都可能让人无法真正投入。

我们的建议是把关键决定前移。开始前确认那些会改变答案的事；确认之后，把注意力交给体验，不必反复审问自己的快乐。只有条件改变、出现不适或有人想停时，再重新决定。

比如一场游戏局，先约定玩多久、是否付费、哪些玩笑不碰。开局后就认真赢、认真笑，不需要每轮讨论价值观。一场演出，先核实安排与返程，现场就按自己合适的方式参与，不拿每个瞬间做投资回报分析。

**边界是为了让愿意投入的人更能投入，不是把享乐改成风险表演。**

<a id="一个更有野心但不靠冒险的版本"></a>
<a id="excitement-arrange"></a>

### 把完整体验安排进生活，而不是换成别的东西

如果想要的是即兴表演、节奏体验、桌游局或陌生题材的现场，就围绕这份愿望确认参与要求、总费用、往返和退出方式，而不是先缩成另一件方便的事。声音、灯光、拥挤程度、规则和同伴互动，也关系到你愿不愿意待在其中；公开活动不天然适合所有人，更不自动等于没有风险。

不是所有地方都能在相同预算里找到选择。[J015](../book/03-novelty.md#j015) 和 [J020](../book/04-play.md#j020) 的数字只是筛选上限，不是“花一百元就能买到刺激”的价格承诺。

暂时条件不合适，可以先安排资源、等待一个想要的版本。小份是选项，不是假装所有体验等价的安慰；微行动不能完全替代现场感。

<a id="excitement-scoreboard"></a>

## 把刺激从人生竞赛里拿回来

想要更带劲的生活，与要求每次都刷新个人纪录，看起来很像，方向却可能不同。

虚构的阿澄参加了一次现场演出，回家后很满足。第二天有人问：去了多少场？有没有进最前排？为什么没拿到互动机会？下次是不是该选更大的场地？如果这些问题变成评价这晚的唯一语言，原本已经发生的享受，就会被改判成尚未达标。

数量和记录并非敌人。有人真心喜欢完整听一轮演出、收集一组作品，或练到下一种玩法；这些目标本身也可以有趣。区别是：指标有没有帮助描述本人想要的过程，还是开始抹掉指标以外已经得到的东西。

重复是否还有想经历的内容，见[新鲜感一章](../book/03-novelty.md#novelty-repeat)对熟悉、真实厌倦与重看研究的区分。阿澄不必先找到新细节，才能承认同样的快乐还值得再来；已经不喜欢，也不必强迫重复。这里反对的是仅凭履历，就把当事人的感受改判为不及格。

同样，安静的一周不会撤销你享乐的资格。若一个主张要求读者每周都能交出新鲜行程、每次都要更敢、更贵、更难忘，它已经把“会生活”做成另一套绩效制度。**耍起不该给日历配一个排行榜。**

这一点也约束我们自己的表达。写得吸引人，不等于把每个普通晚上都说成必须改变人生；鼓励人重视愿望，也不等于承诺只要认真去玩，就一定有所收获。我们希望读者多一些可以投入的生活，不是多一份证明自己活得精彩的工作。

<a id="excitement-continue"></a>

### 一直找下一次，会不会永远不够？

可能。有时候真正想要的体验已经结束，却还在追求把同一种感觉延长。下一局不是因为想玩，而是因为不愿承认刚才的高点过去了；再买一次不是因为喜欢，而是想让下单时的兴奋重演。

这并不自动构成诊断，也不意味着你应该永远减少娱乐。值得分辨的是：此刻的继续，是否仍然有你期待的具体内容，还是只剩“不想停”的命令。

可以离开几分钟再决定，也可以按原约定结束；如果之后仍想玩，下次再安排。结束不是否定刚才的投入，而是承认一次体验有自己的长度。

如果行为已经超出本人控制并影响基本生活，本项目不拿“耍起”替它找理由，也不提供更聪明的升级刺激策略。实际支持应根据具体问题寻找，娱乐菜单并非解决所有困难的工具。

### 什么才算一个带劲的晚上

它可能很吵，也可能只是安静地较劲；可能很新，也可能是熟悉一局的意外；可能认真准备，也可能随手开始。我们不把不舒服、昂贵和失控当成尽兴的必备条件。**更刺激应该是你想增加的体验，不是你必须增加的伤害。**

<a id="excitement-stop"></a>

### 什么时候这套思路不适合继续用？

- 你需要靠伤害自己或他人来制造强度。
- 活动要求隐瞒费用、忽视拒绝或接受不明物质。
- 你已经明确不想继续，却需要不断找理由证明应该继续。
- 当前的疲惫、身体条件或责任安排根本不允许参与。

此时不是寻找更巧妙的刺激方案，而是停止拿本项目的口号催促自己。
