# E01 · 快乐不是一种需要报销的支出

**结论先说：本仓库不是劝人放弃未来，而是反对只有未来收益才能证明今天值得。**

我们很容易替快乐找一个更体面的理由：听音乐可以放松，游戏可以锻炼反应，旅行可以开阔眼界。理由未必错，问题是，假如这些收益不存在，你还愿不愿意允许自己喜欢它？

如果这些收益一撤去，快乐就不再被允许，它仍然只是工具。

**一顿饭可以只是好吃，一场游戏可以只是好玩，一次相聚可以只是想见。句子可以在这里结束。**

本文沿着五个问题展开：

1. [为什么值得](#pleasure-ground)：[把快乐也算成收益](#pleasure-value-metric)，是否就没有分歧了？
2. [愿意付出什么](#pleasure-tradeoffs)：[过程值得亲自经历](#pleasure-process)，也仍然占用时间；[保留选项](#pleasure-options)与[不必选到最好](#pleasure-enough)，各有什么代价？
3. [什么会改变决定](#pleasure-conditions)：[同意不等于赞许](#pleasure-consent-scope)，[关心也不自动授予接管权](#pleasure-concern)；喜欢不能替别人同意，也不让现在自动胜过以后。
4. [结果不如愿怎么办](#pleasure-feedback)：可能选错，仍可以尝试；[重视快乐，不等于必须快乐](#pleasure-not-quota)。
5. [这本书是否做到了](#pleasure-self-test)：既不能拿刺激口号删掉代价，也不能退回只允许零代价的舒服。

主张概览见[耍起](../SHUAQI.md#shuaqi-position)。

<a id="pleasure-ground"></a>

## 一、先争论快乐有没有价值，而不是先算它的用途

### 两种人生账本，差别在目标，不在是否清醒

第一种账本先确定若干长期目标，再看今天的选择对它们有何帮助：更健康、更有钱、更有效率、更自由。它能帮助人理解取舍，尤其当现实资源有限、风险具体时。

另一种账本也看后果，但把“这段时间本人是否愿意这样过”直接列为目标之一。它不要求每段快乐都在别处产生回报：一个没产出的晚上可以直接记为值得，而不必借“恢复之后更能工作”入账。

这是两种说明理由的方式，不是把人分成两类。同一个人也可能在不同事情上采用不同的账本。分歧是：**当目标冲突时，当下的喜欢是否默认让路？** 未来有分量，却不因此对每个今天都有优先权。

这也是我们与参考项目的关系：借鉴它把人生问题讲具体的方式，不把它描述成反对享受的反派；另行提出价值排序，而不是把健康和安全建议逐条反过来。下面讨论的是一种可能的反对意见，不把它安到参考作者头上。

<a id="pleasure-value-metric"></a>

### 把快乐也算成收益，不就还是性价比吗？

这个反对意见值得认真接受：既然好吃、好玩、相聚都有价值，把它们放进“收益”，再比较付出与所得，不就行了？为什么非得换一种人生观？

**如果“性价比”只是提醒人看清代价、别为自己不想要的东西白花资源，我们并不反对。** 同一场演出、相同座位与可靠的服务，价格不同，选便宜的没有背叛享乐。算账有时是在给更想过的生活腾地方，不是它的敌人。

但说“快乐也有价值”，还没有回答三个问题：

- **允许算进去，还是必须证明有别的回报？** 如果一段快乐只有能改善履历、健康或社交时才获准入账，它仍然是工具。把表格那一栏改名为快乐，没有改变这个要求。
- **什么才是付出的成本，什么已经是想得到的生活？** 做饭占用的时间，可能是为了吃饱不得不付的成本，也可能正是今晚想亲自经历的部分。不能不问目的，就把用时越少当成同一个人的收益越大。
- **已经值得，还是必须胜过所有备选？** 承认一场游戏好玩，不等于它必须胜过今晚所有游戏才可以开始。接受未必最优，可能正是愿意为这段生活承担的代价。

我们不是另外发明一张“快乐产量表”。快乐可以直接成为理由，过程可以是所求，选择不必每次都附上一份最优证明。

反对者仍然可以说：“这些我都放进收益里了，也从没要求穷尽所有选项。”那在这些问题上，**我们可能本来就同意，不必为了显得不同而制造冲突。** 如果一种比较已经认真考虑本人的快乐和过程价值，本节没有证明它与“耍起”不相容。我们反对的是某种默认排序，不是“性价比”三个字。

分歧应当落在实际选择上：当快乐不再带来别的好处、亲自经历比代办更费时、另一个选择确实更省钱或更有助于事业时，我们还愿不愿意给它位置？

“享受当下”的答案是愿意。不是每次都选它，也不是付出越多越真诚，而是不让“还有更有用的选择”自动结束讨论。

### 三个不同的问题，不要混着回答

| 问题 | 谁能提供什么 |
| --- | --- |
| 我想把什么放在人生的重要位置？ | 价值选择，不能由研究强制决定 |
| 某种做法通常可能带来什么感受？ | 研究与经历能提供有限线索 |
| 这次是否适合我？ | 需要具体条件、本人偏好与实际反馈 |

“某项研究发现购买省时服务后情绪更好”，不能推出“每个人都该把家务外包”。反过来，研究没有证明一首歌能提高幸福，也不意味着你必须停止喜欢它。

[研究台账](../docs/research.md)用于讨论经验问题，而不是给宣言盖科学印章。

### 另一个反对意见：只顾快乐，会不会没有意义？

有些人更看重贡献、信仰、创造、责任或成就。他们愿意为这些目标承受不愉快的过程，这不是本仓库有资格取消的选择。

但“我愿意为某个目标承受辛苦”，与“所有人的快乐都必须服从某个更高目标”并不相同。你可以同时有责任、有抱负，也保留一部分不服务它们的时间。不必把整个人生压缩成一个总目标，才算有方向。

“耍起”不是要求把意义踢出门，而是拒绝把快乐永远安排在门外。一个爱好可以有意义，也可以没有你愿意对外解释的意义。它不欠别人一段宏大的叙述。

如果有人只是想过安稳、舒服、与亲近的人相处的生活，我们不会因为它不够刺激而判失败；如果有人真想增加新鲜和强烈体验，我们也不会把这个愿望一律按回安静。

<a id="pleasure-tradeoffs"></a>

## 二、愿意付出什么，才是价值排序的分歧

### 对照两笔都负担得起的支出

假设必要支出已经安排好，一笔钱确实可由你自主使用：保留它，还是看一场惦记很久、却没有职业价值的演出？回忆也不保证长久。

这个例子里，没有科学公式能替你决定“保留”还是“去”。我们主张的不是去才正确，而是：**“我真的想听到这一场”已经是一项正当理由。** 它不需要先翻译成社交投资、文化资本或终身回报。

房租和未经同意的共同资金不符合前提；这里不给统一比例，也不代做个人财务判断。但确认必要条件，不等于必须把未来完全安排好：**当讨论已经进入可选择的范围，快乐不是需要先排除的干扰项。** “还要保留多少可能性”值得单独讨论，而不是用一句先攒着结束对话。

<a id="pleasure-process"></a>

### 做得更慢，就一定更不划算吗？

设想两个人都想吃一碗面。以下是为了拆开理由的原创假想，不是调查、计时结果或消费建议。

阿岚饿了，也想早点坐下看电影。对她来说，把面做好主要是取得晚餐的过程；若有符合口味、负担得起又省事的选择，省下这段时间正合心意。

小周却想在厨房里待一会儿：试一试面条的口感，慢慢调一碗自己喜欢的汤。假设可以直接端给他一碗味道完全相同的成品，也不保证替代了他的愿望。被省略的，不只是通往结果的麻烦，还可能是他原本想度过的晚上。

**一道菜可以被端上来，一个想亲自做菜的晚上不能被代办。** 差别不是两人的生活谁更高级，而是他们想得到的东西并不相同。只比较最后碗里的面，就已经替第二个人删掉了一个目标。

把过程算作乐趣，也不会让那段时间同时空出来。小周仍然放弃了同一时段看电影或做别的事的机会。变化不是成本消失，而是这段时间不再**只**被列在成本一边：他想要的部分已经在过程中发生，不必等饭做好以后才开始计算。

这里也不能反过来美化一切耗时。小周可能喜欢调汤，却不喜欢买材料和收拾；可以保留想做的部分，减少不想做的部分。若由同住者默默收拾，那个“我的享受”还包含尚未说清的别人劳动。若今天他只想吃饭，不想下厨，也不必为了维护手作的名声坚持原来的安排。

最有力的反对是：“资源少的时候，哪能任性地慢下来？”确实，必要安排可能使这个晚上根本不可行。我们不能用一句喜欢把这些限制抹掉。但这影响的是**此刻能否安排**，不等于证明慢慢做的部分本来就没有价值。可以承认暂时做不到，而不必再把想要它说成不懂事。

反过来，如果所谓省事要花掉本人更在意的钱或带来别的麻烦，也未必真正合适。这里没有“有钱买时间才会享受”，也没有“亲力亲为才算生活”的排名。

所以，效率有一个前提：先知道要保留什么，再讨论怎样少付不必要的代价。**耍起不是反对节省，而是不让节省把原本想过的生活一起省掉。**

<a id="pleasure-options"></a>

### 人生选项变多，不等于人生已经发生

替未来保留资源有一个很强的理由：多留一些钱、时间和精力，之后就有机会应对意外、改变方向、选择更想要的事。现在用掉它们，确实可能让以后能选的东西变少。不能只把这一面写成胆小或不敢生活。

但这里有两个不同目标：**保留选择的能力，与经历某个选择所带来的生活。** 前者可以为后者创造条件，却不等于后者已经发生。如果任何使用都会因为减少可选项而被否决，选择权就只允许储存，不允许行使。

设想你有一个真正空出的周六下午，没有必须履行的安排。你很想看一场普通演出，它不是最后一场，也没有故意制造的倒计时。两个去处是：看演出，或者继续为某种尚未确定的将来做准备。这是虚构情境，不是把现实所有周六都说成可自由支配。

支持准备的人可以说：“你没有损失什么，下周还能去。”从可能性的角度看，这有道理；从具体经历看，却没有完全说中。下周再去，是下周发生另一段生活，不能让这个周六既用于准备又用于演出。**延期并非一概错误，但延期也不是没有选择。它选择了让这次体验不发生。**

还可以更强地反对我们：“你可能以后找到更喜欢的事情，现在保留选择才划算。”这个可能性值得计入，却需要和另一个可能性一起讨论：未来也可能继续等待，再发现一个值得多准备的理由。不能只把尚未出现的收益当作开放空间，把已经想要的经历当作可随时挪走的占位符。

我们因此提出一个有偏向的立场，而不是一个普遍最优算法：当必要安排有着落、代价在本人可承担的范围内、眼前愿望明确，而继续等待没有更具体的理由时，**我们更愿意兑现一个真实愿望，而不是只增加抽象的可选性。**

这项立场不需要“人生苦短”来制造紧迫感。即使没有最后一次、没有限时窗口，一个普通下午也可以值得被实际度过。限时体验有自己的问题，另见[E03](03-now-or-later.md)；这里讨论的正是没有稀缺广告时，快乐是否仍有正当位置。

三个看似相近的“先不去”，也该分开：

| 延后的理由 | 延后正在保留什么 | 会改变判断的事实 |
| --- | --- | --- |
| 下周要与很想同行的人一起去 | 本人更想要的共同体验 | 对方是否愿意，时间是否真的能安排 |
| 最近有一项已知的重要支出 | 应对一个具体需要的能力 | 支出范围、已有资源和实际责任 |
| 也许以后还能更有用，所以继续等等 | 未指定的未来可能性 | 是否有可说明的目标，还是每次使用都被同一句话否决 |

第三种不是天然不合理。有的人享受留有余地，暂时也没有更想发生的事，这本身可以是偏好。问题出在一边明确想去，一边禁止自己把任何资源用到具体生活里，然后把这套禁令说成唯一成熟的答案。

还有一种真正有力的保留：你正处在可能换工作、换住处的阶段，眼下说不出最终选择，但知道不确定性集中在哪里。这样的余地不因为没有定下去处，就变成“虚构的未来”。我们要求等待接受解释，不要求它预知未来。分歧只在于，是否把任何无法排除的可能性都提升成永久否决当下的理由。

反过来，资源严重受限时，保留选择可能不是抽象偏好，而是在保护基本生活。不能拿本节替代个人财务判断，也不能用“赶紧兑现”催别人花掉他真正需要的储备。**反对永远准备，不等于把准备本身定罪；争取的是兑现也有一次不被预先驳回的机会。**

<a id="pleasure-enough"></a>

### 每个夜晚，都要赢过全部备选吗？

另一个更隐蔽的门槛是：我们已经接受快乐有价值，却仍要求每次选中的快乐必须是最好的。电影可以看，但必须胜过今晚所有其他电影；朋友可以见，但最好别错过更精彩的一场局。

比较当然能减少明显错配。只是“这件事对我值得”“它比另外几个具体选项更合适”“它胜过所有可能选项”，是三种强度不同的主张。前两种并没有自动证明第三种，而日常选择未必需要背负第三种。

设想你知道两部电影的大致内容，今晚想看甲。朋友后来告诉你，乙也许更好看。这里至少有三种情况：

1. **乙确实更符合你当时明确的偏好，只是你漏看了重要信息。** 这可以成为下次改进选择的理由。
2. **你知道乙的特点，但当晚就想要甲的节奏和气氛。** 朋友更喜欢乙，不足以证明你选错。
3. **你不知道看乙会怎样，只知道甲带来了想要的两个小时。** 未经历的乙可能更好，也可能不好；不能用一个被想象成完美的版本，把已经发生的喜欢一笔注销。

这些是逻辑上的区别，不是关于人们通常怎样后悔的心理学结论。它们也不主张“选了就不准反悔”。如果甲根本不合适，可以承认；如果你就是喜欢广泛比较、找更对味的东西，挑选本身也可以是享乐的一部分。

我们反对的是比较拥有无限续期权：只要还有一个未查过的选项，今晚就永远不能开始。把快乐当正事，也包括承认**在信息不完备时，选择一个有理由喜欢的东西，不必先证明它是世界上最好的东西。**

“不必最优”也不是一张给商家和组织者的免检证。承诺的条件是否兑现、内容是否与描述相符、是否擅自增加费用，都仍然可以核对。读者不必追求全球最优，与提供者应当履行明确承诺，不冲突。

再看机会成本。选择一场演出，就放弃同一时间的电影、练习或发呆；这个代价是真实的。但若把所有放弃的项目分别算成损失再相加，仿佛不去演出便能在同一晚把它们全做完，就把比较对象拼成了一个不存在的晚上。应比较现实可行的替代安排，而不是让一个实际选择与所有想象中的好处分身比赛。

这里也没有“既然总要放弃，就别思考”的跳步。重要、难以撤销或影响别人的选择，值得更充分的了解。我们只是不给每一个私人晚上都设置同样沉重的最优证明义务。

**可以认真选择，也可以接受自己没有选遍；可以保留遗憾，也不必宣布已经喜欢过的部分全是假的。** 愿意承受没有穷尽全部可能性，是我们为让生活实际发生而接受的代价之一。

<a id="pleasure-conditions"></a>

## 三、喜欢是理由，不是所有做法的通行证

### 喜欢是理由，为什么还需要讨论？

因为“我喜欢”足以说明一项价值，却不足以说明全部条件。

你喜欢开大音量，邻居也有安静的需求；你喜欢临时旅行，同行者可能不愿承担改计划的麻烦；你喜欢消费带来的兴奋，共同资金却不能由一个人决定。承认快乐有价值，并不赋予它无条件压倒其他人的权利。

可以把判断拆成两层：“为什么值得考虑”，喜欢本身就能提供理由；“这个具体做法是否实行”，还要面对成本、同意、条件和后果，答案可能是换方式、等待或不做。

两层混在一起时，容易出现两个错误：一种因为有成本，就宣布快乐不正当；另一种因为快乐正当，就拒绝谈任何成本。我们两种都不接受。

<a id="pleasure-consent-scope"></a>

### “他人同意”，难道是所有人满意了才准玩？

如果是，那“耍起”只是把工作审批换成了全体熟人的审批。**他人同意，不等于他人赞许。** 要问的是，这件事让谁参与、占用谁的资源、改变了什么共同安排；不是统计有多少人觉得你的爱好像样。

看三个原创假想。阿宁独自在自己的可支配时间里戴耳机听歌，没有占用共同资金或耽误约定。朋友觉得这类歌很俗，不想听，也不想讨论。这些意见可以存在，但它们没有自动变成阿宁停止听歌的义务。朋友不必一起喜欢，阿宁也不必先说服朋友，才能喜欢。

再改一个条件：阿宁把音箱搬进共用客厅，室友正在看书。此时“我的爱好不用你批准”没有回答声音占用了谁的空间。室友要求调整播放安排，不需要先证明这类音乐不好。可协商的是时间、位置、声音和各自的使用机会，不是用审美输赢决定谁配待在家里。[共同居住](../book/36-home.md#home-sharing)进一步讨论，安静也不能被用来要求某个人永远像不存在一样。

第三种情形，阿宁约朋友听歌，朋友答应一起坐一会儿，却没有同样喜欢。阿宁若说“不夸就是不支持我”，便把同意相处扩大成了必须赞许。**别人答应陪你，不等于答应交出自己的感受。** 如果事先约定的是认真听完、提供反馈，可以讨论有没有做到；仍不能约定对方必须真心感动。

三种情形的差别不在谁更会享受，而在于谁对什么作了决定。不参加、不喜欢、要求修改共同安排，并不是同一种拒绝；一句“别扫兴”不能把它们全部取消，一句“别人不同意”也不能把它们全部变成禁令。

<a id="pleasure-disapproval"></a>

### “你这样让我失望”，就获得否决权了吗？

一个更难的反对是：“我在乎你，所以你的选择确实会让我难受。难道这不算对我的影响？”

影响可以是真的，仍需继续问：**这份难受要求我们关心什么，又足以要求对方交出什么决定？** 感受的真实性，不会自动决定应当怎样处理它。否则，只要有人比你更不满意，你就只能按那个人的偏好生活。

假如阿宁答应了共同度过一个晚上，却临时改成独自听歌，对方失望有一项具体约定作为理由。阿宁需要回应的不只是“你为什么看不起我的爱好”，而是自己改变了什么。如果两人总是没有时间相处，也不能等对方拿出逐分钟签字的承诺，才承认关系有实际需要。这里的共同责任不只等于白纸黑字。

但如果已经说清各自安排，对方只是认为“成熟的人不该听这种歌”，失望本身就不足以取消阿宁的选择。对方可以表达不认同，也可以不参加；阿宁不欠一份同样口味的证明。把人物和爱好对换，规则也应如此：反功利的人同样不能因为朋友喜欢进修、练习或认真做项目，就宣布那个人背叛生活。

这不保证关系没有损失。共同兴趣变少，可能使一些相聚不再发生；保有选择并不附赠永远被理解、被邀请的保证。[第8章](../book/08-permission.md#permission-belonging)保留了这种代价。我们愿意为私人选择辩护，也不要求别人为了证明宽容，必须继续陪伴每一种选择。

<a id="pleasure-concern"></a>

### 关心可以提出理由，不自动成为接管生活的资格

密尔在《论自由》第四章区分了几件容易挤在一起的事：帮助别人判断、表达不赞同、选择自己的交往，以及有意让别人受罚、迫使其服从。原文并不是“谁也不准管我”：他保留劝告、关心与不愿交往的空间，也承认对他人的具体义务。[F86：原文与使用范围](../docs/evidence/F86-liberty-and-disapproval.md)

这个区别能把争论向前推一步。朋友提醒阿宁：“你答应明早交接，今晚这个安排可能赶不上”，提出的是可以检查的理由；阿宁应该认真面对，而不是以“别管我”拒绝信息。但如果提醒已经变成“只要我认为你还有更好的用法，你的每个晚上就由我安排”，关心便被扩张成了没有终点的权限。

反过来，阿宁也不能要求朋友只说让自己高兴的话。**批评一种选择，与获得替人决定的权力，不是同一回事。** 一条有用的提醒即使不好听，仍可能改变答案；一条理由不充分的要求，即使出于真心关爱，也仍需要被质疑。

密尔同样不能替本书结束这场争论。他的原文容许因所谓低下趣味而轻视他人，也把某些感官快乐放在较低的位置。本书不接受用这些说法给享乐者排人格等级；有关快乐高低的争论另见[E11](11-pleasure-and-reality.md#pleasure-quality)。我们借用的是评价、关心与强制的区分，不是把他的全部价值排序一起签收。

不赞同也不免除表达方式的责任：威胁、持续羞辱、针对他人的骚扰，不能只因内容涉及私人偏好，就被改名为“各有各的口味”。

这些区分不能直接裁决未成年人的照护、公共规则或具体法律争议；本文讨论的是具备自主判断能力的成年人怎样为私人选择说明理由。它也不把“双方都愿意”当作已经排除所有外部影响。真正的冲突仍需具体了解，而不能由本书替受影响的人宣布没关系。

**快乐不需要全票通过，牵动别人的部分仍需认真交代。** 这不是保证别人再也不失望，而是不让任何一方仅凭“我喜欢”或“我不喜欢”，就获得对整段生活的所有权。

### 即时满足是否天生低级？

把一种选择叫“即时满足”，很容易让它听起来已经输了：短视、没毅力、不懂规划。可同样是现在想要的东西，有的只是听完一首歌，有的涉及大额不可逆支出，有的需要侵犯他人。它们的代价与可撤销程度相差很远，不能只按发生得早晚归类。

延迟也一样。为了和朋友共同参加而等待，可能是愿望的一部分；因为总觉得自己不配，连眼前负担得起的小事也推迟，未必更成熟。时间顺序不自动给选择分配道德等级。

我们主张的及时，是让愿望在仍然存在、条件允许时得到认真回应，不是让所有冲动获得最快执行。当前的喜欢也可以包含“我想慢慢期待”“我想今晚什么都不安排”。

所以我们既不同意“现在快乐就是不理性”，也不宣称“立刻行动才是真正会活”。把两种口号都拿开，才有空间讨论具体愿望。

### 即时满足，究竟在哪些地方有优先权？

以下是本项目的**价值主张**，不是经过实验验证的决策法则：

- **可以现在做，又容易退出的小愿望**：默认不再要求写一份长期收益报告。
- **有明显时间窗口的体验**：认真考虑错过的成本，而不只计算去做的成本。
- **消耗大量资源、牵涉别人或难以撤销的决定**：先确认条件，不能凭“人生只有一次”跳过后果。
- **纯粹是别人认为你该喜欢的事情**：允许不喜欢，不必为了做一个会生活的人而消费。

等待与期待的证据和反方，见[E03](03-now-or-later.md)。

<a id="pleasure-feedback"></a>

## 四、承认可能选错，也保留不尽兴的自由

### 最强的反对意见：人的欲望并不总可靠

是的。你可能想象错一种体验，可能受别人的兴奋影响，也可能在付款后才发现根本不喜欢。承认偏好有价值，不等于偏好信息永远准确。

但偏好会出错，也不能推出别人就应该替你规定所有值得的生活。可做的是增加信息、缩小不可逆代价，允许试过之后改变主意，而不是只接受那些有统一外部成绩的事情。

例如，你想尝试一项爱好，先参与一次而非立刻买整套；你想和朋友旅行，先讨论最在意的环节，而非默认照片里看起来开心就会适合自己；你想买一件物品，先确认真正愿意使用的场景，而非把“拥有后的我”想得无所不能。

这些提议不保证正确。**一次有限、知情的尝试，即使没得到预期快乐，也不必被追责成整个人生观失败。**

但“体验过就值得”也不能替失误开脱：有的经历不想再来，有的决定需要修正。接下来要分清，修正的是选择，还是追求快乐的资格。

### 一个会改变答案的反例

你本来想参加聚会，但今天真的累了。别人说：“你不是主张享受当下吗？来啊。”

如果你因此不得不去，享乐就成了另一种义务。这里的答案应当是拒绝：**当前的欲望也包含想清静、想不回应、想早早结束。**

这不是把“休息能提高效率”换个说法，而是不把任何特定刺激当成所有人的标准答案。

<a id="pleasure-not-quota"></a>

### 把快乐当正事，不是给快乐定业绩

还有一种压力，不是别人把你拉去聚会，而是你已经去了，也确实愿意去，却觉得自己没有资格不尽兴。

设想一个虚构的晚上：演出没有失约，喜欢的歌也唱了，你却只是觉得不错，没有想象中激动。第一句话是“我今晚没那么兴奋”；第二句话变成“花了这笔钱还不够开心，我是不是根本不会生活”。前一句描述经历，后一句开始审判经历它的人。

**允许快乐成为目的，与要求每次追求都交出足够的快乐，是两份不同的要求。** 支持一个目的，意味着愿意为它留资源、承认它在取舍中的分量；并不意味着结果必须服从计划。喜欢一个人，不等于每次相见都必须心潮澎湃；重视音乐，也不等于每首歌都欠你一次震动。

这与前面“不必赢过全部备选”又不同：那里比较的是甲与乙，这里即使没有任何备选，仍可能拿实际感受与“我应该有的感受”比赛。一个要求证明选得最好，另一个要求证明感觉得够好。拒绝前者，未必已经摆脱后者。

反对者可以追问：“如果不管有没有快乐，怎么还叫把快乐当目的？”我们并不说结果无关。持续不喜欢，当然会影响是否继续；明确的承诺没兑现，当然可以质疑。分歧在于，**反馈应当帮助修改选择，还是用来取消一个人追求快乐的资格。**

一次失望可能说明节目不合口味、期待不准确、当天状态不同，也可能暂时没有清楚的原因。它并不自动证明当初想去是可耻的，更不能让付款变成一张要求自己立刻兴奋的欠条。对结果认真，与对自己苛刻，不是同一个动作。

<a id="pleasure-happiness-study"></a>

#### 一项研究把“重视”和“担忧不足”分开了

Zerwas 等人在2024年发表的论文，使用五组北美成年样本，共1,815人，区分两种相关而不相同的倾向：把幸福视作重要目标，以及反复评判自己的幸福程度、担心不够幸福。这里沿用论文的幸福／快乐用语，不把它等同于本书主张的全部内容。[B40核读与数字](../docs/evidence/B40-happiness-concern.md)

在用于考察幸福感关联的三组样本中，后一倾向与较低幸福感有较一致的关联；前一倾向没有呈现一致方向，**不是所有单项结果都毫无关系**。它们也不是“健康的人”和“有问题的人”两类：一个人可以同时很重视快乐，又很担心自己不够快乐。

论文还考察了“对自己的感受再产生不满”：例如，回想一件积极事件，却因自己的反应不够理想而失望。作者称其为负面元情绪。它与事件本身令人失望不完全相同；上述虚构演出只是帮助理解区别，不是实验中的演出情境。

这里有三个不能省掉的限制。第一，这不是把人随机分到“追求快乐”与“不追求快乐”的干预实验，不能推出担忧造成不幸福。第二，部分样本有六个月随访，但分析没有预测幸福感的变化，不能改写成“越追求，半年后越不快乐”。第三，幸福感合成了生活满意度、心理幸福感与反向计分的抑郁症状，不是一天快乐了多少分钟，也不是临床诊断。

这篇研究给了我们一个值得分清的概念，**没有证明“耍起”会让人更幸福，也没有证明放弃追求就会更幸福**。它更不能成为新的指责：“你不开心，就是因为太想开心。”样本、量表、正面事件情境及无法确定因果的限制，都不支持这种归责。

<a id="pleasure-disappointment"></a>

#### 不要求尽兴，也不要求你把失望忍下去

回到那个晚上。“允许没那么开心”至少有三个需要分开的意思：

- **承认感受**：没那么喜欢，就不必表演喜欢。今晚普通，不会自动取消其中某段好听的歌。
- **保留判断**：票面承诺的内容没有出现、同行安排不合理，仍然可以追问。不能用“降低期待”替提供者免除责任。
- **修改愿望**：原来期待整场狂欢，后来发现更喜欢一小段共同合唱；也可能确认自己根本不喜欢现场。无需把两个答案都美化成成功。

这不是三步心态练习，而是三种不应互相代替的判断。认出自己的感受，不能自动解决外部问题；发现外部问题，也不要求证明自己毫无快乐，才有资格不满。

有人会提出更现实的反驳：“我一周只有这一晚可以支配，当然希望它特别好。”这份在意有真实的稀缺条件，不必先解释成个人想太多。若照料责任、工作安排或资源分配让可支配生活过少，给自己少打一次分，并不会凭空增加时间。能否争取条件，见[E06](06-real-life-constraints.md)；本节不能拿接纳情绪代替它。

所以我们也不提出“越不追求，越能快乐”作为反向诀窍。那仍在要求读者为了得到快乐，扮演不在乎快乐的人。你可以很期待、很投入、认真失望，甚至暂时仍然在意自己为什么不开心；不必再为没做到洒脱而自责。

如果困扰持续而明显影响生活，本节既不是诊断，也不是治疗建议，更不能拿“别考核快乐”代替适当支持。**我们争取的是快乐有位置，不是所有不快乐都必须由个人负责消除。**

<a id="这套主张也必须接受自己的检验"></a>

## 五、这套主张也必须接受自己的检验

如果本仓库让人每天挑卡、完成挑战、记录快乐分数，错过一天就自责，它就在把快乐重新做成任务。再好听的标语，也不能免除这个矛盾。

如果我们为了吸引注意力，只留下刺激口号，删掉成本和反例，那是在抢夺读者的判断权，而不是归还它。如果我们为了显得稳妥，最后只允许没有任何代价的微小舒适，也是在回避最初的问题：**有些快乐确实要付出一点，能不能仍然值得？**

我们的答案是能。但需要让读者看见自己正在决定什么，不伪造确定性，不用羞耻催人行动，也不以“越敢付出代价越会生活”制造新等级。

这不是完美人生的竞标书。它是一种有明确偏向、也愿意面对反对意见的生活主张。

### 如果还想继续追问

“快乐可以是目的”是否意味着“只有快乐是目的”？如果感到被喜欢与真的被喜欢能分开，我们想要哪一种？这个更难的问题见 [E11 · 如果快乐可以一键生成，我们还要真实生活吗？](11-pleasure-and-reality.md)。不需要先做一项活动，才有资格参与这个讨论。

下一次做选择时，别把自己的喜欢删到只剩一项需要被克服的冲动。它可以与责任、未来和别人一起被认真讨论。

**快乐不必成为一切的理由。但它应该被允许成为一个理由，而且有时候，这个理由已经足够。**
