# B42 · 线索触发的追求，与实际喜欢

**核读日期：2026-10-02。** 本记录区分动作指标、气味评价与价值判断；不是成瘾诊断、情绪干预或生活方式处方。

## 谁参加，实际做了什么

研究在日内瓦大学招募41名喜欢巧克力的参与者，后来排除5人：2人为技术问题，3人为使用精神类药物。分析样本36人、19名男性，平均年龄24.15岁、标准差3.05岁，未报告嗅觉问题。参与报酬为30瑞士法郎；这不是有代表性的消费者样本。

先进行两类学习：

1. 握压装置的动作可以触发巧克力气味。指标是超过个人最大握力50%阈值的握压次数，不是把每次握力大小相加，也不是花钱金额。
2. 不同图形与巧克力气味、无气味空气或基线情境建立联系。作者称为类似巴甫洛夫条件化的程序：任务中仍有按键成分，论文讨论它与纯粹被动线索学习的区别。

之后18人接受带社会评价的冷压压力程序，18人接受温水对照；前者8名男性、后者10名男性。**主文没有清楚交代随机分派到两组的办法，因此本书不称它为已确认的随机对照试验。** 文中明确的随机化还包括图形身份平衡、线索呈现顺序等，不能拿这些替代组别分配证据。

休息后先恢复有奖励的握压任务，再进入部分消退，最后进行18次无气味奖励的迁移测试。后者每种图形出现6次；测试中的动作不能解释成当场享受气味以后才增加动作，因为此时不再提供该奖励。

气味愉悦、熟悉、可食用感和强度在迁移测试后另行评价；不是一边握压一边连续记录喜欢。愉悦评分涉及巧克力气味与无气味空气，不是实际吃巧克力，更不是生活满意度。

## 动作结果：相对变化，不是总体更用力

印刷131页报告，两组在压力程序之前的平均握压频率已有差异：对照组平均多1.88次，p = .13。作者认为描述性差异较大，在压力处理后的组间检验中控制先前平均频率。**基线不显著不等于已经证明两组等同**，协变量处理也不自动消除一切组间差异。

印刷133页的迁移测试分析报告图形与组别的交互，F(2, 66) = 5.911，p < .01。与无奖励相关图形相比，奖励相关图形引出的握压次数增幅在压力组更大：t(34) = 2.32，p = .02，d = .77，95%置信区间[.09, 1.44]。这是作者报告值，未据原始数据重算。

总体组别主效应不显著（p > .1）。因此不能写成“压力让所有动作都增加”“压力组总共握得更多”，也不能把d改成提升77%。

作者另把每种图形下的动作频率减去基线图形频率：奖励相关图形的组间比较报告t(34) = 2.39、p = .03、d = 1.04、区间[.11, 1.47]；无奖励相关图形的组间比较p > .4。前述检验的参照不同，不应选取其中最大数字当作统一效应。

## 喜欢结果：没有检出组间差异，不是没有喜欢

气味评价部分报告，巧克力气味相对无气味空气更愉悦；但两组对巧克力气味的愉悦评分没有显著差异：t(34) = .19，p = .85。两组的“巧克力气味减去无气味空气”愉悦差异也未显著不同（p > .7）。

因此，这不是“想要巧克力的人其实讨厌巧克力”，也不是“压力让快乐消失”。有限结果是：相对动作指标的组间差异，没有伴随被检出的气味愉悦评分差异。

**一项显著、另一项不显著，不足以单独证明两种结果的差异显著。** 本书没有看到将两种量尺上的处理效应直接比较的检验或等效检验；p = .85不是两组完全相同的证明，也不等于“只有15%的可能存在差异”。

研究把线索触发的动作促进操作化为“wanting”，把气味愉悦评价操作化为“liking”。日常语言中的想要还可能包含预期、长期计划与明确目标，不能与这个动作指标无条件互换；喜欢也不等于事后认为值得。

## 压力操作、统计报告与机制边界

压力组报告了较高的压力与疼痛。但皮质醇前后变化的组间比较，正文给出t(34) = 2.20、p = .051、d = .75及区间[.05, 1.40]；不能抄成在.05门槛上显著。本组数字存在需进一步核解的报告疑点，不能自行选择一个数替换作者结果。正文也承认皮质醇反应比采用同类程序的部分研究弱。

气味比较的一些t检验自由度写为34，而总体分析样本为36人，主文没有为此逐项解释分母；部分效应量与区间的组合也值得复核。本书未取得数据，保留疑点，不自行补上缺失人数或重新宣布显著性。

压力处理、气味学习、动作和之后的主观评分来自特定实验安排。研究没有测量多巴胺、脑活动、购买行为、连续观看或游戏消费。作者关于神经机制的解释明确仍有推测部分，不能改写为本实验已经证明“多巴胺使你想买但不快乐”。

论文讨论成瘾、暴食、赌博的可能联系；这些不是本实验实际观察的临床结局。不能据此识别读者是否患病，也不给诱发压力、食物控制或戒断训练的操作建议。

## 与正文的关系

E10提出“想得到什么、正在经历的部分喜欢吗、知情后还认可吗”三个问题，阿澄、连载及提前看结局均为原创假想，不是研究任务或受试者访谈。

- 研究为分别测量追求与享受提供有限例子，不证明本书三问是一种有效量表。
- 喜欢追逐本身仍可能成立；不能拿“wanting”给不喜欢的读者贴标签，也不能用它抹掉喜欢的读者自述。
- E04已有“购买与使用的乐趣”“事前选择与事后不喜欢”的讨论，B28已有行为、评价与模型的区分；它们不是本研究的独立复现。
- “欲望不自动取得命令权”“研究不授予旁观者接管权”是本书的价值论证，不是实验统计结论。
- 不直接验证60张行动卡，不新增消费者风险分数，不据此推荐产品、时长、消费额或干预。
