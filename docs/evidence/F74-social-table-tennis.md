# F74 · 一张球台上的合作、对抗与轮换

**核读日期：2026-10-01。** 来源为Table Tennis England的社交玩法介绍，不是行为研究，也不是本书的活动试验。

## 读到了什么

[Games and competitions](https://www.tabletennisengland.co.uk/loop/games-and-competitions/)说明乒乓球可以有社交、合作或竞争目的；页面列出单／双打、自订规则、目标练习、绕台、淘汰、循环、梯级、续回合与胜者留台等玩法。已读取主文和这些文字说明，未核验每一项外链、嵌入图片或资源包；没有确定正文最初发表或最近修订日，页脚年份不能冒充文章日期。

本章采用的范围很窄：

- 页面允许共同同意并写下自订规则，不意味着它们就是正式竞赛规则。
- *Build the longest rally*以延续来回为目标，页面同时讨论合作与相互比较纪录。它不是对“合作一定比竞争快乐”的验证。
- *Beat the champ*让胜者留台迎接下一人，可按一分、三分中的多数或一局等不同长度安排；这些选项会影响轮候，但页面没有给出每种方式的实测等待或快乐数据。
- *Round Robins*让组内每两人相遇一次；页面对公平的称赞是组织性判断，不能替代对具体聚会的参与条件检查。

未把页面中的全部建议搬进正文。例如目标练习列举了包括玻璃物品在内的摆放物，绕台也涉及多人移动；本章没有将这些材料和空间要求核验为安全，不把“官方网页里有”当作适合读者照做的充分理由。也未转载其图片或执行页面的晒图宣传邀请。

## 六人六场，是本书的比较而非网页原例

本书设A—F六人、六场两人对局。甲安排为AB、AC、AD、AE、AF、AB，假设A每次获胜并留台；上场次数A6、B2、其余各1。乙安排为AB、CD、EF、AC、BE、DF，每人2次。双方都合计十二个人次。

乙不是完整循环赛。六人完整单循环有6×5÷2＝15场，每人5场；六场比较只说明两种已给定安排的出现次数。比赛时长、触球数、实力、观战愿望和乐趣都未设为相等，因此不能从次数推出谁实际获得更多快乐。

“比分公平不等于参与机会相同”“让分、让球、让场不同”“供球不是默认的免费劳动”为本书原创分析。来源提供不同组织方式，不为这些分析背书；我们没有招募参与者，没有活动记录或改进效果数据。
