## 本章采用的具体条款

| 问题 | ITTF条款 | 能支持什么 |
| --- | --- | --- |
| 回合与得分 | 2.5.1—2.5.4 | 回合中的球可能以重发球或得分结束；重发球不计分 |
| 发球 | 2.6.1—2.6.5 | 静止张开手掌、近垂直无旋转抛起至少16厘米、下落击球、可见性与位置；双打右半区到右半区 |
| 合法回球 | 2.7.1 | 球可以直接或碰球网装置后到达对方台区，不能一见擦网就判无效 |
| 普通双打次序 | 2.8.2 | 发球员、接发球员、发球员搭档、接发球员搭档，按此循环 |
| 双打次序例外 | 2.8.3 | 某方至少一人因身体残障使用轮椅时，发球、接发后该方任一人可回球；不得把普通交替规则写成毫无例外 |
| 重发球 | 2.9.1.1等 | 合法性等条件不能省略；擦网发球并不一律重发，更不是所有发球失误都有第二次机会 |
| 失序击球 | 2.10.1.12 | 普通双打中对手未依既定顺序击球可判己方得分；它不是高手代打的豁免 |
| 一局与一场 | 2.11.1、2.12.1 | 一局通常11分，10平后领先2分；一场为奇数局制 |
| 两分／一分换发球 | 2.13.3 | 通常每两分换；10平后或轮换发球法实施时每分换，不能只说“一直两分” |
| 发接配对 | 2.13.4—2.13.7 | 第一局、后续局与决胜局不能混成同一张图；决胜局一方先到5分有接发调整及换方位要求 |

## 原创例子怎样产生

C38采用A1/A2对B1/B2、首局（非决胜局）A1发给B1，且未启用轮换发球法的设定。球内次序为A1、B1、A2、B2循环；通常发接组为A1→B1、B1→A2、A2→B2、B2→A1，每组两分。

10比10共有20个已计分回合，下一组轮到A2→B2，此后改为每分换发球。重发球不增加已计入分数，因而不消耗这个算例里的分数位置。12比10可结束一局，11比10、12比11不能结束。这些是根据条款构造并核对的例子，不是比赛数据或获胜策略。

原创次序图不表示落点、跑动或站位，不是教练的移动建议；使用MIT许可，未复制官方图像。条款以本项目文字概述和署名链接呈现，没有把官方PDF、教学视频、TTE附加规程或标志重新许可为MIT。

## 不能据此推出

- 正式规则保证了每个人同等上场时间、触球数、尊重或快乐。
- 普通双打交替次序适用于所有轮椅参与情形，或本章已经说明所有无障碍适配。
- 掌握计分就能判断个人适宜强度、受伤风险、减重或健康收益。
- C38的比分与排场实例经过真实读者、教练或参与者试验。
