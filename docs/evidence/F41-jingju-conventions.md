# F41 京剧的舞台约定：项目描述不等于观看实录

- **核读日期**：2026-09-30（UTC+08:00）。
- **来源类型**：`heritage_description_and_nomination`。
- **对象**：京剧 / Peking opera，UNESCO 名录项目 **00418**，2010 年列入。
- **用途**：给现场章节中的象征性表达与有限布景提供具体艺术语境；不是“学习传统艺术能提高快乐”的证据。

中文项目简介与 UNESCO 名录说明的结构和描述高度对应。本书将它们用于语境与措辞对读，不把两者加申报文件说成三项独立实证研究。

## 2. 支持正文哪些事实

中文简介明确列出唱、念、做、打；名录说明介绍象征性动作、有限布景道具、音乐参与节奏与人物呈现。英文申报文件第 4 页谈到舞台可不实置房屋和墙壁，却使用桌椅杯碟等物件，并以演员技艺呈现环境。

这些材料支持“京剧不必以完整实物布景模拟环境”的有限说明。它们没有证明所有传统或当代制作都采用同一舞美，没有提供一段可以直接照做的身段教学，也没有对每个观众的理解过程进行测量。

本书没有把来源概述中的声腔、方言或脸谱描述推广为所有作品与流派的规则。申报文件还含当时的观众数量、传承实践及价值评价，本章没有拿这些数字解释当下热度，也不据名录地位宣布观众应该喜欢。

## 3. 原创解释与假想的边界

正文中“空地上的门”和“递一杯水”为本书原创说明，不对应《三岔口》或任何具体剧目的演出记录，也不声称是京剧标准程式。本文没有观看并核验某一场完整演出，不能冒认演员动作、现场节奏或观众反应。

实际空间、角色处境与表演过程的三层区分，有限可见物如何使未摆出的环境可感，以及共同约定可以让表达差异更易讨论，均为本书分析。它们不是 UNESCO 的心理学结论，也不证明“懂得越多越快乐”。

“知道结局不等于看完”“用功也可以只是享乐”属于正文的论证与价值主张，不是名录认证的效果。若读者想了解某部作品或某个动作，应进一步查相应版本、表演资料与专业解释，而非用本节假想替代。

## 4. 转载与访问边界

本书只作有限中文转述，未转载申报 PDF、中文简介全文、馆方照片、视频或现代演出影像；不把公开可读等同允许复制全部素材。英文材料由本书概述，不使用未经核对的第三方中文译本。

名录项目说明提供的是描述与申报语境，不是机构对本仓库“耍起”价值主张的背书。原始材料与本书推导分开，且不得加入行动卡的背景研究列表充当活动效果。
