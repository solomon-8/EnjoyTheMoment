# B19 核读：同一种酒，价格线索与喜欢评分

**改变的是告知价格，不是酒的物质组成或参与者实际付出的钱。研究不能证明多花钱使人更快乐，也不能替欺骗提供正当性。**

## 谁参加，尝到的是什么

分析样本20人，11名男性，年龄21–30岁，平均24.5岁。另有1人因事后报告不理解任务而被排除。正文列出的筛选条件包括右利手、健康、无相关疾病或酒精滥用史，且喜欢并至少偶尔饮用红酒；不能把这一小样本当作一般人群或酒类专家样本。

实际有三种Cabernet Sauvignon及中性溶液，却向参与者介绍为五种酒：

| 实际液体 | 告知价格 | 设计上的作用 |
| --- | --- | --- |
| 酒1 | 5美元或45美元 | 同一液体，两种价格线索；5美元为真实零售价 |
| 酒2 | 10美元或90美元 | 同一液体，两种价格线索；90美元为真实零售价 |
| 酒3 | 35美元 | 干扰条件，按真实零售价呈现 |
| 中性溶液 | 非酒类价格比较 | 配方模拟唾液的主要离子成分 |

每类条件16次，共96次。每次通过管路送入1毫升液体，价格提示与液体出现同步，呈现顺序随机；参与者按指令品尝、吞咽，酒类试次之间有中性液体清洗。正文称每种液体各取得4次喜欢评分、4次强度评分，使用六点量表。**大量重复试次不等于有96名独立参与者。**

参与者被告知研究品尝时间与风味，未被告知重复酒和价格操纵。正文说所有参与者事后报告能尝出五种酒，也说明未揭示欺骗内容以避免影响小型受试者池；这些都是作者报告，不能当作本书应向读者隐瞒信息的操作范本。

## 行为结果可以支持到哪里

对于两种重复呈现的酒，高价线索下的喜欢评分均更高，作者报告各自p < .001。强度评分没有发现类似效应。有限区别是：在这个设计下，喜欢评分随线索改变，不等于感觉“更浓”；未发现强度效应也不等于证明强度在所有条件下绝对不变。

研究还报告8周后的无价格线索品尝。作者称不再出现原先随价格增加的喜欢模式，并称酒之间没有报告的差异。不过，本次读到的正文没有单独交代随访实际样本数与完整统计，相关SI未取得，因此不补写“20人全部回来”，也不把这次随访称为独立复现或严格证明价签移除消除了全部差异。

该研究不是让人自费买酒，不比较长期满意度、家庭预算或真实购买行为；更不是检验普通食物盲测能否改善生活。作者也提出可能存在迎合实验者的报告倾向。不能只留下吸引眼球的价格反差，删掉任务、样本和测量性质。

## 脑图没有替“真快乐”签发证书

作者比较同一种酒在高低价条件下的BOLD信号，报告内侧眶额皮层等区域的变化，也分析信号与喜欢评分的关系，并据此提出期待可能参与体验评价的解释。

第1051页图2所示激活图阈值为p < .001、未校正，簇范围门槛为5个体素；其他图另有展示阈值。完整模型细节与附表未读，不能把展示的脑区图说成通过了本书重新审核的全脑多重比较校正。原始数据没有重分析，个体成像也不是对某个人是否真心喜欢的测谎。

价格期待通过哪些过程影响结果，是作者的机制解释，不是本章自己验证的神经定律。我们不把“未发现初级味觉区域相同效应”写成这些区域必然毫无变化，也不使用脑区名称为日常建议增加权威感。

## 原文内部不一致：保留，不替作者悄悄修正

- 图1的图注与画面把D标为强度评分、E标为无价格随访；第1051页正文先正确指向E，随后一处却把盲测指向D。本书按实际图示说明，并保留交叉引用不一致。
- 第1053页把5→45美元描述成900%加价，把90→10美元描述成900%降价。按起始价格计算，前者为上涨800%，后者约下降88.9%；价格倍数与涨跌幅不能混用。正文只采用清楚列出的绝对价格，不沿用这两处百分比。
- 价格与喜欢评分相关的文字、图4图注出现p < 0.000写法。这不能被当作合理的精确p值；本书不擅自猜测其应改成什么，也不使用该数值作论据。

这些问题不自动推翻全部结果，但意味着不应把每个印刷数值都当作已独立复核的数据。

## 本书的使用与不使用

第2章据此讨论价格线索、对象本身与喜欢评分的区别。分开对象接触、情境理解、评价选择的三层工具，是本书分析，不是论文的已验证模型。

“受情境影响不自动等于虚假”“曾经快乐不等于认可欺骗”“盲测回答的范围取决于拿掉了什么”，是本书的论证与价值主张。甜点、饮料店、灯光和共同听歌均为假想例子，不冒充该研究的实验条件、作者经历或实测效果。

本书不由这项研究推出：

- 越贵越快乐、便宜货一定划算或昂贵品一定是虚荣；
- 信息不真实也没关系，只要当时产生好感；
- 所有感官、所有文化、所有年龄都有相同价格效应；
- 提高价格或期待即可稳定提升福祉；
- 任何饮酒、盲品练习或J007–J012行动已获得验证。

材料涉及酒，是因为原实验使用酒，不是邀请读者以饮酒重做实验。本书没有新增饮用动作或剂量建议。
