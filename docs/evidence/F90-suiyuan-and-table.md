# F90 · 《随园食单》：好菜、宴席与不强迫的客人

<a id="f90-ear-eye"></a>
## 耳餐、目食：批评的并非感官本身

“戒耳餐”把问题落在食材声名和显示敬客的意图上：贵重、量多或众人夸赞，不足以保证口中所得。作者用宴客故事与食材比较来讽刺这一点；本书没有核实所述太守宴席确曾发生，也不沿用他对某些食材的高低排名。

“戒目食”针对盘碗繁多、菜数成了丰盛的外观，同时担心制作心力与多人配合。文中厨者一天能做好多少味，是作者判断，**不是可移植的厨房产能数据**。不能把“耳餐”解释为听觉不参与风味，把“目食”解释为颜色、摆盘和视觉享受全部虚假；作者用的是特定批评概念。

“戒混浊”还明确将混浊与浓厚分开。这里可以看见他也在分辨具体口中感受，而不是只按价格作判断。但其工艺解释仍属于历史食论，不用于判定当代食物品质或安全。

<a id="f90-hotpot"></a>
## 火锅与强让：把相邻两则放在一起读

“戒火锅”讨论冬日宴客、席前喧腾及把有不同火候要求的菜持续同样加热的问题。作者对“菜冷奈何”的反问，把好菜与客人应当迅速吃尽联系起来。本书保留这个可反对的论点，而不将他概括成反对所有现代火锅，更不据此比较现代锅具、地区吃法、燃料或健康影响。

其后“戒强让”主张客人按自身偏好取用，反对主人把菜夹堆客前乃至硬塞入口。这是该文本对待客的价值判断，不是证实某种现代同意制度已经存在。正文把它与前一节放在一起，提出关于最佳入口时刻和共同用餐节奏的追问；这个追问属于本书，不伪称作者已给出相同答案。

不立即吃完可能与谈话、等待或食欲有关，是本书列出的可能性，不是对书中人物动机的实证诊断。“一项风味状态变差，但整顿饭仍可值得”，也不是袁枚或咖啡实验已经验证的普遍结论。

<a id="f90-limits"></a>
## 不把可借用的观点变成整套权威

序文承认不能强求天下人同嗜，却仍试图推己及物、提出判断。不能把这点简化成“作者认为怎么吃都一样”，也不能把所有当代偏好都放回古代等级里审判。

“戒苟且”对厨者有身份贬抑，以赏罚和监督组织制作；“戒强让”等段落也包含针对女性及其他群体的轻蔑修辞。本书不同意这些身份判断，不照搬辱骂、性暴力类比或主仆式管理。反对强迫客人吃，不自动证明整本书平等对待所有参与者。

“戒落套”批评固定名目的排场，同时承认自家某些寿筵婚席也难免采用类似安排。作者的批评、叙事中的自我辩护、实际宴席历史须分开；本书没有查其家庭账册、厨者记述或同期独立材料。

## 本书怎么用

C14的朋友聊天、想及时尝菜、做菜者不愿待命，是原创假想。三种处理各有损失，不是经验证最优的聚餐方法；制作投入值得尊重，不等于可以要求特定感受或赞美，是本书立场。

不采用书中的屠宰、火候、保存、劝酒或其他操作作为现代指导。不从转录词句或扫描色泽推断熟度、卫生、过敏适用性，也不提供复热或饮用温度建议。F05感官科普、F25供应商结构手册、B29咖啡实验与这份食论各有任务，不能混成互相重复验证的四项研究。
