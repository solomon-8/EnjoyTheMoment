# B18 核读：想要怎样的一生，与怎样的下一小时

**这组研究询问偏好，没有把人安排进两种人生。回答“更想要哪一种快乐”，不等于已经测到哪种选择真的使人更快乐。**

## 实际版本与阅读范围

Cassie Mogilner、Michael I. Norton，*Preferences for experienced versus remembered happiness*，[DOI: 10.1080/17439760.2018.1460688](https://doi.org/10.1080/17439760.2018.1460688)。

2026-09-30 读取[哈佛商学院服务器托管的 PDF](https://www.hbs.edu/ris/Publication%20Files/Mogilner%20Norton%202018_cb9d78a7-bbfd-47dd-9995-c8f582abd99e.pdf)，共9页：一页封面，加正文及参考文献8页。封面标示2018年4月5日在线发表，正文为提前在线排版，未带后来的连续期刊页码。

[Crossref记录](https://api.crossref.org/works/10.1080/17439760.2018.1460688)的标题、作者、DOI与在线日期一致，另列2019年3月4日印刷发表、The Journal of Positive Psychology，14(2)，244–251。因此2018与2019不是两项研究，也不能把所读版本说成已与最终卷期版逐字比对。

本次通读摘要、引言、五项研究的方法与结果、总讨论及参考文献；目视核对封面、正文第2–3页的研究1人数和图1、第5页春假设计与图3、第6页跨国结果与图4。出版社正文入口返回403；未取得原始数据，未完成复现或勘误核验。Crossref没有列出更新关系，不证明没有勘误。

## 先说明他们到底问了什么

核心问题强制参与者在两项描述中选一项：在那段时间里逐时感到快乐，或结束后回想那段时间感到快乐。不同研究改变所指时间、回忆描述或日历呈现。

这不是比较两个实际活动的随机效果试验，也不是逐分钟记录快乐后再考察回忆准确度。论文引言转述的疼痛、旅行记忆与“峰终”研究，不是本文新增的五项研究；本书没有从转引段落补写那些原始实验的方法或效果。

作者承认两种快乐不必互相排斥。但问卷要求二选一，因而测到的是这套描述和约束下的相对偏好，不能直接推成现实中的全部选择。

## 五项研究与样本

| 研究 | 样本 | 核心操作与实际测量 |
| --- | --- | --- |
| 1 | 美国MTurk参与者1,145人 | 随机回答下一小时、今天、今年或一生中的一种时间范围；选择快乐类型，并说明理由 |
| 2 | 美国MTurk参与者960人 | 小时或一生；回忆选项分别描述为回想时感到快乐、认为那段快乐、记得那段快乐 |
| 3 | 美国MTurk参与者313人 | 下一小时、一生最后一年里的一个小时、或一生；检验时间范围与等待回忆开始的时间是否可区分 |
| 4 | 美国大学生185人 | 同一个即将到来的一周春假，分别在年历、月历上突出显示，或不展示日历；问假期快乐偏好与已有计划 |
| 5 | 四国网络面板748名成年人 | 英格兰203、荷兰197、中国152、日本196；回答小时或一生的偏好 |

合计3,351名参与者，是五项不同研究样本之和，不是同一群人的长期随访。第五项原计划每国200人，作者称排除误纳的未成年人后保留748人；各国数量不等，也不是各国居民的概率代表样本。

## 研究1：不要把组间差别写成同一个人的自相矛盾

正文报告：

- 一生组225 / 284人选择过程中的快乐，约79%。
- 下一小时组140 / 285，约49%。
- 今天组137 / 286，约48%。
- 今年组196 / 290，按人数算约68%；正文文字却写65%，图1标68%。本次目视确认不一致，保留人数与图，不自行猜测正确原始数据；第10章没有使用今年组百分比作论据。

研究1的时间范围总体效应报告 p < .001。小时与今天组对半比例的比较分别为 p = .81、p = .52；不能把“接近一半”改成大多数人在小时或一天里偏爱回忆，更不能从不显著推出两种偏好完全等量。

每个人只被随机分配到一个时间范围，没有让同一人先选择整个人生、再选择每个小时。作者讨论生活哲学与逐时安排可能不一致，是从结果延伸的推测；本书不能宣称观察到了这些参与者实际怎样过完人生。

## 研究2–3：措辞与时间位置不是完全消失的因素

研究2的三种回忆措辞总体差异未显著（p = .20），不能说措辞永远无关。小时组的两个版本分别59%与58%选择过程快乐，对50%的比较都为 p = .06；它们不是“已经证明大多数”的结果。小时与一生之间，其中一个措辞版本的组间比较为 p = .05，应保留这个边界，而非都写成同样强的证据。

研究3中，一生组83 / 106选择过程快乐，下一小时54 / 103，人生最后一年中的一小时56 / 104。两种“一小时”的回答比较接近；它支持时间范围不只是等待长短的一个代称，但仍是想象情境，不是测量参与者真正面对生命最后一年时会怎么选。所读文本有一处 p = 49 的印刷写法，本书不擅自修正或依赖该数值。

## 研究4：日历改变了回答，不等于改变了实际假期

所有人面对的仍是一个星期，没有实际增加或减少假期：

| 呈现 | 选择过程快乐的人数 | 应怎样理解 |
| --- | --- | --- |
| 年历中的一周，视觉上较短 | 37 / 62，约60% | 不是多数选择回忆；与对半相比未显著 |
| 月历中的一周，视觉上较长 | 47 / 61，约77% | 与年历组偏好有差异 |
| 无日历 | 46 / 62，约74% | 无日历本身并未使人更偏爱回忆 |

年历与月历两组比较 χ²(1, N = 123) = 4.29，p = .04，Cramér’s V = .19，95% CI [.02, .36]。这个检验不是三组同时比较，也不证明每位参与者都把一周主观感受成同样长短；所读方法没有报告另一次独立的主观时长操纵检验。

作者还分析已有春假计划：偏好过程快乐者更常计划海滩旅行，偏好回忆快乐者更常计划志愿工作。但这不是随机分配实际旅行类型。志愿工作只有3人与1人的计数，不能推出做志愿工作不快乐、海滩必然更快乐，或两类人拥有不同道德品质。没有报告假期中的实际体验或返程后结果。

## 研究5：不能拿四国样本给“东西方”排性格

英格兰与荷兰合并后，一生组130 / 199选择过程快乐；小时组76 / 201选择过程快乐，另外125人选择回忆快乐。中国与日本合并后，一生组140 / 172、小时组148 / 176选择过程快乐。

后两国合并的时间范围效应未显著（p = .51）；各国分别也未显著（中国p = .95，日本p = .35）。不显著不是没有任何差别的证明。不能只因部分国家显著、另一些不显著，就宣布国家之间效应差别已被正式交互检验证实；所读结果段没有报告这个跨组合并交互检验。

作者用宗教传统、正念观念与工作伦理解释可能的差异，但本研究没有直接操纵或系统测量这些机制。所读方法没有充分交代各语言的翻译等值性审核，便利网络样本也不能代表所有居民。国别标签、个体信仰、语言理解和生活条件不能被混成一种“民族性格”。

## 本章采用的判断与保留的未知

有限结论是：在这些强制选择的问卷里，时间范围和呈现方式与快乐偏好有关，但模式并非所有所测国家都一样。它让我们认真区分“人生愿望”和“眼前选择所优先保留的东西”，而没有替哪一种人生裁定胜负。

第10章的三个问题——过程如何、现在怎样回想、下次是否还选——是本书分析，不是论文验证的诊断表。关于难忘体验、共同回忆、讲述与分享的虚构场景，也是本书自己的论证。

本书不从这项研究推出：

- 每段时间必须只选体验或回忆之一；
- 重视回忆就是虚荣、受骗或不懂享乐；
- 只要看月历就更幸福，或为一生选出的偏好应机械统治每小时；
- 好结尾足以补偿糟糕过程，或某个收尾仪式能改善情绪；
- J055–J060的动作、时长、预算及效果获得研究验证。

即使某人确实更重视过程，也可以自愿选择费劲、强烈、值得记住的体验。取舍由本人承担，不由问卷里的多数票决定。
