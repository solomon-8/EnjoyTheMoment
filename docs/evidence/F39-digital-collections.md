# F39 数字收藏：保存指导与本书的选择问题

- **核读日期**：2026-09-30（UTC+08:00）。
- **来源类型**：`personal_digital_archiving_guidance`。
- **作者机构**：Library of Congress，美国国会图书馆。
- **主材料**：[Keeping Personal Digital Photographs 网页](https://www.digitalpreservation.gov/personalarchiving/photos.html)及其所链[单页 PDF](https://www.digitalpreservation.gov/personalarchiving/documents/PA_photo.pdf)，两者均 HTTP 200。
- **范围**：网页正文与 PDF 全页的四组 Archiving Tips；PDF 217,276 字节，提取文本后实际渲染核看标题、四组条目与末尾建议。

## 1. 来源实际建议什么

指南按四组组织：

1. 识别相机、电脑、可移动介质及网上的照片在哪里。
2. 选择重要照片，可以少也可以多；重要照片有多个版本时，保存质量最高的版本。
3. 使用描述性文件名、人物和主题标签，建立文件夹结构，并对目录结构与照片写简短说明。
4. 至少制作两份副本，放在不同介质和实际可行的不同地点；把照片清单副本与重要文件妥善保管，定期检查可读性和更新介质副本。

网页与 PDF 的这四组条目基本对应。PDF 另有将重要照片放入关联分组的导语；本书没有把排版不同说成两项独立研究。

来源页正文没有显示可核实的发布或更新日期；本书不从版权页脚、下载时间或文件属性推定其首次发布日期。它包含 DVDs、CDs、portable hard drives、thumb drives、Internet storage 等介质举例，不是核验过的当前产品比较。

## 2. 时间建议保留为来源内容，不泛化设备寿命

来源明确建议至少每年检查一次能否读取，每五年或必要时创建新介质副本。两条不互相替代，也不表示五年以内不会损坏、五年到期必然失效，或只要按时复制就可确保长期保存。

正文采用分开存放与检查可读性的方向，没有输出统一硬件更换周期、存储服务排名、介质寿命或云服务恢复保证。没有读取厂商当前服务条款、验证账户设置、实际迁移用户文件，或执行恢复测试。

## 3. 需要明确分开的本书推导

以下不是国会图书馆原文提出的收藏标准：

- **技术质量不等于版本意义**：有批注的副本可能承载另一层内容，不能只凭像素较少便决定删除。原图、裁切件、批注件的具体例子为原创假想，不是对某个实际相册的检测。
- **同名不等于同对象**：两件版画对应文件若用相同文件名覆盖，会丢失原本保留的差异。这是本书虚构文件操作情形，没有在用户文件上执行覆盖。
- **分开位置须看共同故障条件**：同一介质上的两个文件夹，并未对整块介质不可用增加第二个保存位置。这不预测设备故障概率，也不等于任何不同位置的副本就有完整恢复能力。
- **检查要触及内容**：从另一个位置打开重要文件并核对内容，是本书提出的检查例子，不是完整存储、数字取证或灾难恢复规范。
- **私人来源与分享范围分开**：本书不把照片含有人名和标签视为适合公开，也不把收藏链接等同下载、发布或改编许可。没有给出地区性的法律判断。

这些推导帮助读者保留回到旧喜欢的条件，而不是要求把全部收藏整理完才能开始欣赏。没有来源证明归档、命名、分类或增加副本会带来特定快乐增益，亦没有读者实验或用户效果记录。
