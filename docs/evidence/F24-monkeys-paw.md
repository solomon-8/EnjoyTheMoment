# F24 《猴爪》：文本写了什么，读者又补了什么

**来源类型：文学作品数字文本。不是作者访谈、观众反应研究或恐怖体验安全依据。**

## 本章如何定位例子

不含结局的部分只描述第一节开头：室外冷湿，室内有窗帘与炉火，父子下棋；父亲冒险的棋路及试图转移注意的谈话均可回到原文核对。

“安全小空间”“熟悉生活被改变”是本书的解释，不是原文自带的心理效应指标。也不把棋局认作作者已经承认的唯一象征体系。

## 第一、二节：愿望、消息与数字

父亲许愿二百英镑；公司使者后来说到儿子的机器事故与死亡，并提出同样数额的款项。使者进屋之前在门口犹豫，入内后又逐步说明来意。

本书把这种次序分析为信息递进，而非一开始完全无信息。这个分析可讨论，但不是关于读者每一秒真实反应的实测。

文本让人物在巧合与愿望应验之间争论，不提供独立的超自然因果证明。不能把某位人物的确信直接当成叙述者已证实的世界规则。

## 第三节：门外的空白

第二个愿望是让儿子复生。之后有等待和敲门，母亲想开门，父亲寻找猴爪。母亲够不到门闩、移动椅子，父亲终于找到猴爪并说出第三个愿望；敲门停止，门外道路安静无人。

正文没有直接写出第三个愿望的具体措辞，也没有展示门外来者的形貌。读者可以形成强烈推断，但应把“我据此猜测”与“原文描写了”分开。

本书没有补写血腥形象，没有借某个改编版本填满原作空白。母亲与父亲对敲门的不同理解、开门与寻找的动作竞速，是本章解释悬念的依据，不是作者意图的最终裁决。
