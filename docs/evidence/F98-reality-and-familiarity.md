# F98 · 不愿离开熟悉生活，能解释“我不要体验机器”吗？

核读日期：2026-10-05（UTC+08:00）。不是论文发表日期。

- **原作**：Felipe De Brigard，*If you like it, does it matter if it’s real?*，*Philosophical Psychology*，23(1)，2010，43–57。DOI：10.1080/09515080903532290。文件封面标明线上发表日期为2010-02-08。

- **未读、未验**：未取得个体原始答卷或重跑统计；未独立核读本文所引全部研究、后续复现或系统综述。本文内的诺齐克引文仍是转引，不能据此宣称直接核读了诺齐克1974或1989年的原书。

## 原文做了哪些比较

| 位置 | 设计或结果 | 读取时要保留什么 |
| --- | --- | --- |
| 45页 | 作者提到一次课堂非正式调查，讨论拒绝接入的理由 | 不与下列正式报告的72人混成同一实验，不用课堂百分比概括公众 |
| 46—48页 | 72名UNC本科生、无先前哲学学习经历，随机分为三组，每组24人；每人只读一个“已经接入”的故事 | 三组改变外部生活信息，不是现实／机器两种起点的随机对照 |

| 56页注3、注5 | 注3报告初次三组的χ²(2, N=72)=10.6，p=.005；注5说明后续还改变了回答选项的措辞 | 该检验不是初次中性组与后续中性样本的差异检验；未将统计量自行重算为原始数据 |

论文的初次中性版本未说明外部生活好坏，也没有明确保证其他条件与现有生活相同。不能把它简写成“只改变真假，其他全一样”。

<a id="reality-study-followup"></a>
## 后续比较为什么不能单独识别现状倾向

第二中性版本不只增加“外面生活完全不同”的说明，也将回答选项从“回到现实”（Go back to reality）改为“断开”（Disconnect）。作者在注5说，前一种表述可能因为“现实”的正面意味而影响回答。

因此两次报告的46%与59%留下，来自不同样本、不同生活说明和不同选项措辞。不能写成同一批人改变了主意，也不能把差额全部归于留恋现状。本文没有报告这两个中性样本之间的专门显著性检验；没有检验不等于已经证明无差异。文中也没有交代两次招募是否有人重叠，因此不将72与80相加称为152名独立参与者。

50—53页用现状倾向与前景理论提出解释。文中的价值函数示意不是从这批答卷拟合出的个人参数，不能用来计算某位读者该离开或保留什么生活。该解释值得考虑，不等于所有竞争解释已被排除。

## 研究、作者解释与本书判断分开

作者主要挑战的是：不愿接入的直觉，是否能直接证明人们因重视现实而拒绝机器。他也讨论快乐、现实、熟悉生活可能共同进入判断，并在54页反对把受现状倾向影响的判断一概视为不理性。不能把本文概括成“真实不重要”“人只要快乐”或“保守选择都是偏差”。

本文54页关于婴儿与婚姻的例子含有本书不沿用的表述与判断；不据它们给残障、亲密关系或照护决定作建议。记下作者对理性标签的反问，不等于接受其全部论证。

[E11](../../essays/11-pleasure-and-reality.md#pleasure-familiarity)进一步区分：

- 作出某个选择，与识别选择的原因；
- 有一种可能机制，与已经单独检验该机制；
- 解释为什么不想改变，与判断应不应该改变；
- 珍惜熟悉的经历，与事实上的关系或行动确曾发生。

最后一组区分及本书对私人生活的回应是本项目的分析，不是问卷测量结果。论文不能裁决某种人生客观更好，也不能把模拟生活等同现实中的游戏、小说或数字社交。
