## 样本与任务：66人不等于66位现场舞者

英文线上机会招募，66人，17—63岁，平均30.14岁。包含17岁参与者，不能写成“全部成年人”。参与者来自多个地区，不等于经过跨文化代表性抽样。

每人以随机顺序听50段合成鼓段，分别对想动程度与愉悦程度作1—5分自评。两小节4/4材料循环四次，速度120拍/分钟，每段16秒；鼓声包括底鼓、军鼓、踩镲，踩镲维持八分音符。没有微时差，不能用这项研究解释真人演奏的微小松紧。

34段由funk曲目转录，2段来自GarageBand模板，14段为扩展切分两端、控制起音数量而构造。它们都被合成为实验片段；“曲目转录组”不是直接播放原录音，36段敏感性分析也不是36首现场实录。

正式评分前有两段非实验示例并调整舒适音量。设备品质为自报，不是随机分派；设备分组未显著不等于设备无影响。没有记录实际运动、同步准确率、生理信号或夜店中的共同体验。

音乐背景分析排除9位训练年数不落在两端类别者，余57人：训练超过8年22人，少于4年35人。常听groove的39人、非该组18人；舞蹈背景组37人、非该组20人。分组来自训练年数和自报习惯，不是随机培训，因此组间评分差异不证明跳舞训练使人更快乐。并非每个分析都用57人；也不能从表5的自由度49直接推断只分析了50人。

## 研究的“切分”不是所有复杂度

论文用针对多声部鼓型的切分指数，并另测联合音频熵。前者考虑事件与节拍位置及乐器关系，后者由音频波形数据计算；不能把它们都译成同一种“刺激量”，也不能把切分、速度、响度、起音密度、微时差互换。

修正版S1表中，低、中、高切分组分别包含17、17、16个刺激；指数范围分别为0—22、23—46、49—81。分母是50段刺激，不是把66人分成三组。这里的“中等”取决于材料和指数，不是音乐世界的自然边界。

修正版S2的Box 1印出`S = N − Ndi + I`，但其后具体算例文字按后一个较强位置减前一个较弱位置，加乐器权重，例如`−1 − (−3) + 5 = 7`。**本书保留公式与算例方向的表述疑点，不自行裁定并重算刺激指数。** 正文章节的八格四起音示意不使用该公式，不模仿研究的多声部分数，也不声称属于实验三个等级之一。

S4另比较单声部与多声部指数，所报多声部回归数值与主文预测贡献分析并不完全相同；本书不拼成同一张“复现结果表”。未核验代码与底层数据，不将差异自行归因于某一计算步骤。

## 主结果：曲线形状不是快乐增加百分比

论文先对个人评分作线性、二次拟合，再比较调整后R²；另对50段刺激的平均评分作预测贡献分析，并按切分三档考察背景与评分类型。**个人、刺激与背景子样本是不同分析单位。**

主文对刺激均值的预测贡献分析报告R²：想动 .3474，愉悦 .4267。它们不是“快乐提升34.74%／42.67%”，也不是参与者获益比例。表4愉悦行注释印作`R² = 4267`，与正文`.4267`不一致；这里按正文转述并保留疑点，不无声修补原表。

表3中，切分的二次模型优于线性模型，平均调整后R²差 .09，p < .001；联合音频熵差 .01，p = .020，未达到该表校正后的p < .01阈值。不能写成所有“复杂度”指标都支持同一倒U形。

表5的以下差值来自配对对比，阈值校正为p < .005：

| 对比方向 | 想动评分差 | 愉悦评分差 |
| --- | --- | --- |
| 低减中 | −.31，p < .001 | −.32，p < .001 |
| 低减高 | .25，p = .001 | .07，p = .441 |
| 中减高 | .55，p < .001 | .39，p < .001 |

两项的中组均较高，但低、高之间的模式不完全相同。**一项显著、另一项不显著，不足以证明两项彼此差异显著。** 高切分处“想动减愉悦”为−.14，p = .020，也未达到上述校正阈值。不把这些分数差换算成跳舞分钟数、幸福增幅或听者个体的最优点。

## 去掉专门构造片段后，结果没有原来那么整齐

S5仅保留34段曲目转录及2段软件模板，共36个刺激，排除14段研究者构造片段。它没有把所有“真实世界因素”都控制掉，软件模板也不等于真实演出。

刺激平均评分的二次模型中：

- 想动：调整后R² = .0448，整体F(2,33) = 1.82，p = .178，不显著。
- 愉悦：调整后R² = .2133，整体F(2,33) = 5.74，p = .007。

S5对个人二次项的检验也只在愉悦上显著，想动不显著。其分析段称采用单尾检验，但所报想动t(65) = −.570、p = .571的尾部口径存在疑点；本书不改算成自己的p值，正文只采用它未显著的保守判断。

作者承认构造刺激的人工性与不熟悉感可能影响结果。本书因此不把全体50段上的趋势，直接提升为排除了材料选择影响的稳健普遍规律；也不因删减分析的一项不显著，就声称全研究已被推翻。

S6关于曲线顶点的背景比较又使用筛选后的48人（想动）与45人（愉悦），只纳入二次模型调整后R²更优者；不是全部66人的最优值比较。未显著的组间差异不等于不同背景听者偏好完全相同。

## 重复为什么仍有吸引力：解释，不是已测机制

作者讨论一个难题：循环被听熟后，切分不再提供同样的新信息，为什么仍可能有groove？他们提出主动身体参与、节拍实现等解释，属于讨论中的推测。**本实验没有实际运动记录，不能直接证实身体参与机制。** 最想动也不意味着同步最准确；没有脑成像结果可供本书引用。

[C37](../../book/37-nightlife.md#nightlife-repeat-participation)据此区分“知道下一拍”和“愿意亲自经过下一拍”。这是本书的解释与价值延伸，不是论文验证了“耍起”，也不是不喜欢重复的人需要纠正。

不推荐固定速度、切分分数、音量、消费金额或跳舞时长；不验证任何行动卡，不保证现场安全、文化普适性、治疗效果或长期幸福。本条增加的是对具体音乐结构与研究边界的理解，不是拿背景实验给私人愿望发许可证。
