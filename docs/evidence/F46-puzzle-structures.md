## 3. 道路例子的独立核对

本书自行给出四地点完全图，六边为AB、AC、BC、AD、BD、CD。每点度数3，总共四个奇数度点。正文的一进一出配对解释，足以推出本例没有每边恰好一次的路线；它不是一般充分性的完整证明。

删去AD后，A、D度数2，B、C度数3。见证路线 **B—A—C—B—D—C** 依次使用BA、AC、CB、BD、DC，恰好一次用完五条边，起终点分别为B、C。

[有限算例程序](../../tools/puzzle_examples.py)从每个有边顶点出发，递归尝试所有尚未用过的相邻边。测试同时枚举四个固定顶点上的63个非空简单图，把完整搜索结果与“有边部分连通且奇数度点为0或2”作比较；另检验两个不连通三角形的反例。这个有限检查不能代替对所有图的证明。

原创图中A在上方，B、C在左下、右下，D在三角形内部。六条线只在标记的顶点相接，画面长度不是道路距离；程序检查SVG的端点与边集合。没有历史地图、真实场馆或出行安全含义。

## 4. 灯题、改题与完整可达集合

五位0/1状态，起点00000，0灭1亮。原规则只能翻转位置1—2、2—3、3—4、4—5中的一对，首尾不相邻。状态空间共32种。

- 一次操作使亮灯数增加2、减少2或不变，因此总亮灯数的奇偶性保持。起点为偶数，10000为奇数，不可达。
- **00000 → 11000 → 10100 → 10010 → 10001** 分别由1—2、2—3、3—4、4—5四次翻转得到。允许访问相同状态，不要求最短；本书没有据此提出最短步骤结论。
- 完整广度优先搜索得到16个可达状态，恰为亮灯数偶数的所有状态。这里的“恰为”由有限枚举核验，并不从必要条件直接跳得。
- 取消2—3后，操作只剩1—2、3—4、4—5。左右两部分各自保持偶数亮灯，目标10100虽然总体为偶数，却在两部分分别为奇数，因而不可达。可达状态恰有8个；每盏灯仍可被某种操作翻转，不能解释成“某盏被冻结”。

程序测试全部32个状态的合法转移、翻转两次还原、完整可达集合、改题的分区性质，并拒绝非法索引或只翻一盏的不同规则。它没有接入真实灯具，不证明人类求解难度、愉悦或智力训练效果。
