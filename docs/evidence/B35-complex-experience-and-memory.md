## 样本与操纵：没有成功改善结尾

40名Tilburg大学一年级学生，16男24女，19—30岁，平均21.7岁、标准差2.8。随机各20人观看XSTNCE的13分14秒普通版或14分26秒版本，后者延长并加剧关键负面场景，其余相同。不是把结束专门改成更快乐的一组。

作者没有检出预期的版本评分差异，因此合并40人继续分析。后续回归不能借用前面的随机分组，被描述为“操纵峰终成功导致回忆改善”；它主要比较不同回忆指标与整体评价的关系。

材料来自一部VR影片，包含不同情绪段落。没有随机比较一组“同质经历”和一组“异质经历”，所以异质性是对结果的解释之一，不是已经被单独证明的原因。

## 测量顺序：所谓过程，也是后来重建的

1. 看完后复述。实验者按“and then”等连接词切分叙述，不是预先给所有人同一套段落。
2. 先给整体体验的正负情绪（valence）和唤醒（arousal）各打1—9分。
3. 再为每个回忆段落给出同样两类评分。
4. 与实验者重看影片，确认各段起止时间，据此重建情绪时间曲线。
5. 约一周后返回，实际平均间隔8.70天、标准差3.25，再评整体，并选出最难忘时刻（MMM）和评分。

因此，没有观看时实时连续评分，也没有本研究的生理连续测量。逐段重建在整体评分之后，之后又重看/加工了影片；这些过程都会影响“过程影响回忆”的解释。作者在局限部分承认，段内变化可能被整段分数遮住。

平均每人11.03段、标准差2.54，范围7—18段；段时长均值57.25秒，范围1—373秒。peak是最正面段，trough是最负面段，end是最后一段的评分，不是“最后一秒”。峰终指标是峰与末段的平均。

表2把average写成跨段平均，但没有在该定义中说明按时长还是等权加权的具体实现；本次没有代码与数据核验，不能把它说成每秒快乐的积分。唤醒量尺从平静到激动，不能直接当喜欢程度或“刺激越多越幸福”。

MMM在后一次随访才选。用它解释较早的即时总评属于同一样本的关联分析，不是提前预知这个人刚看完会怎样评分。

## 主要结果：看指标，也看校正门槛

作者每次用一个预测变量作普通最小二乘回归，比较样本内R²。它是解释变异的比例，不是因果效应大小、控制其他变量后的独立贡献或样本外预测准确率。

正负评价有9个候选指标，Bonferroni校正后α = .006；唤醒有7个，α = .007。不能用统一.05门槛重新挑出更多“成功结果”。

以下摘出表3中能改变正文解释的几行，均为原文报告，不是重新分析：

| 正负评价指标 | 较快总评：R² / p | 稍后总评：R² / p |
| --- | --- | --- |
| 最正面段peak | .419 / < .001 | .242 / .001 |
| 最后一段end | .000 / .946 | .136 / .019 |
| 峰终平均peak-end | .099 / .049 | .291 / < .001 |
| 跨段平均average | .293 / < .001 | .462 / < .001 |
| 最难忘时刻MMM | .043 / .210 | .362 / < .001 |

据校正门槛，即时峰终平均的p = .049不能称为显著，稍后end的p = .019也不显著。即时正负总评由peak解释的比例最高；稍后由average最高。峰终平均在稍后仍有显著关联，R²还从.099升到.291，不能写成“时间一过峰终就失去作用”。

表5的唤醒结果也需要不同表述：

| 唤醒指标 | 较快总评R² | 稍后总评R² |
| --- | --- | --- |
| peak | .216 | .436 |
| end | .242 | .347 |
| peak-end | .265 | .442 |
| average | .472 | .443 |
| MMM | .410 | .271 |

这些所列模型的p值都跨过对应.007门槛，但不表示模型之间差异显著。尤其稍后average的.443与peak-end的.442只差0.1个百分点；原文没有提供据此证明average优于peak-end的模型差异检验。我们不沿用“平均值普遍更好”的强表述。

整体valence均值从5.875到5.075，而arousal从4.350到5.675；两个指标方向可以不同。时间点差异不能自动归为某一单一记忆机制，因为重建、重看和随访都在程序中。

## 保留报告疑点，不擅自修表

第9页表6标题说用valence预测arousal，但结果列仍写overall valence；end一行同时给出R² = .111、F = .087、p = .036，数值之间存在不协调。这些是目视核对后的报告疑点，不自行选择一项当正确答案，也不拿这行建立正文结论。

表1中部分均值、检验量与组合指标的关系也留下待核问题；本次未重算。关于版本操纵，仅按作者结论转述“未检出评分差异”，不以表1所有单元格作新增证据。

原文讨论有比结果更强的概括：复杂经历中平均值更好，或峰终随时间失去预测力。这里保留表3和表5的不同情况，不从标题/摘要直接复制成通用结论。我们也没有把未检出当成精确零效应。

## 能带回正文什么

[C10的复杂经历部分](../../book/10-aftertaste.md#aftertaste-peak-boundary)采用三个限定：评价维度不同、回忆时点不同、取样方法不同，所谓“最佳预测指标”就不宜一概而论。它不是峰终研究的系统综述，也不直接推翻[B34](B34-gifts-and-endings.md)的不同实验。

40名大学生不能代表所有年龄和生活处境。单一影片、回忆分段、重看加工与未解释的方差，都阻止我们把它当完整生活公式。
