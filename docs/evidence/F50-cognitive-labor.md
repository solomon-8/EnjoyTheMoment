# F50 家庭认知劳动：作者项目介绍的读取边界

- **核读日期**：2026-09-30（UTC+08:00）。
- **来源类型**：`researcher_authored_project_summary`，作者对研究项目的自述；不是本项目已核读的原始论文全文。
- **用途**：说明预见需要、寻找选项、作出决定、跟进结果这四个区别；让正文对执行与组织的讨论有明确概念来源。

## 1. 实际使用了什么

Allison Daminger 的[研究页面](https://www.allisondaminger.com/research)返回HTTP 200，123,072字节。读取页面可见项目介绍，包括 *The Cognitive Dimension of Household Labor* 一节及其链接的两篇相关论文名称；其余项目介绍只用于辨认页面结构，不作本章论证依据。

威斯康星大学麦迪逊分校社会学系的[作者介绍](https://sociology.wisc.edu/staff/daminger-allison/)返回HTTP 200，236,750字节。读取姓名、个人站点链接、研究简介与所列发表记录，用于关联作者身份和书目。该页把书籍写成预先签约状态，个人页则说已经出版，两个页面更新状态并不一致；本书不据此判断书籍目前的出版状态，也不把机构页当作对研究结论的独立复验。

书目核对对象为：

Allison Daminger（2019），*The Cognitive Dimension of Household Labor*，*American Sociological Review*，84(4)，609–633。DOI：[10.1177/0003122419859007](https://doi.org/10.1177/0003122419859007)。

Crossref元数据及作者履历中的对应条目用于核对书目，不是方法、结果或样本的读取依据。没有在本书背景研究序列中为此新建一条“全文已读”的B记录。

## 2. 页面说了什么，不能多说什么

作者在该项目介绍中把认知劳动描述为四类工作：

1. 预见家庭需要；
2. 找到满足需要的选项；
3. 在选项中作出决定；
4. 跟进结果。

中文为本书自行转述。作者还把此项目放在家庭分工与性别不平等问题中讨论。本书保留这个语境，不把它描述为与性别毫无关系的通用效率技巧；但也不借项目概述为每一对伴侣或每一个家庭安排定性。

**网页说的170余次访谈，是其项目整体的描述，并列涉及不同性别与同性别伴侣、2019年及2020年文章和书籍。它不能直接充当2019年论文的样本量。** 本次未取得那篇论文全文，因而不报告其招募方法、人数构成、编码程序、组别比例或结果大小，不从二手转述补齐这些空白。

四类工作是一种分析区分，不等于四个等量工时单元，不是已验证的家庭公平评分，也不意味着所有任务都严格按相同顺序发生。

## 3. 没读到的资料仍然是缺口

出版社PDF请求返回403；一个检索到的JSTOR入口虽返回HTTP 200，实际只有HTML页面，不是PDF。作者页面链接的论文、其他相关论文及书籍均未在本次完成正文核读。

作者CV下载成功，但只读取相关书目区域，不把CV或“文件下载成功”写成论文全文核验。没有独立复核原始访谈、后续复制研究或全部方法争议。

因此这里的证据等级不是“已经验证认知劳动必然导致某种休闲结果”。作者本人对项目的介绍属于一手自述，但相对于论文方法与完整论证仍然是摘要性材料。

## 4. 哪些是本书自己的推导

第9章的朋友野餐、来家里吃饭、三种分工、权限与共同条件，全部是本书原创假想，不是来源里的访谈引文，也不是实施过的干预。

把家庭研究的概念用于朋友活动，是本书作的类比；不能因此声称研究已覆盖朋友聚会，或已证明“完整接管”一定比“按清单协助”更快乐。

认知劳动、身体执行、情绪感受与待命条件在正文中分开，是为了不让一个术语替代所有负担的说明；不是给读者作心理、关系或照护诊断。“有责任也要有决定空间”“喜欢照顾不等于永久承诺”是本书的价值论证。

F01的中国时间利用统计与本记录不是同一项调查，不能合并样本、替换活动定义或拼成因果链。本记录不为J049–J054的预算、动作、时长、适用性或效果增加研究背书。
