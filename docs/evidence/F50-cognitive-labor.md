# F50 家庭认知劳动：项目说明与博士论文的指定核读

- **核读日期**：作者项目及书目初读2026-09-30；项目页与博士论文指定范围核读2026-10-04（UTC+08:00）。
- **来源类型**：`researcher_summary_and_dissertation_excerpt`。包含作者项目自述、博士论文方法章和指定段落；不是整本博士论文通读，也不是2019年期刊论文全文核读。
- **用途**：区分预见需要、寻找选项、作出决定、跟进结果；进一步讨论认知任务的时间边界、可见性与影响机会。朋友活动的推演仍属本书原创。

## 2. 方法与样本能支持到哪里

方法章描述2017–2020年的两波招募，地点涉及波士顿地区与新泽西。对象为有子女的异性伴侣，样本主要为白人，教育水平偏高；不是全国家庭概率抽样，也不同于作者项目页跨多项成果的总体范围。

第一项研究分别访谈伴侣双方，并用前24小时的决策日志帮助回忆和讨论；不能将日志解释为对全部认知劳动的精确计时。第二项研究允许只有一方参加，并用38张任务卡（24项认知、14项身体任务）辅助访谈。作者结合访谈、任务分类与迭代编码分析分工；受访者怎样理解“共同承担”并不完全一样，分类不能直接换算等份工时。

只有一方参加时，自我报告可能偏向自身贡献；另一方面，另一方不愿参加本身也可能与分工有关。论文讨论了这些解释，不能任选一个当作事实。访谈能帮助展开经验与概念，但不让本书获得对任何具体家庭的诊断权。

**所读版本的访谈人数存在内部不一致。** 摘要及方法开头写136次个体访谈、76对伴侣；分研究所列64与74次合为138，印刷页28正文及29表3也列138人（63名男性、75名女性）。本书未独立解决这个差异，不把它静默改成一个数字，不据此计算总体或性别比例。这里取用的是指定段落的分析区别，不以发生率为论据。

印刷页78明确说，这些数据不能建立认知分工与经济、健康结果间的因果连接。本书也不把它写成朋友聚会实验、快乐效果比较或“完整交接必然有效”的证据。

## 3. 正文取用了哪些区别

### 四环节不是四份等量工作

作者项目说明与博士论文指定段落把认知劳动分为：预见需要、寻找满足需要的选项、作出决定、跟进结果。中文为本书自行转述。

这些是分析区别，不是已验证的家庭公平评分。不同任务可能来回穿行于多个环节；不能按各占两行就宣告公平，也不能把身体执行、情绪感受、关系维系与待命一律塞进同一个概念。

### 负担、认可与影响不是同一回事

印刷页54–58把认知任务的性质继续分开：复杂程度与是否有清楚的时间边界影响负担；可见性与影响结果的机会涉及作者所说的significance；新颖性可能同时增加前期投入和建立新安排的影响。本书不把significance译成道德上的工作价值高低。

正文所据的两个具体片段为：

- **Holly（印刷页56）**：持续了解家中用品库存，却起初未把这种记在脑中的监看理解成自己承担的一项工作。同页还讨论，买房、装修或旅行等特殊筹划往往比维持饭菜、衣物等日常条件更容易被看见和认可。
- **Kendra（印刷页57）**：丈夫每天决定给孩子装什么午餐，而午餐袋、容器与通常备什么原料的安排已由她建立。这一片段让“设立安排”与“在安排内作日常选择”的区别具体可见，不证明任何一方承包所有权力或全部劳动。

印刷页58还区分了把事项提上议程与决定怎样处理事项。前者可能提高事情得到处理的机会，却不等于后者。以上均为对所读研究文本的转述，不是本书重新访谈得到的资料。

## 4. 哪些仍然不能声称读过

2019年期刊论文的出版社PDF请求返回403 HTML；此前检索到的JSTOR入口也只是HTML，不是PDF。本书未完成该文全文核读；作者其他相关论文和书籍亦未在本记录中完成正文核读。初读作者履历只用于书目，不能以下载成功冒充研究正文已读。

博士论文的取得没有自动补齐这些缺口，也没有独立复核原始访谈、后续复制研究或全部方法争议。项目网页对更多成果的概述，不能替代逐项研究的读取。

## 5. 哪些是本书自己的推导

第9章的朋友野餐、来家里吃饭、三种分工、权限与共同条件，以及惊喜环节、集合提醒与完整参加聚会的情境，全部是本书原创假想；Holly、Kendra则是明确标注的论文个案转述，两类内容不能互相冒充。

把家庭研究中的区别放进共同享乐，是本书的类比，不意味着研究已经覆盖朋友活动。被看见、能决定、能参加可能分离，不能简化为“隐形劳动永远更多、更高贵”，也不能推导出显眼策划不值得感谢。

“有责任也要有决定空间”“喜欢照顾不等于永久承诺”“感谢不能替人参加聚会”是本书的价值论证，不是验证过的干预结论。我们不要求按性别判定谁有错，不鼓励以破坏安排证明贡献，也不把互相给予改成永久债务。

F01的中国时间利用统计与本记录不是同一调查，不能合并样本、替换活动定义或拼成因果链。本记录不为J049–J054的预算、动作、时长、适用性或效果增加研究背书。
