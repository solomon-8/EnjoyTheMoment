# F91 · 健身会籍：付款周期、续订动作与取消滞后

**来源类型：`primary_research_excerpt`。原始研究的指定段落核读，不是全文及数学模型复核，不是当前消费合同或健身建议。**

## 样本不是一组随机分派的合同

研究使用三家美国新英格兰地区俱乐部的会籍、付款和出勤资料。第一家记录为1997年4月至2000年7月，另两家延续到2001年2月；不能说每名会员都完整追踪三年。

从初始10,175人中排除不在分析范围的会籍类型、资料问题、家庭会籍及此前特定会籍等，得到7,752人、8,273段会籍记录；正文分析使用每人的第一段。顾客自行选择合同，企业补贴也影响实际付款，**不是随机让一部分人月付、另一部分人年付**。

按次用户的实际出勤不在该跟踪数据中。文中关于同样出勤次数下可以少付多少钱的计算，不等于对随机按次组的实测快乐或福利比较。消费章不借本研究推荐某种健身频次或承诺省下固定数额。

<a id="f91-contracts"></a>
## 付款周期与默认结果：印刷697页

原文描述第一、二家俱乐部的主要合同如下；第三家同类菜单的价格更低、服务略有不同。

- **月付**：持续自动扣款，直至用户取消；可到场或书面取消。原文写10号以前取消，当月底结束；10号之后取消，还须支付下月费用，至下月底结束。未补定恰好10号的处理规则，也不把“提出取消”当成“当天终止”。
- **年付**：年费相当于适用月费的十倍，换取十二个月承诺；到期自动结束，想继续需要重新注册为年付或月付。不能把这个历史安排套到所有现代年卡。
- **按次**：可以单次购买或买十次卡。十次卡与定额会籍采用同类进门交卡程序，不能编造每次付款都必须长时间排队的差别。

本书从这组合同提出“未来哪一个动作需要本人完成”的问题，属于原创讨论。合同并非只在默认选项上不同，故不能以组间结果单独识别默认续订的因果作用。

<a id="f91-lag"></a>
## 2.31个完整月，测的是哪段间隔：印刷708页

作者以**最后一次出勤到合同终止之间的完整月数**作为取消滞后指标，对象为终止时持有月费合同的会员。为限制重新加入的费用，分析限于无入会费者；脚注20进一步注明无企业补贴、月费超过70美元或年费超过700美元、在样本开始后一年内加入等限制。本书不补写该特定子样本人数。

结果为平均2.31个完整月，对应会籍付款187美元；其中20%的间隔至少四个月。**这些不是7,752人的全样本均值，也不是“已经决定不要以后”的实测等待时间。** 研究没有直接观察那个决定何时形成。

作者的计数例子是：3月10日最后出勤，4月5日取消，4月30日合同终止，51天按其口径计为一个完整月。最后出勤、提出取消、合同生效结束是三个不同时间点。

作者认为这个代理指标可能低估低出勤者的取消滞后：它不包括低但仍为正的出勤月份，最后一次到场也可能是为了取消。这是作者的解释，不是对每名会员取消动机的直接记录。合同的终止规则也不能从间隔中抹掉。

<a id="f91-limits"></a>
## 解释竞争与本书不用它证明的事

印刷713–716页讨论交易成本、会员身份的心理收益、偏好随时间变化、有限记忆、现时偏好及过度自信等解释。作者认为一些解释能说明部分模式，却不足以共同说明全部发现；并不等于这些动机在任何个人身上都不存在。

作者较支持同时高估未来出勤以及取消／未来效率的解释。本书没有复验其模型、重跑数据或穷尽后续研究，不能把作者的综合判断改写成每个低使用者的诊断，也未独立核读文中引用的其他论文。

正文仅用本研究建立合同与指标的具体区别。它没有测量主观快乐，没有验证本书的演出会员假想，没有证明短期、按次或年付合同普遍更好，也不给行动卡的预算、时长和效果背书。愿意为可用性付费、希望支持创作与忘记扣费，在记录上可能都表现为继续付款，不能仅凭行为替个人选定一种解释。
