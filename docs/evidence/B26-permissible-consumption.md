# B26 核读：收入标签如何进入“别人可以消费什么”的判断

**论文研究观察者怎样评价情境中的购买与分配，不是对低收入者消费后幸福、财务结果或真实救助方案的效果评估。存在未解决的样本与统计表述冲突，不能把所有数字照单全收。**

## 文献与读取范围

Serena F. Hagerty、Kate Barasz（2020），*Inequality in socially permissible consumption*，PNAS，117(25)，14084–14093，[DOI](https://doi.org/10.1073/pnas.2005475117)。

2026-09-30读取[PMC期刊HTML全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7321998/)中的引言、11项主实验方法与结果、表1至表3、总讨论、脚注和参考文献，并目视核对两幅原始结果图。这里的11项是1A、1B、2、3、4、5、6、7、8、9A、9B，不是11篇独立论文或11个研究团队的复现。

出版商全文与PDF请求返回403；PMC的论文和补充文件下载请求返回下载准备页，不是PDF。本次没有取得这两份PDF，没有读完补充材料或逐个预注册文件，也没有复算OSF数据。PMC HTML足以读到主文，但不能据此声称完整审计所有研究材料。

作者在主文中称各项研究预注册、未排除数据并报告全部测量和操纵。这是作者报告；本项目没有逐项比对预注册与最终分析。研究2的方法还注明，预注册目标为1,000人，外部平台继续收集至1,174人，作者称全部收集结束后才分析。

## “许可”到底是什么？

论文把五项评价组成综合分数：购买是否负责、是否值得拥有、是否经过考虑，以及反向计分的冲动与本应购买别物。它是人际评价量表，不是购买是否违法，也不是直接测量歧视行为的统一标准。

研究还用另一组五项评价测“感知必要性”：观察者觉得物品是否必不可少。这里的“必要”是被调查者的判断，不是作者已经建立的客观需要清单。

收入操纵通常把情境人物描述为美国收入分布的底部或顶部四分之一。样本来自美国城市街头、网络平台，以及两组作者称具有全国代表性的分层样本。研究2按收入、性别、年龄、族裔分层；研究3按性别、年龄、族裔分层，不能把二者都说成按同一套收入分层招募，也不能仅凭这些描述确认具体抽样实现。它们不是中国社会或全球人口的代表性调查。

## 主实验回答了哪些不同问题？

| 实验 | 方法部分报告的样本 | 情境与范围 |
| --- | --- | --- |
| 1A、1B | 200、300 | 同样用抽奖所得200美元礼品卡买电视；1B增加未说明收入的组 |
| 2 | 1,174 | 选择两款设定安全评分相同、便利性不同的儿童座椅，评价购买 |
| 3 | 500 | 从20类日常消费中随机展示10类，评价许可程度 |
| 4、5 | 209、402 | 评价座椅与住房属性的必要性，而非购买后感受 |
| 6、7 | 404、399 | 改变倒车摄像头的用途描述或所选手机，测必要性与许可 |
| 8 | 200 | 假设分配200美元，每人选择一个支出类别 |
| 9A、9B | 201、200 | 情境中选择赠予哪张礼品卡；先改变面额，再给出接收者偏好 |

这些问题相互关联，但不是同一个结果指标反复测11次。金额是原实验设定，不是现价、建议预算或实际购买记录。

### 同一购买，评价可能不同

研究1A报告，低收入情境的综合许可均分为3.56，高收入为4.07，效应量d = 0.51；两组都被告知使用抽奖所得礼品卡。1B中，低收入组为3.62，高收入和未说明收入组均为4.49。

不过表1里，五个分项并非都显示相同的显著差异。尤其不能把综合分显著直接写成每个实验都明确证明“人们觉得穷人不配拥有电视”这一单项结论。

礼品卡相同削弱了一些解释，却没有让两种收入情境拥有相同的全部机会成本。研究并未提供两个人完整、等价的预算与备选需要，不能由此断言所有负面评价都不含对实际取舍的考虑。

### 不是任何物品都同向

研究3的20类物品中，19类的综合许可显著较低，个人护理品没有显著组间差别。

研究5的住房属性中，17项的必要性评价对低收入家庭显著较低；靠近休闲场所／公园、靠近超市没有显著差异，靠近公共交通则方向相反，被认为对低收入家庭更必要。不能把这些结果说成低收入者的所有需要一律遭否认。

研究7的图2也显示，低收入人物购买基础翻盖手机得到的许可评分并不比高收入人物更低；差异取决于所选物品。手机情境同时改变型号、功能和价格，不是只改变抽象的“必要性”，更不是当下购机建议。

### 有差别，不等于人人如此

研究9A让参与者在100美元食品礼品卡与200美元电子产品礼品卡之间选择。选择面额较大电子产品卡的比例，低收入接收者情境为25%，高收入为53%。作者将面额称为客观价值，但商店限制与现实用途仍可能影响实际效用，不能把更大面额等同于每个接收者一定更需要。

9B把面额都设为200美元，并告知接收者想买电视。选择符合这项偏好的卡，低收入情境为73%，高收入为87%。差异支持进一步讨论，但两组多数人都选了当事人希望得到的卡，不能改成“多数人不尊重穷人的偏好”。

研究8明确称为假设分配，9A、9B也让参与者想象赠卡情境。没有在此跟踪真实援助接收者的福利、财务表现或长期满意度。总讨论向援助与政策的延伸，是作者对可能影响的讨论，不是这些实验已经验证一套政策优劣。

## 原文里有哪些尚未解决的冲突？

1. **总样本数。** Significance部分写11项实验合计4,179人；逐项相加方法部分列出的样本为4,189人。研究4方法写209，但结果报告t(197)。这些线索不足以确定差异由何而来，本记录保留两种原报告，不把其中一个擅自改成“正确总数”。
2. **研究6的必要性统计。** 主文将安全描述下低收入组均值写为5.28，95%区间却为[3.95, 4.61]；该均值不在区间中，又与紧邻的“较低”描述及另一组4.77不相容。不能猜一个4.28替换，也不能据这一行生成精确比较。图1画的是许可，不是这里的必要性，不能拿图1替它纠错。
3. **研究7的文字与图示范围。** 主文一处把收入主效应概括为两种手机均更不被许可，但同文的分组均值与图2不支持将此推广到基础翻盖手机。应看交互和具体条件，不把总体主效应扩展为每个条件都同向。另有部分均值、区间与检验表述未能在本次核读中相互核准，因此不引用其完整精确统计表。

我们目视检查了图1与图2，但图像不是原始数据，也不能让文字冲突自动消失。Crossref返回的当前记录未列关联更正，这不证明没有勘误；本次没有穷尽所有后续更正、复现或反方研究。

## 机制、因果与使用边界

实验以组间设计改变收入标签、产品描述或所选物品，作者据此讨论这些操纵对当场回答的影响。主文明确描述了部分题项顺序与展示子集的随机化，但本次未从预注册或代码核验每项实验的分组实现，不能把题目随机顺序当成已经审计随机分组。作者还报告必要性与许可之间的中介模型，但感知必要性本身是测量变量，产品描述也可能同时改变其他理解；不能把统计中介直接当作所有现实评价都只经过这一条心理路径。

主文的显著与非显著结果都应保留。“未显著”不等于证明完全相同，显著也不等于每个观察者都持这种意见。单篇多实验不等于独立重复验证，也不提供2026年中国人对此问题的流行率。

[E06](../../essays/06-real-life-constraints.md#constraints-permission-study)只用它呈现一个值得认真面对的问题：收入标签可能进入对相同物品的许可和必要性判断。本人是否值得有快乐、谁可要求说明共同支出、帮助应有什么条件，仍是本书的规范性论证。

本研究没有证明非必需消费必然使人更幸福、无限制现金援助一定优于其他安排，或所有预算提醒都是偏见；没有验证任何J卡、比例、时长或具体消费。尊重愿望也不等于建议立即兑现。
