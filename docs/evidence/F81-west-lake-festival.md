## 五类是叙述安排，不是人口分类

以下按独立篇目概述，不按职业或身份替历史人物补心理：

| 文中的次序 | 文本怎样安排“看” |
| --- | --- |
| 第一类 | 船、宴饮与声光十分显眼，叙述者说名为看月却未见月 |
| 第二类 | 坐在月下而四处张望，叙述者说实不看月 |
| 第三类 | 看月，也希望别人看见自己看月 |
| 第四类 | 看月、看人、看不看月的人混在一起，叙述者又以“无一看”收束 |
| 第五类 | 与友人相伴，藏影或避入里湖，不以被人看见为前景 |

这不是五项互斥动机的测量，没有抽样、访谈、人数比例或分类可靠性。叙述者的贬褒不等于旁观者能够准确知道陌生人的内心，尤其不能把原作中的性别、身份与年龄称谓变成当代欣赏资格。

正文只对第三与第五类作重点细读：前者并非完全不看景，后者并非独自一人。我们据此讨论观看、展示、相伴可能共存；不是宣称作者提出了今天的社交媒体理论。

## 后半夜没有把所有人赶出文章

中段写拥挤、碰撞、声响及队伍离去；后段才让“吾辈”靠岸。低唱者与先前隐在树下者再出现，被邀来同坐，继而有宴饮与声乐，客人在天将明时散去。

因此，结尾并不是“所有人散光，叙述者终于独自看月”。第三、第五类在后段被重新提及，但本书不据此断言作者已经完全取消前段的等级判断。可以说他选择了另一种相聚，不能替他宣布人与人之间已经一律平等。

正文有关短句碰撞、景物重新获得描写、视线与篇幅分配的说明，是本书文本分析。它没有测量真实月色、声压、密度、行船条件或每个人当晚的感受，也不证明人多一定不好、人少一定好。

原文写到舟、轿夫、门军与入席表演者，足以提醒这不是完全脱离他人和条件的一夜。**没有报酬、同意、休息或劳动安排的完整记录**，不能从本篇重建劳动制度，也不能声称每个服务者遭到或没有遭到剥削。正文“谁等得起”的问题，是对把特殊条件泛化成普遍品位的质疑，不是对作者财富或人格的调查结论。

## 本书怎样延伸，停在哪里

[C18](../../book/18-celebration.md#celebration-west-lake)提出：同样的地点、菜和同伴，换一个时刻不一定构成等价体验；公共时间与共同在场可以是庆祝的内容。阿禾、小乔和年末倒数是本书虚构情境，不是古文情节、真实读者来信或实验案例。

“错峰可能错开所要的事件”“想参与不自动等于被气氛操控”为本书价值论证。既不赞成人群越密越好，也不把安静当作唯一真正的享受；不要求别人为了自己延长工作、陪伴或开放时间。

本篇标题的七月半，不改写成中秋节，也不换算为今年可参加的节庆安排。古文中的宴饮、通宵与舟中休息只作叙事内容，**不是今天的饮酒、夜航或人群安全建议**。不新增B系列研究，不给任何行动卡、仪式安排、效果增幅或现代西湖游览作背书。
