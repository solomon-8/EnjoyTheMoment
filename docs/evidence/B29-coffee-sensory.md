# B29 咖啡：浓度、萃取与感官描述，不是偏好排名

## 样品和人，分别数清

研究使用一种洪都拉斯水洗阿拉比卡混合品种咖啡；同日烘焙后混合批次，以减少批间差异。设备是可编程的商用平底纸滤滴滤机，不是多种家庭器具的代表性抽样。

设计为3种冲煮温度87、90、93℃，与目标TDS 1%、1.25%、1.5%，目标PE 16%、20%、24%组合，共27种条件。报告总共270次冲煮；这是冲煮次数，不是270名消费者。为达到目标，研究者调整研磨、粉水比例和水流通断节奏；不能当成其他条件不变的单一降温试验。

12名品评员为19至30岁，4男8女，来自当地招募、经筛选的黑咖啡消费者。先训练四周，每周三次；随后采用盲码、随机化的Williams拉丁方区组安排，样品重复评价。评价31种属性：3种香气、22种口中风味、2种口感、4种基本味质，强度位置转为0至100分。不是喜欢程度问卷，也没有一般消费者购买选择。

样品在冲煮后约30分钟开始供应，供应持续最多45分钟；品评前控制在64–66℃。这是实验条件记录，不是推荐入口温度。存放与服务条件限制了对现冲饮用的推广；本书不采用原文的健康与碳排放外推作为已验证结果。

## 两个比例，不是两个质量等级

引言及方法公式1中，TDS是饮液溶解固形物的质量比例，PE按TDS乘以实际所得饮液质量、再除以投粉质量计算。原文称量所得饮液，而不是把投入水量直接代入。

正文20克粉、300克饮液、1.2%浓度，以及加水60克的例子，是本书根据公式做的理想质量账。3.6克溶解物不变，浓度降为1.0%，PE仍是18%；没有额外萃取、蒸发、洒出或其他质量损失。不是论文的一组配方、实际品评结果或对稀释后风味的精确预测。TDS不等于咖啡因含量，也不能唯一确定化学组成。

## 采用的结果与不能抹掉的条件

主文表2的多变量分析：温度主效应F = 1.25，p = .11；TDS为F = 5.44、p < .001，PE为F = 2.46、p < .001。这支持“在所测范围且控制TDS、PE及品评温度时，整体描述对冲煮温度的变化较小”，不构成统计等效证明，更不是所有单项、所有交互都无差别。

主文图6、结果与讨论给出：苦、涩、黏稠等随TDS增加，相关模型中与PE的关系未达显著；黑茶描述的拟合强度在较低TDS、较高PE处更高。黑茶是感官属性名，不是加入物。拟合面是样本与模型的结果，不保证每杯咖啡遵循相同曲面；也没有做化学分析来验证文中提出的机制猜想。

文中对传统控制图的批评，区分了强弱尺度、风味词和“理想”评价。本研究自身没有测偏好，所引其他偏好论文未在此独立核读，不能代它们宣布多数消费者喜欢什么。行业要求按论文2020年叙述记录，未核查2026年现行认证。

## 已更正的错误，与仍要保留的图文差异

**配水方法勘误**：2021年更正把矿物加入量对应的水量从“每升”改成“每100升”，相差100倍。此次取得的主文HTML和PDF仍可见旧写法，因此不能只看主文页面的更新提示。本书不转抄矿物配方，也不让读者把原文方法当家庭饮水建议。

**坚果风味差值**：主文第7页说温度对应的Nutty差别只有约1分；补充表S5的Nutty Flavor行在87、90、93℃分别为26.07、28.10、26.65，90℃与两侧的差分别为2.03和1.45。另有Nutty Aroma行，不能混读。本书不重复“准确只差1分”，也不自行更正原始数据。

**交互项**：主文称多变量分析中四阶以下没有显著温度交互，但补充表S2的Judge:Temperature:TDS为p = .035。它含品评员因素，不同于表2所列三个实验因素的交互；不能据主文概述写成所有温度交互均不显著。

主文对仅随TDS变化的属性声称“八种”，列举却有九项；表S5部分字母标记与均值关系也不宜凭常识自行修订。正文只采用上面明确且与论点相关的窄结论，不依赖这个总数或未解释的字母排序。没有取得原始数据重算，也没有穷尽后续复现。
