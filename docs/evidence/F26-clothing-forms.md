# F26 服装细读：色块、斜裁与着装语言

**来源类型：博物馆历史叙述、馆藏记录与指定数字图像。不是穿着实验、材料性能测试或普遍审美结论。**

核读日期：**2026-09-30**。文字、图注与图像分开核对。没有接触实物、查看全部背面和内部、测量颜色或观察真实穿着过程。

## 1965：向 Mondrian 致意

读取巴黎 Yves Saint Laurent 博物馆的 [Homage to Piet Mondrian](https://museeyslparis.com/en/biography/lhommage-a-piet-mondrian)。馆方把该组设计归于 1965 年秋冬系列，说明以羊毛针织料嵌拼、接缝不显露，形成对绘画几何关系的回应。

目视核看该页两张指定数字图像：

- 图注为 original sketch of a cocktail dress、1965 秋冬系列的草图；
- 图注标明由 Muriel 穿着、Louis Dalmas 拍摄于 1965 年 7 月巴黎的照片。

正文的色块描述只对应第二张：深色横竖带、大块红色、浅色区域及下缘黄色带。草图与照片的颜色分布并不完全一致，**不把它们默认为同一件成衣的前后对照**。页面第一张配图的图注另标 1962 年；不因它放在该页面里，就改写为 1965 年作品。

“嵌拼而非简单印画”的构造判断依据馆方文字，不能仅由远景照片独立证实。平面画面与身体轮廓两种观察目标，是本书解释，不是设计师关于每位穿着者的心理声明。

另读取 Metropolitan Museum API 的 [object 83442](https://collectionapi.metmuseum.org/public/collection/v1/objects/83442)，其记录为 Yves Saint Laurent、Dress、fall/winter 1965–66、wool。Met 网页请求受限，API 未提供主图；不把它当成已看实物、已看该馆图片，或确认它就是 Muriel 照片中那件衣服。

## 1931：Vionnet 的斜裁与复合部件

读取 V&A [Madeleine Vionnet – an introduction](https://www.vam.ac.uk/articles/madeleine-vionnet-an-introduction)，页面标示更新于 2024-04-17。选用其关于斜裁、垂坠、复杂构造和客户社会条件的说明；没有把整篇传记中的法律与劳动史说法逐一独立考证。

同时读取 [馆藏 T.381-2009 / O1156839](https://collections.vam.ac.uk/item/O1156839/) 及其 [API 记录](https://api.vam.ac.uk/v2/object/O1156839)：

- 设计者 Madeleine Vionnet，法国，1931 年；
- printed silk chiffon；由斜裁部分拼接；
- 短披肩与衣身、腰带联系，相关部分套过头后两端系在腰间，覆盖上臂，裙摆不齐；
- 为 Lady Minoru Foley 衣橱中的服装；馆方明确描述其高定客户的财富与社会条件。

目视核看馆方图像编号 **2010CT4482** 的公开数字图，可见印花、肩臂覆盖部分与不齐下缘。完整裁片、穿法与内部构造仍依据记录，而非声称仅凭图片反推出纸样。API 返回的记录更新时间是 2026-07-22，它不是服装制作时间。

丝、雪纺、印花、斜裁和成衣部件属于不同描述层次。由此提醒不要拿一个标签代替整件衣服，是本书的编辑应用；不保证某种裁法舒适、适合特定身形或适合自行仿制。

## 1966：tuxedo 的转用与接受

读取巴黎博物馆 [First Tuxedo](https://museeyslparis.com/en/biography/premier-smoking)，并目视核看图注明确为 Ulla 穿着、Gérard Pataa 拍摄的 1966 秋冬照片。

馆方说明是沿用男式服装符号并调整，而非逐样照搬。图中可见深色外套与长裤、浅色内层、领部系结；本书不从黑白图推导精确材料颜色或内部裁剪。

“高级定制版本最初只卖出一套，rive gauche 版本获得不同回应”来自馆方历史叙述，**未独立核对销售账册**。它可用于讨论受众与条件，不是统计推断，也不证明穿这种衣服会让所有人自信。更不能将其写成女性裤装的发明史。
