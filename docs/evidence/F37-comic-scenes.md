## 1. Wilde：一盘茶点与两套说法

Oscar Wilde，*The Importance of Being Earnest: A Trivial Comedy for Serious People*。取得 Project Gutenberg [电子书 844 元数据](https://www.gutenberg.org/ebooks/844)与 [HTML 正文](https://www.gutenberg.org/files/844/844-h/844-h.htm)，两项均返回 HTTP 200。下载正文 139,119 字节。

目录标注电子书于 1997-03-01 发布、2025-11-10 更新，制作致谢为 David Price。文件中的历史演出题记写有 1895-02-14；电子书发布日期、文件更新日期与历史演出日期不同，本书没有用文件更新时间给作品定年。

**实际核读范围**：第一幕开场，Lane 摆下午茶，Algernon 进入；继而 Jack 来访、三明治与烟盒谈话、身份与借口讨论、姨妈 Lady Bracknell 到场，直到她与 Algernon 进入音乐室。重点逐段核对三明治的准备、食用、限制他人、空盘与黄瓜借口。不把下载全文说成逐字读完整部戏，也没有核读全剧结尾来作新的情节判断。

章节所用文本依据：

- 开场 Lane 说已备好茶点并端上来，Algernon 拿了两块；不是一开始就没有食物。
- Algernon 阻止 Jack 吃为姨妈准备的三明治时，舞台提示让他自己拿一块吃。Jack 直接指出他一直在吃。
- 姨妈到场提起三明治后，舞台提示写出空盘及 Algernon 的惊讶动作；Lane 以严肃语气说没有黄瓜，补充跑了两次、现钱也买不到。
- Algernon 把这套说辞接受并转述，姨妈说没有关系，提到先前吃过的食物。不能改写成她已识破并当场揭穿。

“嘴和手互相拆台”“体面随需要移动”“道具参与情节”是本书对上述顺序的解读，不是从作者访谈取得的创作意图。没有观看、录制或评估任何舞台演出；纸面的舞台提示不等于实际节奏、演员表情或观众反应。

## 2. Carroll：茶会的局部认真与整体不讲理

Lewis Carroll，*Alice’s Adventures in Wonderland*。取得 Project Gutenberg [电子书 11 元数据](https://www.gutenberg.org/ebooks/11)与 [HTML 正文](https://www.gutenberg.org/files/11/11-h/11-h.htm)，均返回 HTTP 200。下载正文 169,663 字节。

目录标注电子书于 2008-06-27 发布、2025-06-26 更新，制作致谢为 Arthur DiBianca 与 David Widger。这些是指定数字版本信息，不是原作首版年份。

**实际核读范围**：第七章 *A Mad Tea-Party* 全章，从茶桌旁的空间与待客冲突、谜语、换位句、怀表、Time 对话、Dormouse 的故事和换位，直到 Alice 离开并在章末进入花园。本书不分析邻章或影视改编，也没有下载或转载配图。

章节所用文本依据：

- “说出所想”与“所说是所想”的争论后，人物依次提出吃/看、喜欢/得到、睡/呼吸的换位句。本文解释其中关系不能自动互换，但不把对话当成一篇形式逻辑证明。
- 出题的 Hatter 及 March Hare 在这场对话中没有给出乌鸦与写字台的谜底。本次未核读后来的序言、作者书信或各版附加答案，不能断言作者从来没有作答。
- Hatter 把 Time 当成能交往的对象，并借 `beat time` 从音乐打拍子转向挨打。中文说明展示英语条件，不声称汉语有完全一致的双关。
- 依 Hatter 的讲述，他在演唱后得罪 Time，此后总是六点、没有洗茶具的间隔。Alice 问绕桌回到起点怎么办，March Hare 转移话题。人物的解释及转移不构成由本书补完的世界规则。
- 后文确实为干净杯子换位，叙述说主要得利者是 Hatter，Alice 因上一个位置上的牛奶更不方便。
- Alice 厌恶离开，最后看见另外两人试图把 Dormouse 塞进茶壶。不能把这段当作所有角色都愿意或享受的聚会。

“荒唐前提产生物品与相处后果”“局部正确不等于善意交谈”“场外欣赏与场内体验不同”，都是本书细读，不是 Carroll 本人解释或经验研究结论。第七章含改编歌谣，正文未复录歌谣，也不借歌词推演音乐效果。
