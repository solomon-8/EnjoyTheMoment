# F17 舞蹈来源：描述工具不等于身体或审美的统一标准

**来源类型：考试机构的舞蹈课程规格，以及舞团的作品记录。前者给出教学分类，后者提供作品的归属和自述背景；都不是享乐效果研究。**

## 实际核读的教学材料

2026-09-30 读取 AQA 的 [GCSE Dance 8236：Choreography](https://www.aqa.org.uk/subjects/dance/gcse/dance-8236/specification/subject-content/choreography) 页面，并从官方页面所给链接取得 [GCSE Dance Specification PDF](https://cdn.sanity.io/files/p28bar15/green/d4b3594ec07c0496b08958e5f2acc5c84fcd8dfe.pdf)。

PDF 封面标为 **Version 1.3 June 2026**，全文件 42 页。实际核读第 15–17 页的第 3.2 节及相邻说明，目视核对第 15、16 页的分类表；没有完成整套课程、动作视频或评分材料的审核。

该节将编舞内容分为动作、动态、空间与关系，列出移动、手势、静止、重量转移，速度和质感，路径、层次、方向，以及领随、镜像、反应、接触和队形等方面。它也列有重复、对比、齐做、依次进入等编舞手段，以及语言、身体打击声和静默等声音环境。

来源的用途是课程与评估，包含时长、人数及评分要求。本书只借用有限的描述分类，**不把考试标准变成普通人跳舞的资格线**，也不把这套分类说成全球舞蹈传统的完整体系。

正文把“动作少也能形成不同时间关系”展开为四格手势和多人接续示例，是本书原创构作，不是 AQA 教材中的既有例子。术语日常化转述不意味着官方认可这种解释、具体做法或情绪效果。

## 实际核读的作品记录

同日读取 [AILEY 官方《Revelations》作品页](https://ailey.org/repertory/revelations)的作者、首演、作品介绍和音乐署名部分。它将编舞者列为 Alvin Ailey，首演列为 1960 年，并将作品与非裔美国人的宗教歌曲、文化传统及编舞者童年记忆联系起来。音乐署名分为三个部分，分别列出编曲、改编及相关贡献。

这些是舞团提供的作品记录与解释，不是本书独立考证过的完整创作史。中文采用《Revelations》保留原题，不给其宗教词语强行指定唯一中文解释。

**没有观看并核验完整演出**，因此正文不逐动作分析该作、不据舞台照片推断动作顺序，也不复制剧照、音乐、录像或编舞谱。页面的近期场次、时长与售票信息没有被用于推荐具体演出；演出版本和现实参与条件须另查。

舞团对作品广泛传播、感染力和观众热烈反应的表述，属于机构的介绍或宣传。本书不将其当作代表性调查、所有人的反应或已被验证的幸福效果，也不以此判定每个人应当喜欢这部作品。

## 本书的解释与非主张

“准确、好看、舒服、有意思是不同问题”“关系不是遥控”“模仿不等于原创署名”，是本书提出的区分。分类与作品来源用来约束表述，不替价值选择作科学认证。

本章没有证明小幅度、数拍、即兴或共同舞蹈一定更快乐；没有评估个人关节、平衡、力量或疾病条件；不提供跳跃、托举、下腰或接触技巧的安全教学。正文的接触与拍摄同意要求属于本项目的参与原则，不冒充任何舞种的全部礼仪或法律结论。

读文字、看图、观看演出和亲自跳舞是不同经验，不能相互冒充。学习者可以愿意认真练习，也可以只想动一动；教学资料不能替本人回答哪一种才算值得。
