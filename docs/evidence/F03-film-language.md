# F03 来源记录：看懂一点表达，不等于必须喜欢

**来源类型：大学托管的电影分析教学资料。它提供术语和分析例子，不是“这些技法会使所有观众更快乐”的研究。**

## 读取范围

来源：[Yale Film Analysis](https://filmanalysis.yale.edu/)。核读日期：2026-09-29。此次查阅三个教学页面的相关条目：

- [Cinematography](https://filmanalysis.yale.edu/cinematography/)：画幅比例、景别、焦点变化、摄影机运动等。
- [Editing](https://filmanalysis.yale.edu/editing/)：交叉剪辑、长镜头与节奏。
- [Sound](https://filmanalysis.yale.edu/sound/)：声桥、叙事内／叙事外声音、画外声音和声音性质。

实际依据是条目的文字解释。没有声称观看并逐一复核全部示例片段，也没有完成整个站点课程。本站含较早的技术与媒介语境，本书不把其中对当时常见格式、设备或片长的描述改称当代统一标准。

## 本书采用的有限知识

画幅比例描述画面宽高关系；裁切可能改变构图。景别描述画面呈现的尺度，不同于镜头持续时间。焦点变化可把清楚的平面从一处转移到另一处。

剪辑将镜头组织起来；节奏也与运动、镜头持续、声音及场面调度有关，不能只数切了几次。长镜头的“长”是相对持续，不在本书设定一个适用于所有作品的秒数门槛。

声桥可让声音跨越场面转换；画外声音的声源被理解为位于场景空间中，但暂时不可见。叙事内外讨论声音在故事世界里的位置，不等同于拍摄时录音还是后期配音。

## 哪些是我们的提问，而非来源结论

“为什么让我看听者而不是说话者”“我比角色多知道还是少知道”“我想看梗概还是亲自经历揭示”，均为本书据这些概念设计的阅读入口。

正文中的对话、门外脚步、收音机场面为原创虚构例子，未借用课程具体例片的解释。没有复制台词、片段、剧照或教材正文。

本书不会从术语推导“长镜头更高级”“安静观看优于讨论”“必须不借助字幕”。某项技术可以怎样表达，与个人是否喜欢某部作品，是不同的问题。

课程说明是理解工具，不是审美权威替读者作出的判决。当前播放版本、字幕、音频描述或设备设置是否可用，应查具体提供方，不能由这些概念页保证。
