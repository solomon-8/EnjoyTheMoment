# F09 来源记录：难度可以拆开，不只是简单或困难

**来源类型：面向游戏开发者的无障碍设计指导。不是玩家幸福实验，也不是每款游戏的功能承诺。**

2026-09-29 核读微软 [Xbox Accessibility Guideline 108: Game difficulty options](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/108) 的目标、概述、设计问题、指南与示例文字；页面正文标示最后更新于 2026-03-04。未逐一观看示例视频或实测所提游戏。

第 19 章使用三项区别：

- 体验到的难度涉及玩家能力与游戏障碍之间的关系；同一障碍不对所有人形成相同挑战。
- 整体难度档位可以包含不同机制，指南建议分别调节某些机制，例如战斗与谜题。
- 改变资源、规则和体验的创作模式，不必然只是原模式的低难度版本。

指南也讨论让玩家更改难度、保存进度等设计。它说明一种开发方向，不证明目前每个产品、平台、模式或版本都实现了这些功能。本书不据此提供游戏购买清单、可及性认证或设备兼容保证。

本章关于查看实际游玩过程、区分自己想承担的挑战，以及共同游戏中的协商，属于原创应用分析，不是微软验证有效的个人决策方法。未复制页面截图、视频或游戏素材。

## 钟楼例子的来源边界

2026-10-03再次取得上述官方页面，复核Overview和Implementation guidelines中对独立机制调整、保存进度、简化控制方案、难度用语及暂停的文字。页面仍标示2026-03-04更新；没有把本次取得日期当作指南发表日期。没有观看示例视频、实测所列游戏，或进入Resources and tools里的外部文章；页面列出旁路/跳过资源，不等于本书已经独立核读那些文章。

[C19的钟楼例子](../../book/19-games.md#games-skip-example)由本书构造，不出自微软：五次3分钟运送、20分钟解谜、5分钟结尾、两项各6元选项与30分钟/6元额度都是假定。加减和可行性只在该模型内成立，不是市场报价、操作时间测量、无障碍测试或付费建议。没有算快乐单价，也不把最快结束当最佳体验。

[收费菜单的三种安排](../../book/19-games.md#games-skip-menu)同为假想；未调查某个真实游戏是否曾添加门槛再出售跳过。玩家选择是否合意与收费安排是否合理，是本书区分的评价层次，不是指南的政策结论。指南没有给付费跳过背书，也没有证明所有辅助都应按某种价格提供；有关参与条件与公平的规范主张由本书承担。

本次不改变来源类别，不增加B类研究，不验证行动卡。与[障碍是否构成体验的反问](../../book/19-games.md#games-skip-objection)一起读，不能把“障碍可以有价值”改写成所有人必须接受相同控制要求。
