## 实验一：评分时，还没有观看那些DVD

来源为Dartmouth College三次慈善募款中的本科捐赠者，104人合并，排除4人后分析100人。研究者将参与者随机分到五种免费DVD赠送安排。A、B名单各10部影片，依据电影网站评分区分较高与较低但仍正面的等级；这是材料选择规则，不是对每名参与者实际喜好的直接测量。

只A组收到一次A名单选择；A+B组先选A，之后才收到可从B再选一张的通知；B+A顺序相反；A+A两次从高评分名单选择；只B组只从B选择。完成全部选择后，参与者评价对整体赠送安排有多满意，随后才送达DVD并说明研究。

所以实验操纵的是选礼/获赠安排，不是看电影的体验。不能把评分称为“看完电影后的快乐”，也不能推知后来是否观看、看了几次或快乐持续多久。

表1报告的样本数与评分如下。这里只保留均值用于追溯，不以平均数代替个体偏好：

| 条件 | 人数 | 平均整体评价 |
| --- | --- | --- |
| A | 29 | 5.21 |
| A+B | 21 | 4.14 |
| B+A | 17 | 4.82 |
| A+A | 19 | 5.50 |
| B | 14 | 2.57 |

非参数总体比较χ²(4) = 41.8，p < .001。A与A+B比较z = 3.31、p = .001；A与B+A比较p = .179，未显著；A+B与B+A比较z = 2.08、p = .045。最后一项是有限的顺序证据，不应因为跨过常用.05门槛就称为强而普遍的定律。论文没有在这几项成对比较处明确说明多重校正，不能自行补称已校正。

排除的4人曾在评分解释中给出与预设等级不一致的理由，例如偏好B中的某片。这个选择影响外推：分析结果不等于涵盖了所有与研究者品味不同的人。

## 实验二：28名儿童，测的是收糖时

万圣节住宅门口的28名讨糖儿童参加，平均年龄10.03岁，标准差1.79，7名女孩。A是整块Hershey巧克力，B是泡泡糖；收下后用七级笑脸量尺评价刚才收到的糖，不是吃完后的享受。

分配概率分别为A和A+B各3/8，A+A与B各1/8。实际A组10人、A+B组11人、A+A组4人、B组3人。平均评分依次为7、5.91、7、3。A与A+A都达到量尺顶端，不能从这个天花板说两者实际效果精确相同。

总体χ²(3) = 18.04，p < .001；A与A+B比较z = 2.96，p = .003。尾注因大量同分另作“7分/非7分”分析，报告χ² = 9.545、p = .002，Fisher双侧p = .004。它们是同一批数据的分析，不是额外复现。

这项没有B+A组，不独立检验倒转顺序。两实验合起来可以支持“额外获赠不必提高整体评价”的有限表述，不能由儿童实验单独给出“最好的放最后”的完整因果比较。

## 原文中的解释，不能全部升级成测量

**量尺文字有矛盾。** 第97页实验一方法写最低分为least pleased；第98页讨论说两项实验最低分1是neutral。两处已目视核对。我们不擅自认定哪处应改，也不拿B均值高于1就证明每个人从B获得了正效用。

作者将额外正面礼物解释为客观增加了总体快乐，并讨论人评价的不理性。接受免费礼物可以是线索，但本实验没有独立测量每件礼物的过程效用，更没有测量它们的快乐总和。因此，“获赠更多”与“实际快乐更多”保持分开。

论文把整份赠送作为统一事件来问，并据此讨论峰终规则；它没有随机操纵事件边界，也没有直接区分所有可能的信息聚合机制。不能据其结果保证把活动改名或分场就改变回忆。

实验一在当时伦理审批下没有事先告知研究目的；这是原文程序说明，不是本项目开展未告知实验的许可。我们没有开展参与者实验。

## 本书采用与不采用什么

[正文的礼物部分](../../book/10-aftertaste.md#aftertaste-gifts)用它质疑“多送就一定总评更高”，同时保留测量对象、材料等级及排除规则。[事件边界](../../book/10-aftertaste.md#aftertaste-one-episode)的演出与宵夜是本书原创设例，不是论文的干预。

“好结尾不该替整个过程免责”属于本书价值论证，不是作者测出的规范结论。B34不决定一个人该停留多久、不替所有赠品排序，也不验证J055—J060或任何行动卡。

和[B35](B35-complex-experience-and-memory.md)并读时，不把两个不同设计当直接复现或彼此推翻。选礼的总体满意度、影片的情绪回忆和生活中愿意付出的代价，是相关但不同的问题。
