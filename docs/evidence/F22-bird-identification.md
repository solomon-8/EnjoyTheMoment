# F22 辨鸟：物种特征不是本地出现证明

**来源类型：RSPB 物种介绍与 BTO 鸟类资料。使用机构自己发布的识别文字，不冒充物种调查或图片识别实测。**

核读日期：**2026-09-30**。实际读取：

- RSPB：[Tree Sparrow](https://www.rspb.org.uk/birds-and-wildlife/tree-sparrow)，学名 *Passer montanus*。核读 How to identify、Key features、Where and when to see them 的文字。
- RSPB：[House Sparrow](https://www.rspb.org.uk/birds-and-wildlife/house-sparrow)，学名 *Passer domesticus*。核读识别特征，特别是成鸟雌雄与幼鸟差异。
- BTO：[Tree Sparrow](https://www.bto.org/learn/about-birds/birdfacts/tree-sparrow)。核对导言中的顶冠、颊斑与对照对象，不使用后面的英国种群统计推出中国情况。

这些是本次实际成功读取的资料。Cornell 的 Four Keys 与 All About Birds 两个物种页返回 403，因此没有把它们列作已经核读的根据；也不把其他成功返回的网页外壳当作读到了完整物种资料。

## 为什么选择这个对照

本章不追求列出最多鸟名，而是通过一个例子解释三种常见推理错误：

1. **颜色不带位置。** 栗色或黑色本身太粗，需要说清顶冠、面颊还是喉胸位置。
2. **单张成年雄鸟替代所有个体。** 家麻雀的雌鸟和幼鸟不符合成年雄鸟的整套外观描述。
3. **名字或所在地替代形态。** “Tree” 与 “House” 不是站在树上或房屋上的判定规则。

RSPB 与 BTO 对 *P. montanus* 的栗褐色顶冠和浅色面颊中的深斑描述相合；RSPB 另给出雌雄相近、幼鸟较淡的限制。家麻雀的对照来自 RSPB 自身条目。本章把这些特征重组为辨认示例，没有宣称只靠两个特征即可排除世界上所有相似鸟种。

## 地理和资料范围

RSPB 的英国保护等级、英国种群下降和地图均有自己的对象与时间。本章没有搬用它们描写中国。其 Tree Sparrow 条目甚至在行为环境中区分英国和欧洲大陆，更不能因为“我在城市”就用英国条目一票排除某个候选。

确定某条本地记录，需要地区、日期、可见特征和其他候选信息。这里没有完成中国各地区名录、季节、亚种或罕见记录的核验，不提供遇见概率和目的地推荐。

## 不是作品观察或性能保证

本次没有播放来源中的鸟声录音，没有逐张目视核验照片，也没有下载或复用来源的图片、音频。正文对物种形态的描述来自文字，不声称由本书的野外照片确认。

行为片段、观察维度、声音归属问题和软件候选工作流均为本书的解释与建议，**不是这些物种条目验证过的识别算法**。本书没有比较不同认鸟软件的准确率，没有给不完整观察签发定种结论，也没有证明辨鸟训练能够提高幸福感。
