# F02 来源记录：听音乐可以使用哪些词？

**来源类型：制作者发布的音乐入门教学，不是心理效果研究。概念可以帮助描述，不证明学会概念必然更享受音乐。**

## 读取了什么

来源是 Ableton 的官方教学项目 [Learning Music](https://learningmusic.ableton.com/)，核读日期为 2026-09-29。此次读取首页及以下五页的文字说明：

| 页面 | 本书使用的基础概念 |
| --- | --- |
| [Beat and tempo](https://learningmusic.ableton.com/make-beats/beat-and-tempo.html) | beat 可指鼓的节奏型，也可指基础脉冲；tempo 是进行速度，BPM 表示每分钟拍数 |
| [Make melodies](https://learningmusic.ableton.com/make-melodies/make-melodies.html) | 旋律是单音形成的线条，可由歌声或乐器承担 |
| [Make basslines](https://learningmusic.ableton.com/make-basslines/make-basslines.html) | 低音线使用低音区音符，可能与和弦及鼓的节奏配合或形成对照 |
| [Make some chords](https://learningmusic.ableton.com/chords/chords.html) | 该入门课把和弦解释为同时发声的一组不同音高 |
| [Play with song structures](https://learningmusic.ableton.com/song-structure/song-structure.html) | 段落的组合形成歌曲结构或曲式，编排把小材料组织成完整作品 |

这是选读，不是完成课程。没有逐项操作和验证所有交互、音频播放、语言版本或辅助技术兼容性，也没有复制其示例歌曲、声音片段、图像或互动代码。

正文的贝多芬与巴赫谱例另据 [F15](F15-musical-scores.md)，不是该课程的示例，也不表示本书已试听特定录音。

## 能支持什么，不能支持什么

这些页面可支持正文中基础术语的说明。正文由此提出“先描述想保留什么、再选择改变什么”“注意某一条声音”“区分速度与节奏疏密”等入口，属于本书原创提议。

它们不是实验证据，不能写成：

- 只听一条声部必然提高快乐或专注；
- BPM 越高越刺激，某个速度适合所有人；
- 所有音乐都必须具有同样的主歌、副歌、旋律和和弦结构；
- 听不出术语对应的东西，就是听觉或审美能力不足。

入门材料的例子与组织方式有其范围。本书不拿它替代所有音乐传统，也不把常见流行音乐结构当作唯一标准。
