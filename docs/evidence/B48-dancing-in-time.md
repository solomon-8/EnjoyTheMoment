## 两个人都在场，改变的是听到的时间关系

48人组成24对，自选让自己感到自在的伙伴。年龄19–31岁，均值25.17，多为在芬兰的国际学生；20对女性、3对男女、1对男性。62%有某种正式舞蹈训练，85%有正式音乐训练，77%自认当时是活跃音乐人；不是一般人群随机样本。

研究在动作捕捉实验室进行，参与者戴无线耳机，按听到的音乐自由动作，不学习指定舞步。每对经历全部三种条件，条件顺序随机；每种条件有12段30秒音乐，由六首歌的片段各呈现两次组成，以平衡谁听到先后或变速版本。

- **同步**：双方同时听相同版本；包括双方都听原版，也包括双方都听变速版，避免把单纯变速的影响当作两人不同步。
- **速度不同**：一人听原版，另一人听向120 BPM方向作小幅变速的同曲版本；两人的先后会不断变化。
- **相位错开**：速度相同，一人的开头延迟四分之一拍，即90°；这一段中的拍点保持固定错位。

这三项不等于“有音乐／没音乐”“独自／有人陪”，也不等于“努力跟上／故意不配合”。参与者被告知双方总听相同音乐，实验结束后才获知操纵；因而不能把结果说成他们知情选择了不同步。

正文描述速度改变为5%；表1中一首歌从115到121.675 BPM，与统一5%的写法不一致。本书没有音频或代码来判断实际用了哪一个值，不替作者改成某个“正确”数字，也不将速度当作可照搬的活动参数。

## 五个问题，不是一份总快乐分

每完成一种条件，参与者轮流独立作答，量尺1–10。问题涉及：

1. 与伙伴互动的质量；
2. 对这项任务的享受；
3. 舒适程度；
4. 焦虑或紧张；
5. 对音乐的享受。

作者把第一项作为主要分析目标，其余用于探索及避免反复作答时过度聚焦互动。论文对量尺的总说明是1偏负面、10偏正面，但没有逐题完整交代紧张题的计分方向；不能据总说明重构全部问卷编码。

自报结果按48名参与者报告：互动质量Friedman检验χ²(2) = 10.75，p < .01。Bonferroni校正的Wilcoxon配对比较，仅同步与相位错开显著，W = 454.5，z = −3.109，p < .01，同步条件评分较高。其他两两比较未显著。

**其余四个问题没有报告显著条件效应。** 所以“互动评分更高”不能改写成“任务更好玩”“音乐更好听”或“焦虑降低”。未显著不等于证明等效，更不是每位参与者都没有变化。

作者在讨论中明确说明，为适应同一伙伴的重复测量，他们没有直接问社会联结强弱，而是问这次互动质量。把第一项解释为社会亲近的线索，是作者的解释；不应当作已经测到长期友谊。

## 动作数据测到了什么，没测到什么

全体佩戴反光标记，但因技术问题，主要动作分析剩19对。每段只分析开头10秒之后的20秒，先给参与者时间找到节拍；不是连续跟踪整晚。

**头部相对朝向：** 用双方头部标记计算各自朝向相对伙伴的夹角，再相加，构成head divergence指标；不是数“对视了几次”，也不是眼动仪。作者报告总体条件效应F(2,54) = 3.45，p = .042；进一步比较在同步与相位错开之间显著，报告p = .033，同步的偏离较小。头部朝向变化的方差未显著，p = .078。

**人际距离：** 按双方头部中心点估计。平均距离的条件差异未显著，p = .22；距离变化的方差也未显著，p = .95。不能写成“同步使两个人靠得更近”。

**动作相位锁定：** 另用髋部垂直运动速度检查时序关系，因髋部标记缺失再去掉2对，剩17对。结果的相位关系稳定度排序是同步最高、相位错开居中、速度不同最低，三组配对差异均显著。但主观互动评分并没有按这三档都拉开显著差异。身体指标不是给感受排好的名次。

## 需要保留的方法与数字疑点

- **分析单位：** 研究设定说把双人组作为单位，互动评分分析却按48人报告；文中没有充分说明这一步怎样处理同组伙伴回答可能相关。动作分析则按19对，不把两种n混在一起。
- **自由度与检验说明：** 文中将19对、三条件的动作检验称为重复测量ANOVA，却报告F(2,54)。常规未校正的该设计通常给出不同的误差自由度；没有数据、代码和完整模型说明，无法确认实际检验怎样执行。成对事后检验又同时给出Tukey说明、t(18)、r与p，本书只按报告辨认方向，不据此重算可靠性或宣布结果无效。
- **速度数字：** 表1的一处BPM与“5%”描述不一致，见前节；讨论对四分之一拍毫秒数的概括也不能替代每首曲子的实际换算。本书不输出同步阈值。
- **指标不是机制：** 头转向伙伴可以是注意线索，但没有眼动追踪；感觉听到的拍点与看见的动作冲突、判断伙伴节奏能力、社会互动需要等解释，没有被彼此排除。作者也承认该研究没有解释清楚效果为何发生。
- **样本与外推：** 自选伙伴、多有音乐训练、小样本，未测陌生人破冰、大型人群、观众合唱或长期关系。19对和17对的动作资料又少于招募样本。

这些不是“所有结论都不能谈”，而是限定谈到哪里：原报告呈现了特定条件下互动评价与部分动作指标的差异，同时保留若干未显著结果和方法不清楚之处。不能把它抬成同步必然带来快乐、亲密或顺从的定律。

## 本书怎样使用，不怎样使用

[E02](../../essays/02-excitement-without-escalation.md#excitement-together)用它拆开同场、时间配合、互动评价与个人享受。它补充的是测量上的区别，不与[相处章的共同注意](../../book/05-connection.md#connection-shared-attention)、[舞蹈章的时间结构](../../book/27-dance.md#dance-time-grid)重复记作同一发现。

小禾与阿季的情境及[共同节奏需要让出什么](../../essays/02-excitement-without-escalation.md#excitement-shared-cost)，均为本书的原创规范论证，不是这项实验测到的个体故事。研究没有比较“自由改动”与“自愿协调”哪一种人生更好，也没有授予任何人要求别人继续的权力。

**共同配合可以是本人想要的生活，不需要靠将来的人脉回报证明；它却不是让所有人必须同样尽兴的理由。** 这是本书的立场，不是论文结论。不提供动作技术、安全认证、个人最佳节奏、健康建议或行动卡效果保证。
