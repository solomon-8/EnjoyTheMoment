# B36 / N36 · 被要求增加频率，不等于自发想要更多

## 随机的是指令，不是每次自然发生的欲望

研究对象为35—65岁、合法结婚的一男一女夫妻。筛选要求愿意改变性行为模式，基线性交频率至少每月一次、不超过每周三次；排除糖尿病、高血压等部分健康状况，以及相关身体不适或围绕性的关系紧张。不能推广为任意年龄、取向、关系形式、健康情况或有冲突者的建议。

按年龄及频率分层随机；指令在基线问卷后给出。干预组被要求在90天中将基线频率翻倍；两人基线报告不同或给出区间时，采用较高值制定目标。对照组无频率指令。问卷报酬与填写有关，**不是按性行为次数付钱**，也不按完成翻倍目标付钱。

正文解释排除、可用数据不足与分层分配后，表1可用样本为对照58人、干预70人，即29对与35对，共64对。表2的对照表头却为60人；本次未取得数据以确定差异来源，保留口径疑点，不自行补成另一个样本。

参与者每天独立填报。基线回顾频率与实验期逐日报告不是同一种测量，作者认为前者可能偏高。两组婚龄、教育及部分心理测量不平衡；这一点影响心情结果的解释。

## 行为、欲望、享受与心情分别测量

- **频率**：基线回顾及实验期逐日报告；表4按男性和女性报告分别建模，不把夫妻两人当两次独立行为。
- **心情**：每天询问情绪，主要因变量为选取的PANAS条目合成分数，再对已填写日取平均。不是“婚姻幸福”或完整人生价值量表。方法列出九个合成条目，但后文又讨论14个单项，不能把两种口径混为一谈。
- **欲望**：表6为三个相关条目之和；不是对某次接触的同意测量。
- **享受**：有性行为时才问的单项评价；不是每一天均有可比较的体验记录，也不能当作同意已经成立的证明。

## 结果与不能省略的限制

干预组实验期频率高于对照组，但平均没有翻倍。正文把模型结果概述为约40%的提高；表4注明使用对数链接，系数不是可以直接乘100的百分比。本书正文只采用方向与“未平均翻倍”，不把该近似叙述重算成精确效应或个人目标。

表5九个模型中的干预系数均为负。基础模型为−2.6，标注p < .05；加入基线单项幸福或人口学变量的模型II/III为“+”，仅表示p < .1。正文称其仍显著，必须带上作者使用的门槛。加入婚龄的模型IV为−1.9，**未达到p < .1**。不能只摘基础模型，宣布稳定证实“更多性行为降低幸福”。表注称夫妻随机效应，正文称夫妻层聚类标准误；未核代码，保留模型描述差异。

表6欲望结果：I—III的干预项仅为p < .1，IV—V为p < .05。表7享受的五个模型干预项均为负、达到p < .05或更严格门槛；它回答的仍是特定指令下的自报享受，不是证明频率本身必然有害。表7模型IV的年龄项印作−3.79，标准误.011，而相邻模型接近零；目视确认该异常印在PDF中，本书不使用它解释年龄效果。

加入欲望/享受变量后，表5的干预系数减小，作者因此讨论动机解释。但这些中间变量没有单独随机化，不能凭系数变化宣布因果机制已证实。“没完成配额导致羞愧”也不能冒充结果：干预组目标与实际差距同心情的简单相关为−.01，p = .93。

表8的双方时间协调分析明确为**事后分析**。正文说欲望与单项幸福的协调降低，但表中欲望p = .2、单项幸福p = .03，多项心情p = .45；享受协调反而更高，p = .02，且仅行为发生日能测。不能概括为所有协调都显著下降。表中最多124次观测与正文90天设计的关系未交代清楚，本次没有补充材料核解。

## 作者最后收窄的问题

论文讨论明确区分：这项实验回答“要求夫妻增加频率怎样影响心情、欲望与享受”，**没有回答自发发生的频率与幸福是否具有因果关系**。要求可能改变活动动机，是解释候选，不是单独随机操纵的机制；通过减轻照护、旅行等改变条件，是讨论中的未来设想，不是本研究已验证的方案。

[C35](../../book/35-intimacy.md#intimacy-frequency)据此拒绝把次数作为多种体验的共同代理；关于自愿、期待差异、相处安排与价值排序的论证是本书原创，不是论文结论。研究没有评估J卡、个体性健康、同意质量，也没有给出任何人的最佳频率。希望更多或更少，都不能拿这项研究代替当事人选择。
