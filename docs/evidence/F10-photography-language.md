# F10 来源记录：摄影术语帮助描述，不替人决定好看

**来源类型：设备厂商的摄影教学词汇表。用于基础概念，不作为购买背书或完整摄影课程。**

2026-09-29 读取尼康美国站 [Photography Glossary](https://www.nikonusa.com/learn-and-explore/photography-glossary)，核对 Aperture、Shutter Speed、Depth of Field、Composition、Perspective 与 Side Lighting 的定义。没有审核整个大型词汇表的全部产品条目。

第 20 章采用的有限内容：

- 光圈是镜头开口，光圈值较小表示开口较大；快门速度涉及曝光持续时间。
- 景深是对焦对象前后可接受清晰的范围，并受光圈、焦距及拍摄距离等条件影响。
- 构图指画面元素的安排；透视涉及三维对象在平面上的相对大小、距离与深度关系。
- 侧光来自对象侧面，可用于呈现受光侧的细节与纹理。

这些定义不推出某套参数必然“出片”，也不规定照片必须明亮、背景必须模糊或主体必须放在特定分割线上。关于画框取舍、与同伴协商、用途和分享的讨论是本书的原创分析。
