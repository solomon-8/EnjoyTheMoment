## 人数、材料与分配

论文报告在北京师范大学招募102人，分成12名材料评级者、59名实验一参与者、31名实验二参与者。招募期为2019-10-10至2023-09-16，不是2024年的同一天。排除电影专业参与者；样本与任务不能直接代表一般电影观众。

51段脸部片段经作者内部选择留下30段，男女各15；分配到恐惧、中性、愉快三组。每组10段情境视频。前后同脸的2秒—4秒—2秒结构，包含同一序列内的重复；不同条件使用不同的面孔和情境，**不是让每一张脸轮流接受全部三类情境**。

影片灰度化、去掉声音；面孔蓝幕背景按情境合成。作者称这些措施更接近电影连续性，但没有直接测得比另一版本更沉浸或更好看。不同面孔、情境与背景处理共同存在，不能视作只更换背景的一因素纯隔离实验。

实验一按恐惧—中性—愉快或反向安排两种区组顺序，不是全部六种排序；实验二使用六种区组顺序、区组内随机和4–6秒抖动间隔。两次的量尺与设备不同，不能合并平均分。

## 关键结果不是一个总分

| 实验与指标 | 恐惧／中性／愉快的报告均值 | 主效应 |
| --- | --- | --- |
| 实验一，面孔正负评价，−1至1 | −0.45／0.07／0.27 | F(1.6,92.5) = 104.05，p < .001，偏η² = .642 |
| 实验一，演员情绪强度，1至5 | 此处不另抄均值 | F(2,57) = .13，p = .879，偏η² = .005 |
| 实验二，正负评价，−4至4 | −1.48／−0.16／0.89 | F(1.5,45.9) = 60.10，p < .001，偏η² = .667 |
| 实验二，唤醒评分，1至9 | 5.27／4.20／4.94 | F(2,29) = 9.92，p = .001；效应量存在下述冲突 |

两次正负评价的Bonferroni两两比较均报告p < .001。实验一的强度不显著，不能写成已证明所有情境完全一样；也不能用实验二的唤醒显著，替代实验一强度的结果。

实验一有7人听说过该效应、52人没有。观影频率分布为42人每周0–2部、16人3–5部、1人6–8部。未显著的知识或频率分析，不证明知识和经验永远不影响观看，更不是“分析不会破坏快乐”的实验。

## 保留的表述与统计疑问

- 实验二唤醒偏η²，正文报告 **.406**，图3D图注报告 **.005**；两者不一致，不能任选一个充当已核正结果。
- 中性面孔预评均值在材料段为 **−0.02 ± .14**，结果段为 **0.02 ± .13**；保留差别，不擅自改正。
- 作者在部分方法与讨论中把唤醒量尺描述成观众生理反应；实际任务使用主观评分，图3又将其标为面孔的唤醒。**评分不是客观外周生理记录，评价对象也有表述歧义。** 不把这一项直接写成测得观众心率、身体兴奋或享受。
- 部分F检验自由度与常见单变量重复测量写法不同；没有分析输出，不能仅凭自由度外观断言计算错误或自行换算。

## 神经影像不能补出什么

31人的分析比较第二次面孔与第一次面孔，并进一步比较情境间的差异之差。论文报告FDR p < .05、5体素阈值；校正后没有检出其讨论中提及的杏仁核活动，不是全部既有结果都得到复现。

激活与某类心理过程相关，不自动证明唯一因果机制。第一次与第二次呈现的位置、情境经历及重复共同改变；脑活动不能独自告诉我们观众是否喜欢、影片是否真实，或者哪个导演能随意控制反应。
