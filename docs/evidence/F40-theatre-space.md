## 原文支持的区别

Proscenium 有建筑框架，名称中的 arch 不表示框架一定呈拱形；其前沿有时伸出框架。Thrust 的表演区向观众伸出，观众位于三侧。In-the-round 的中心表演区被观众从四周围合，但形状不必为圆。Black-box / studio 可以改变座位布置，不固定等于上述任何一种。

来源也区分 site-specific 与 promenade：前者通常利用非传统表演地点及其环境意义，后者让观众随演出移动。这不是互斥分类。大型 arena 与 in-the-round 有相近的围合关系，规模和设施描述不同；正文图示不承担完整分类。

本书“镜框式”“伸出式”“四面围合”“特定场域”“行进式”为相应词语的中文表达。它们不证明某个中文售票页面采用同一口径，应另看该场具体说明。

## 哪些是本书推导

正文的“它把我放在哪里看”、演员转向使不同方向看到不同侧面、对面观众可能进入视野，属于从空间关系出发的观看分析。没有在真实场馆测量视线、声学、观众注意力或亲密感。

来源将伸出式与增加亲近感的用途联系起来；本书没有把用途写成每个位置必然产生的效果，也没有给三种形式排优劣。原文对围合式布景避遮挡的介绍不是任何实际制作无盲区的保证。
