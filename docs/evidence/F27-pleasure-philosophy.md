# F27 快乐的价值：两份原作数字文本与一份二手哲学解说

**来源类型：哲学文本与二手学术解说。不是行为实验，不是某种人生观已经获得科学验证。**

核读日期：**2026-09-30**。本文区分直接读取的原作数字文本、百科转引及本书自己提出的例子。`philosophical_primary_and_secondary` 表示混合来源类型，不表示原书、译文、版本与相关研究都已核验。

## 伊壁鸠鲁：读取的是英译数字文本

- 入口：[MIT Internet Classics Archive，Letter to Menoeceus](https://classics.mit.edu/Epicurus/menoec.html)。
- 页面署名 Epicurus，译者 Robert Drew Hicks。核读书信页面，实际采用关于快乐、选择与避免，以及不把享乐等同连续宴饮的段落。
- 能支持的概括：快乐作为目标，不推出选择每一项快乐；比较后续烦扰与快乐会影响选择。文本对身心不受扰的重视，不能改写为推崇刺激升级。
- 没有读取希腊文底本，没有与纸本译文或校勘本逐字比对。该网页有明显转录缺字与断句异常，例如谨慎段落中的不完整句；本文不据这些残缺句建立论点，也不自行修补后冒充原文。
- 书信中的健康、痛苦与其他人生判断属于哲学文本的内容，不是本书核验过的医学事实。本书未采用其中关于死亡的劝说，也不从它生成健康处方。

正文对平静与波澜的区分、假设中的出门选择，是本项目的讨论，不是伊壁鸠鲁的案例或对他的整套学说的概述。

## 密尔：第二章相关论证，不是现代品味调查

- 目录：[Project Gutenberg #11224](https://www.gutenberg.org/ebooks/11224)；文本：[Utilitarianism](https://www.gutenberg.org/cache/epub/11224/pg11224-images.html)。
- 数字本题名页标示 1879 年第七版。数字记录发布于 2004-02-01、更新于 2024-10-28；不是用这两个日期给思想或纸本定年。
- 实际采用第二章关于快乐作为目的、质量与数量、熟悉两者之人的判断，以及能力与机会可能失落的段落。定位短语包括 “quality is considered as well as quantity” 和 “competent judges”。没有声称完整核读全书或核验所有版本差异。
- 不把“更高质量”的论述压缩成价格、艺术门类或作者名望的排行榜。密尔讨论的道德标准也不是只让行为者本人愉快；因此不能据书名或“快乐”一词把其功利主义等同自私。
- 正文“谁有资格替别人决定”“如何对待熟悉两者却意见不同的人”等追问，是本书对论证的分析。不是密尔亲自承认的漏洞，也不是调查得到的受众结论。

正文区分一次选择与稳定比较判断，保留密尔对未选较高快乐的回应，不用“有人今晚没读书”声称已推翻其理论。

## 诺齐克：实际读取的是二手条目中的 1989 年表述

- 来源：[Internet Encyclopedia of Philosophy，The Experience Machine](https://iep.utm.edu/experience-machine/)，页面作者 Lorenzo Buscicchi。
- 实际核读第一节的原文引文及时间设定说明、第二节关于目标理论的解释，并阅读第七、八节对改变起点与方法问题的讨论。条目将第一节引文归于 Nozick 的 *The Examined Life*（1989）。
- **没有直接核读《无政府、国家与乌托邦》1974 年原版或《经过审视的生活》1989 年原书。** 尝试访问的多份大学托管候选 PDF 未能取得内容，不能称为原典核读。
- E11 据二手条目压缩转述的条件包括：内在体验可编排、接入后不记得这是机器造成的、不确定性可以模拟，以及是否为余生选择它。没有把这一版本与两年一段的其他表述混写。
- 本书不采用条目列举的参与者比例、实验结论或关于学界共识的概括。未核读那些研究，不能从二手数字声称大多数人怎样选择、偏差已被证明或享乐主义已遭证伪。

正文的两种相聚、抽屉、观鸟、游戏与互动服务例子，是本项目写作的假想，不是实际产品、真实访谈或诺齐克原书案例。反向设问关联条目第七节讨论的改变起点，本文不声称独创；没有采用二手转述的实验统计。“关系、行动与结果、接触世界”是本书组织理由的方式，不冒充原书的逐项引述。

## 来源究竟承担什么工作

这三组材料承担的是不同哲学立场和问题设置的来源说明，不是支持某项活动效果的证据：

1. “快乐值得”“只有快乐值得”“人人只追求快乐”“必须最大化快乐”是正文用于澄清争论的区分；命题之间不能因为共享同一个词就相互推出。
2. E11 选择多种价值可以并存的立场，不宣称建立了普遍有效的排序算法，也不宣称三位思想家赞成本仓库。
3. 不把体验机器等同现实中的游戏、小说、数字社交或具体 AI 产品；虚构对象、真实参与和被误导的对象认知需要分别讨论。
4. 没有读者测试、实际机器实验、心理诊断或快乐测量。本文不增加背景研究数量，也不改变行动卡的原创试做性质。
