# F54 《卧室》书信：作者自述、编辑判断与作品版本

- **核读日期**：2026-09-30（UTC+08:00）。
- **来源类型**：`artist_letters_in_scholarly_edition`，学术编辑版提供的书信英译、元数据与注释；不是观众实验，也不等于直接核读手稿。
- **用途**：讨论颜色与休息的创作目标、平面色调与厚笔触、信件所指对象，以及意图与反应的区别。

## 直接支持什么

705英译说，颜色与简化应使卧室画表达休息或睡眠；随后列出若干部件的颜色，提到去掉阴影、以平面色调接近日本版画。706英译也谈休息目标，并把平面色调与粗厚涂抹并列。本章以此解释“色调安排的平”与“颜料痕迹的厚”不必矛盾；这一步概念展开是本书分析。

两封信的日期来自编辑判断。705元数据通过前后信与休息日程推定日期；706元数据通过Gauguin拟来访日期及通信先后推定。本章使用编者日期，不写成两封手稿都明署该日期。

两页注释对应的油画是F482 / JH1608。705所附草图为JH1609，706信中草图为JH1610；草图编号不是另一幅油画的馆藏号。705注释指出挂画、帽子及盆等差异，推断油画可能在附图之后改动；本章保留推断语气，没有自己看图核实。

706元数据还解释，这封信曾被收入致Bernard信集，后来的版本沿用了容易误导的B22编号；当前收信人为Gauguin。不把“被收入信集”误写为该信原本寄给Bernard，也不把旧编号当作另一封同文信。

## 与F13馆藏说明的差异

重新读取芝加哥艺术博物馆[作品28560的对象记录](https://api.artic.edu/api/v1/artworks/28560)，HTTP200，20,896字节。这是F13已有对象，不算新的独立证据。该画为1889年第二版，不能混作1888年书信所谈的F482 / JH1608。

馆方`description`把一串颜色描述归为致Theo信。但所读两封信中，馆方引用措辞更接近706致Gauguin的对应段落，例如地面与家具的用词；705的对应措辞并不完全相同。本书保留来源间的这一差异，不自行指定它来自另一封尚未核读的信，也不凭相似措辞宣布已经完成引文溯源。

正文只概述两封信共同支持的休息目标，并明确把平面色调与厚涂并列的段落定位到706。没有复制馆方颜色引文再重新标成705原话。

## 不能由此推出什么

信件说明梵高如何向收信人描述自己的工作，不证明所有真实动机都已完整说明，更不证明观众必然平静或某种用色有普遍疗效。706关于工作状态的比喻不作精神状态诊断。

两封信也不独自提供整幅画的精确色值、完整修改顺序、颜料老化速度或颜色重建方法。修复与变色采用的另是[F55](F55-bedroom-conservation.md)所列馆方说明，不把两类来源合成一项本项目已做的实验。
