# 七天试吃，不是七天挑战

“天”只表示七种场景，不要求连续，不要求全做。你也可以只挑一个。

以下是原创试做路线，不是干预研究，没有承诺七天以后更幸福。预算上限不是要求花掉的金额。

| 一次试吃 | 今天试什么 | 时间 / 新增费用上限 | 不合适时 |
| --- | --- | --- | --- |
| 第一口：立即 | [只听一首喜欢的歌](../book/01-start-now.md#j001) | 5 分钟 / 0 元 | 听半首，或者跳过 |
| 第二口：感官 | [比较两种熟悉的味道](../book/02-senses.md#j010) | 20 分钟 / 20 元 | 只用现有食物；不适合食用就不做 |
| 第三口：新鲜 | [给熟悉路线开一条支线](../book/03-novelty.md#j013) | 20 分钟 / 0 元 | 不出门，只观察窗外 |
| 第四口：刺激 | [开一局真正想玩的游戏](../book/04-play.md#j019) | 60 分钟 / 0 元 | 换十分钟可结束的版本 |
| 第五口：关系 | [发一个具体邀请](../book/05-connection.md#j025) | 发邀请 10 分钟 / 0 元 | 写下来但不发送也行 |
| 第六口：无用 | [给一个爱好取消成果要求](../book/04-play.md#j024) | 30 分钟 / 0 元 | 随便玩五分钟 |
| 第七口：留白 | [留一段不需补偿的空白](../book/08-permission.md#j043) | 30 分钟 / 0 元 | 什么都不额外安排 |

## 唯一可选的收尾

不需要每天打分。愿意的话，最后只回答：

- 哪一次是我真的想重复的？
- 哪一次只是看起来应该好玩？
- 有没有比原方案更便宜、更省事、更适合我的版本？

只保留你喜欢的。**没有“全部完成”这个奖品。**

不想记在纸上也可以。想留一张私人菜单，复制[这个模板](../templates/my-menu.md)，不用发到公共仓库。
