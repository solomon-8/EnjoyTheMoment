# 怎样带走这本书

**不用从头读完，也不用把行动卡当作作业。先找到一个与你有关系的问题。**

想知道我们在争论什么，先读[耍起：把快乐当正事](../SHUAQI.md)与[为什么快乐必须证明有用](../essays/01-pleasure-is-an-end.md)。想从具体乐趣进入，可以读[音乐](../book/11-music.md)、[电影](../book/12-film.md)、[味道](../book/14-flavor.md)或[收藏](../book/26-collecting.md)。找跨章节的问题，使用[阅读地图](reading-map.md)。

## 三种读法，各自保留什么

| 读法 | 适合什么 | 需要知道的区别 |
| --- | --- | --- |
| 仓库 Markdown | 按章读、核对出处、提出具体纠错 | 章节与研究记录是内容源；外部链接需要网络 |
| 单文件 HTML | 浏览器搜索、筛选、跨章跳转；下载后离线打开 | 不需要账号；文字、图像与脚本在同一个文件里 |
| [下载 EPUB](../downloads/EnjoyTheMoment.epub) | 放进支持 EPUB 的阅读器，使用其目录、字号、书签和阅读进度功能 | 本书不收集阅读进度；阅读器自身的同步或隐私设置另行决定 |

EPUB 不是摘要版。它包含核心长文、生活章节及原有卡片、完整玩法、阅读地图、研究台账与核读记录、文化背景、编辑标准、来源和素材署名。章节里的折叠内容在电子书中直接展开，避免不开折叠就漏掉条件。正文配图随书保存，不需要联网才能看图。

电子书不提供网页的随机抽卡和筛选按钮；目录与文内链接可以帮助跳转。研究编号、卡片编号和原有引用保持一致。可以从正文进入来源记录，也可以沿记录里的链接回到论证；外部原文、仓库首页和代码文件仍需要网络。电子书附有许可说明，第三方材料不因被打包而变成本项目原创。

## 大表格与图像怎样读

字号和分页由阅读器决定。表格保留原来的各列，不把不利结果、研究限制或成本列删成一句“结论”。在窄屏或大字号下，可能需要使用阅读器的表格横向滚动、横屏或缩放；若阅读器截断表格，请改用网页或 Markdown，不要把不可见的一列当作不存在。

图像有替代文本，章节也保留文字解释。图解里的假设、原作与数字复制的区别、裁切和署名说明仍应一起读。我们不把某一种设备上的显示检查，称为所有设备或辅助技术都已兼容。

## 怎样确认一句话的性质

本书区分价值主张、原创假想、个人经历和研究结果。正文支持一个选择的资格，不等于实验已证明该选择能让每个人快乐。阅读研究时，要保留样本、版本、测量指标、未显著结果和外推边界；[研究台账](research.md)与具体核读记录提供这些信息。[编辑标准](editorial-policy.md)同时说明 AI 辅助起草及实际验证范围。

文中金额和时长若标为假设或预留上限，不是实时报价或效果承诺。行动卡是原创试做，不是研究验证的处方；不想照做，可以只读论证，或者不同意它。

## 离线不是自动更新

已经下载的文件不会自行变成仓库的新内容。需要当前文本时，请重新下载；正文中的出处与核读日期不因下载日期改变。本书不会在离线文件里加入后台更新、统计或阅读记录上传。

EPUB 是中文全文版，不是全书英文译本；英文首页是导读。当前没有单独排版的 PDF 版，不把浏览器“打印为 PDF”称为已验收的电子书排版。
