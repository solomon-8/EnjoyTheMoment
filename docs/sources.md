## 借鉴什么，不借鉴什么

**借鉴：**

- 一个清楚、可讨论的价值主张。
- 先按读者问题导航，再进入具体章节。
- 每条尽量给到动作与代价，不只说口号。
- 建立纠错与反对意见入口。

**本项目的组织方式：**

- 每张卡写明“现在做、想得到、付出、换小份、散场线、性质”。
- 以个人选择为中心，不建立快乐排行榜。
- 包含零元、小份、独处和可中断的版本。
- 用显式 `J001` 等编号支持稳定链接与本地随机筛选。

**不复制：**

- 原仓库正文、数字、医疗或法律结论。
- 原有视觉素材、脚本、网页、赞助配置和 Git 历史。
- 原作者身份、语气人格、经验故事或项目背书。

## 研究引用与文化来源

“现在的快乐应该占多大权重”首先是价值判断。[四篇背景研究](research.md)分别写明全文或摘要读取深度、设计、能支持什么及不能支持什么，不充作行动卡效果证明。

“耍起”的传播材料另见[文化来源台账](culture-shuaqi.md)。本项目定义、媒体解释和人物原话分别标记，不冒认背书。两类来源都按[编辑标准](editorial-policy.md)处理。

## 关于“能否获得社会关注”

醒目的主张、具体的争论点、可以实践和贡献的内容，是本项目的设计选择，不是走红预测。没有购买传播、制造虚假互动，也没有声称已有用户效果。

能不能引起讨论，要由真实读者决定。
