## 借鉴什么，不借鉴什么

**借鉴：**

- 一个清楚、可讨论的价值主张。
- 先按读者问题导航，再进入具体章节。
- 每条尽量给到动作与代价，不只说口号。
- 建立纠错与反对意见入口。

**本项目的组织方式：**

- 核心长文提出价值冲突、论据与反对意见，不要求读者先认同口号。
- 生活章节展开各个领域的具体问题、判断依据和真实取舍，不只列出活动。
- 来源记录区分研究结果、事实说明与本书推导，并保留不能支持主张的结果。
- 行动卡是配套：每张写明“现在做、想得到、付出、换小份、散场线、性质”，不是本书价值的唯一尺度。
- `C`、`E`、`J` 等编号分别定位章节、长文和行动卡；阅读与检索不必以执行某项活动为终点。
- 保留零元、独处和可中断的选择，但不把所有快乐缩小成省钱、省时的任务，也不建立快乐排行榜。

**不复制：**

- 原仓库正文、数字、医疗或法律结论。
- 原有视觉素材、脚本、网页、赞助配置和 Git 历史。
- 原作者身份、语气人格、经验故事或项目背书。

## 关于“能否获得社会关注”

醒目的主张、具体的争论点、可以实践和贡献的内容，是本项目的设计选择，不是走红预测。没有购买传播、制造虚假互动，也没有声称已有用户效果。

能不能引起讨论，要由真实读者决定。
