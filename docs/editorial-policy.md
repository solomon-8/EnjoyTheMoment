# 编辑标准：不要把价值观伪装成实验结果

## 一、四种内容，分开标记

| 类型 | 可以怎么写 | 不可以怎么写 |
| --- | --- | --- |
| 价值主张 | “我们认为快乐不必为生产力服务” | “科学已经证明及时享乐是最优人生” |
| 原创试做 | “试着听一首歌，看看自己喜不喜欢” | “听五分钟必然改善情绪” |
| 个人经历 | “投稿者说，这个版本对他有效” | “很多人都这样，所以一定适合你” |
| 可核验事实 | 原始出处、对象、时间、结论与局限 | 无出处的数字、把相关性写成因果 |

60 张行动卡全部是**原创试做**。时间和钱是作者设计的预留上限，不是实测完成时间、实时市场报价，也不是行为科学阈值。

## 二、卡片最低要求

每张卡有固定 ID、标题、显式链接锚点、机器可读筛选信息，以及六项正文：

- 现在做；
- 想得到；
- 付出；
- 换小份；
- 散场线；
- 性质。

标题必须是人能采取的动作。不能只写“学会爱自己”“保持松弛”“提高生命浓度”。

“想得到”不得暗示保证。“换小份”不得把贫困、照料负担或身体限制说成借口。“散场线”应具体且与该活动有关，不要用一段通用免责声明代替。

## 三、筛选信息不是推荐分数

```json
{"id":"J001","minutes":5,"budget":0,"company":"solo","energy":"low"}
```

- `minutes`：主方案预留的分钟上限，不是成功最低剂量。
- `budget`：主方案新增人民币花费上限；已经拥有的资源不在此重新计费。
- `company`：`solo` 为独自活动，`social` 需要其他人，`either` 两者皆可。
- `energy`：粗略参与负担 `low` / `medium` / `high`，不是身体能力评估。
- 所有费用还要以本人实际情况为准；不能在上限内找到选项，就换小份或跳过。
- 规划、发邀请与实际消费是不同活动，不能把规划卡的 0 元冒充后续活动免费。

筛选器只匹配这些字段，不排序幸福、不预测效果、不使用个人画像。

## 四、哪些内容需要外部核验

涉及健康效果、医学、法律、金融、交通、票价或具体活动开放时间时，不能靠记忆补齐。

引用研究时，记录题名、作者、年份、原始来源、研究设计、研究对象、主要结论和不能推出什么。不把观察性结果说成因果，不把单项小研究说成共识，不用统计相关替价值偏好作决定。

不仿照参考项目的 A/B/C 标记给主观建议镀金。现有四篇背景研究见[研究台账](research.md)，读取深度不等于质量评级，也不升级卡片的依据类型。梗和文化报道另见[文化来源](culture-shuaqi.md)，不把热度或媒体评论当作效果证据。

## 五、社区边界

- 不以他人的同意、隐私、安全或共同财产为娱乐成本。
- 不收录自伤、伤人、胁迫、赌博追损、危险挑战或不明物质的操作指南。
- 不伪造案例、专家背书、用户数量、论文和传播效果。
- 不刷 Star、不购买虚假互动、不去其他项目骚扰式引流。
- 不做消费鄙视链、快乐排名或连续签到。
- 不挂未披露广告、返佣和利益关系；本项目没有广告和返佣。
- 接受反例和无效经历，不要求投稿者先认同项目。

## 六、AI 与实际验证披露

本项目由维护者发起，使用 AI 辅助起草、组织、翻译和编写校验工具。AI 生成不是证据等级，也不应被藏在“作者亲测”之后。

已做的验证是可复查的文件、结构、链接和脚本检查。**没有声称维护者亲自体验过全部活动，也没有进行用户实验或证明这些活动能提高幸福。**

阅读页与 JSON 从 Markdown 同源生成；`python3 tools/build.py --check` 检查漂移。对卡片去重时优先澄清区别和互链，不把已经发布的 ID 静默换成另一项活动。

## 七、改稿优先级

先修危险或误导，再修不适用的默认条件，再修事实和链接，最后修措辞与风格。不能为了保住一句有传播力的口号，牺牲准确性或他人的尊严。
