# 耍起宣言：快乐，不必等批准

这是本项目的短宣言。完整立场、取舍与争论见[耍起](../SHUAQI.md)；不是艺人语录或效果保证。

我们想过一种不必把每个小时都解释成投资的生活。

一顿饭只是好吃，一场游戏只是好玩，一次相聚只是想见。<br>
这些句子可以到这里结束，不必再补一句“对未来有用”。

**好玩，可以是理由的终点。**

## 一、今天不是人生的试用版

保留选择的能力，与亲自经历某个选择，不是同一件事。[准备可以有终点，兑现也应有位置。](../essays/01-pleasure-is-an-end.md#pleasure-options)

## 二、我们公开偏爱及时满足

我们愿意为真正想经历的东西，少得到一些产出、便利或赞许。不保证最后补赚回来，也不保证每次选对。

## 三、刺激，不等于把音量开到最大

悬念、较量、即兴与陌生，都可以带劲。认真喜欢一件事，不需要证明自己敢承受多少伤害。

## 四、低级快乐不是需要忏悔的快乐

喜欢流行歌，不需要毕业到古典乐。认真与随便、热烈与安静，都不该成为衡量别人生活资格的等级。

<a id="五钱是门票不是入场资格"></a>

## 五、买不起，不等于不配喜欢

有些愿望确实需要资源，眼下实现不了，可以遗憾，不必把它说成不值得。账单不替快乐作证；小份可以是另一种选择，不是原愿望已经被满足的证明。[愿望与实现条件，是两回事。](../essays/06-real-life-constraints.md#constraints-necessity)

## 六、别人的自由不是你的娱乐成本

不把同伴的拒绝当扫兴，不把他人的无偿劳动藏在合影外面。共同的快乐，要允许共同决定。 [同意不等于赞许](../essays/01-pleasure-is-an-end.md#pleasure-consent-scope)：不替别人答应参与，也不等所有人欣赏同一种快乐。

## 七、我们不是主张活得短

我们不把享乐伪装成工作策略，也不把失控伪装成勇敢。改变的是价值排序，不是把安全建议倒过来。

<a id="八允许无聊允许难过允许退票"></a>

## 八、允许无聊，允许难过，也允许改主意

没有每天开心的作业。钱未必退得回，也不必靠继续忍受，证明当初喜欢得正确。已经答应的组织、收尾或同行安排，仍要说明、协商和处理影响；[改变主意，不等于约定自动作废。](../SHUAQI.md#shuaqi-exit)

**耍起。把资源换成想经历的生活，而不只把生活换成更多资源。**
