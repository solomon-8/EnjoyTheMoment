# 35 · 亲密值得追求，但不是关系里的交付指标

**想被喜欢的人靠近，想拥抱、接吻，想拥有自己期待的性生活，都不必先解释成改善健康或维持婚姻的手段。** 快乐可以就是理由。但另一个人的身体，不是兑现这个理由的资源。

本章讨论成年人之间自愿的亲密，不提供性行为技巧、个体医疗方案或当地法律判断。没有伴侣、不想要性接触、不把身体接近放在人生中心的人，同样不欠任何人一份“活得够尽兴”的证明。

我们的主张不是“多一点总比少一点好”，而是：**亲密不必拿次数证明，欲望也不必被假装没有。** 要让两句话同时成立，比单说“尊重边界”或者“大胆一点”难得多。

**沿四个问题读：** [向一个人靠近，想得到什么](#intimacy-closeness) · [说过希望你主动，再主动还算不算](#intimacy-invitation) · [愿望不同，怎样仍有相处的余地](#intimacy-difference) · [激情是不是被写得太谨慎](#intimacy-judgment)。这里既不把亲密化成配额，也不把所有想被靠近的愿望化成需要克服的依赖。

<a id="intimacy-closeness"></a>
## 一、向一个人靠近，不只是找回自己

从[亲密本身的价值](#intimacy-value)进入，再看[“另一半”的吸引力](#intimacy-halves)、[融合与回应](#intimacy-fusion)、[依靠与人格完整](#intimacy-dependence)、[共同改变](#intimacy-changing)。想让距离变小，不等于必须让另一个人的意愿消失。

<a id="intimacy-value"></a>

### 不只是不出事，也不只是把关系维持住

下面是一个原创假想，不是真实读者的经历。

两个人终于有一个不用赶时间的晚上。一个人期待身体上的靠近，另一个人也愿意。他们不准备生育，不需要为周年纪念交作业，也不是要执行一份“健康关系每周应该怎样”的计划。这个晚上值得发生，仅仅因为他们都想经历它。

如果只能用“有利于身体”“夫妻关系更稳定”“明天心情更好”来为它辩护，就把此刻又变成了为别处服务的工具。那些后果即使存在，也不是快乐获得资格的唯一入口。我们允许这段经历没有更远大的用途。

这里的快乐也不必被压缩成一个结果：被邀请而不是被默认，看见对方认真留意自己的反应，发现某种从前没有说过的偏好，或者终于不必维持“我应该很熟练”的样子。这些都是本书对亲密价值的描述，不是所有人的体验清单，更不是已证实的幸福配方。

WHO在性健康的工作定义中，把身体、情绪、心理与社会层面的良好状态纳入讨论，而不只看疾病是否缺席；它也提到愉悦、安全、尊重以及不受强迫、歧视和暴力的条件。[F69](../docs/evidence/F69-sexual-health-and-asexuality.md) 这不是在说“有性生活的人才健康”，也不是用机构名义为本章的价值排序盖章。

**值得认真对待的不是“怎样表现得像一个有激情的人”，而是这份靠近对当事人有什么意义。** 意义可以浓烈，也可以很轻；不必先证明它比独处、友情或别种生活更高级。

<a id="intimacy-halves"></a>

### “另一半”的故事，为什么比条件清单更动人？

你想和一个人靠近，未必只是因为他符合若干优点。也可能是终于不用把每句话解释两遍，有些难以说清的东西被认出来，于是产生一种“原来我一直在找你”的感受。这里描述一种可以理解的愿望，不是宣称每个人都会这样恋爱。

柏拉图《会饮篇》里，阿里斯托芬讲了一个关于分离的神话：原初的人被切成两半，分开以后彼此渴求，希望重新合在一起。故事里的相遇不只指向身体接触，还指向当事人一时说不清的、更长久的共同存在。[F80](../docs/evidence/F80-symposium-and-wholeness.md)

先把来源说准确：这是对话人物阿里斯托芬的演说，不能直接标成“柏拉图的爱情定律”。神话包含不止一种配对，也带着古代的性别等级和年龄关系；本书不把这些描述移植为现代身份分类或关系规范。它不是人类起源知识，也没有证明世界上存在可以被识别的唯一命定对象。

但指出它是神话，还没有回答它为什么值得认真想。它给出了一种强烈的承诺：**你不是随便一组条件的合格供应者，而是我想遇见的这个人。** 本书这样理解这份吸引力，不冒充原文已经给出上述现代说法。

因此，问题不能只处理成“相信缘分的人不理性”。若用一个更高分的人就能无损替换眼前的人，曾经共同经历的东西去了哪里？我们也不认为亲密只是在市场上找最优配置。但“这个人对我有不能随便替换的意义”，仍然不等于“没有这个人，我就不算一个完整的人”。

<a id="intimacy-fusion"></a>

### 如果真的融成一个人，谁来回应你？

阿里斯托芬接着请人想象：赫淮斯托斯提出，把相爱的两个人熔合为一，让他们生前死后都不再分开。演说把接受这个提议描述成他们深层愿望的实现。[F80](../docs/evidence/F80-symposium-and-wholeness.md)

神话没有说明熔合后思想必然一致。下面把身体的合一与意愿的合一作对照，是本书自己的追问：你期待的是对方知道你想要什么，还是从此不再存在对方自己的答案？两者看起来都能减少分歧，却不是同一种靠近。

设想两个纯粹虚构的版本。一个版本里，对方永远与自己想得一样，回应只像回声；另一个版本里，对方有时不同意，却理解你为什么在意，也会主动带来你未想到的东西。不能据此证明后者使所有人更快乐。但如果你珍惜的是“这个人愿意向我走来”，那么另一个意愿仍然存在，就不是亲密要彻底修掉的故障。

**被另一个人回应，与把另一个人取消成自己的延长线，不是一回事。** 这也不要求伴侣必须处处不同才有价值。深厚默契、共同偏好和长时间相伴都可以令人向往；区别在于一致是否还能被修正，而不是一定要制造多少分歧。

同一部作品稍后还有不同声音。苏格拉底转述狄奥提玛时提出：人追求的并非仅仅是自己的半边或整体，还在于它是不是善的；论述随后指向长久拥有善。[F80](../docs/evidence/F80-symposium-and-wholeness.md) 所以连原作内部，也不能只摘出“寻找另一半”就宣布讨论结束。这里的“善”不等于本书的即时快乐，长久拥有善也不是我们的现成答案。我们借它保留一个追问：**感觉像找回了自己，能不能独自证明这段相处值得继续？**

<a id="intimacy-dependence"></a>

### 需要别人，不等于自己原本只有半个人

对前面最有力的反驳是：“你是不是又在要求人必须独立、没有缺口，才配进入关系？”

不是。一个人可以很需要陪伴，可以在某段生活里依靠另一个人，也可以希望对方承担已经答应的照料。**不把自己说成残缺，不等于宣布自己不需要任何人。** 若只有情绪永远稳定、生活永远能独自处理的人才有资格被爱，所谓完整又成了更苛刻的入场考试。

这里要分清的是人格上的地位与实际的依靠。承认一个人有自己的意愿，不表示他拥有无限资源、能独自处理一切，或者随时离开都没有困难。相反，正因为有人在某些事情上离不开帮助，帮助才不该附带“那你的其他选择都归我”的条件。关于照料和资源限制，见[有责任的人不需要另一份作业](../essays/06-real-life-constraints.md)。

依靠也不自动构成剥削。一方暂时多承担，双方愿意如此，可以是共同生活的一部分；没有必要把每次需要都改写成独立训练。真正需要说清的是愿意承担什么、什么时候需要调整，而不是让得到帮助的人不断证明自己也很有用。

另一面也不能省：一个人有被照顾的需要，并不使某个特定伴侣自动具备满足全部需要的能力。承诺不能轻轻抹掉，人的限制也不能被浪漫故事抹掉。我们不提供“只要相爱就扛得住”的保证，更不把无法独自脱身归罪于谁不够自主。

<a id="intimacy-changing"></a>

### 在关系里变了，不一定就是失去自己

还有一个看似相反的问题。既然要保留两个意愿，是不是每个人都该守住原来的生活，任何改变都算退让？

也不是。用一个原创假想来说明：起初，甲很爱散步，乙只想快点到家；后来他们共同形成一条会绕去看河的路。有时是甲提议，有时乙先等在那里。它不再只是“甲的爱好，乙勉强配合”，也不一定是乙找回了本来就藏在心里的命定偏好。他们可以在相处中做出一种此前没有的期待。

这不是证明伴侣应该互相改造，更不是从散步推到身体接触。它只说明：**自主不必表现为永远不变，也可以表现为愿意参与自己怎样改变。** 接触后的喜欢、共同形成的习惯、后来觉得不再适合，都应由当事人描述，不能由旁人按“谈恋爱前后是否一样”代为判定。

因此，值得问的不只是“我为这段关系改了多少”，还包括：“改变怎样发生？我有没有提出不同意见的余地？当我不再想这样时，能不能讨论？”一次选择会影响以后，也可能形成需要认真处理的共同承诺；可讨论不等于随时撤销一切后果，长久相处也不等于某一天把未来的自己全部签走。

“耍起”在这里不是寻找一个永远配合自己的人，也不是把依恋视为软弱。**我们想要的不是两个人拼成一个才够资格生活，而是两个人能共同创造值得过的生活。** 它可以亲密、投入、相互依靠，不必以抹平其中一个人的意愿为完成标志。

<a id="intimacy-invitation"></a>
## 二、被主动想起，为什么不能只按次数算

“这个月多相处了几次”，未必回答了“有没有哪次是你想来找我”。这一节只作原创情境与价值讨论，不把它当成关系诊断，也不声称这些说法能让谁更有欲望。

<a id="intimacy-authored-invitation"></a>
### 我说过“希望你主动”，你再主动就不算了吗？

设想两个成年人，林和遥，都愿意继续这段关系。林说：“我想的不只是你答应我。我也希望，有时候是你想见我，自己来问我。”几天后，遥发来邀请，林却有些失落：“可这次是因为我提醒过你。”

这份失落不是完全没道理。林想要的可能是：不用安排一次见面，也能知道自己曾进入对方的念头。若把所有责任都推给“你想见就开口”，共同见面仍可发生，却让一种期待无处安放。**答应邀请和发出邀请，可以同样真诚，却未必给对方同一种被需要的感觉。** 这是对假想人物愿望的区分，不是所有关系都应追求的标准。

但“你知道了我的愿望”和“你只能执行我的愿望”，也不是一回事。听见林的话以后，遥可能更留意到自己也想见面，再决定什么时候、怎样提出；也可能只是害怕没完成任务。两种情形表面上都可以是一条消息，却不能只由“林说过”三个字选定解释。

**自己选择，不等于从未受对方影响。** 一份愿望被说出来，可能让另一人更有条件回应，而不只是让回应失去资格。我们不能一面希望对方理解自己，一面规定：只要理解来自自己说过的话，此后的选择就一律不算数。

<a id="intimacy-signal-and-choice"></a>
### 同一场见面，可以答对一件事，却没答对另一件

把假想再拆开。林可能在问三件不同的事：

- 这个晚上，我们是否真的想在一起？
- 发起和安排是不是总由同一个人承担？
- 在我没有提醒的时候，你有没有想起过我？

见面很愉快，可以回答第一件，却不自动改变第二件的分工。遥这次主动安排，可以回应分工，却不可能把“林曾提醒过”这段历史变成没发生。第三件若要求的是一份关于过去的证明，就不能让今晚的快乐替它补交。

反过来，也不能让第三件的遗憾抹去前两件真实发生的东西。**“不是我原先盼的那种主动”，与“这次见面全是假的”，之间还有很大一段距离。** 对方的主动、自己的感受、谁做了安排和双方从前知道什么，需要分别说，而不是压成一个“够不够爱”的总分。

这不是教林降低要求。如果他盼的是在那次开口之前就收到邀请，这次邀请确实不能让那个期待成真；但没收到邀请，也不能单独说明遥此前从未想起过他。**没发生的行动、尚不知道的念头、已经失落的感受，不是同一个空缺。** 缺失不必被夸大为对其他一切的判决。遥同样可以说自己更喜欢回应邀请，而不善于或不想经常发起；说清不保证彼此适合，却比把每次行动都放进同一种解释更接近分歧本身。

<a id="intimacy-initiative-objection"></a>
### 最强的反对意见：我想要的恰恰就是“不用我说”

那种愿望值得承认。意外收到邀请、发现一件小事被记住，可能正因为没有预先安排而动人；把惊喜取消成定期提醒，确实可能失去想要的部分。本书不把“都沟通了就应该满意”当答案。

但没有预先说明，也意味着对方未必知道什么会被理解为亲近。若把一条没有说出的规则作为必须通过的考试，又要求对方不能知道自己在考试，双方就很难分辨：这次错过的是信息、愿望，还是根本不想接受这项要求。我们不凭一次漏掉的邀请替任何人下结论，也不承诺把规则说清以后就会有好结果。

林可以说明自己重视被主动想起，再看这样的相处是否仍然是双方想要的；不必每次编排一句台词，也不能把“这不算”变成永远移动的终点。遥可以理解这个愿望，却不承诺时时读懂没说出口的期待。**被理解不保证每次被满足，照着请求做了也不保证对方得到同一种感受。** 这不是给任何一方新增一份必须满意或必须使人满意的义务。

<a id="intimacy-invitation-range"></a>
### 主动是一份邀请，不是提前签好的交付

即使遥真心发起，林那晚也可以不想见；即使林高兴赴约，也不等于答应了后面所有身体接触。主动的价值如果来自另一个人愿意向自己走来，就不能反过来要求那个人从此失去改变主意的余地。

同样，林曾说想被邀请，不代表每次都须答应来证明这项愿望真实。**愿望可以长期存在，某一次仍然不合适。** 被拒绝可以失落，却不能把发起的心意变成对方的欠账。

这也不抹掉相互关系的困难：如果一方一直发起、另一方一直不愿参加，双方可能需要面对想过的生活确实不同。我们保留这种未必能解决的分歧，而不把更多邀请、更多接受或更少期待规定成统一解法。关于普通聚会的自愿让步，见[共同经历](05-connection.md#connection-compromise)；这里不把接受活动邀请当作任何身体接触的同意。

<a id="intimacy-difference"></a>
## 三、愿望不同，怎样仍有相处的余地

先分清[欲望、同意、感受与关系评价](#intimacy-distinctions)，再看[次数指令的研究](#intimacy-frequency)、[期待不一样的对话](#intimacy-mismatch)、[可以提前安排什么](#intimacy-planning)，以及[不想要的人为何不需要被修好](#intimacy-spectrum)。彼此听懂，不保证所有愿望都能同时实现。

<a id="intimacy-distinctions"></a>

### 想要、同意、愉悦与关系满意：四个不能互相代答的问题

亲密中的误解，有时不是不知道一句原则，而是让一个答案替代了另外三个答案。

| 要分清的问题 | 它在问什么 | 不能替代的答案 |
| --- | --- | --- |
| 欲望 | 我此刻想靠近，想经历什么？ | 不能替对方作选择，也不等于已经决定行动 |
| 同意 | 我现在是否自愿参与这件具体的事？ | 不承诺体验一定愉悦，不自动涵盖别的接触 |
| 实际感受 | 经历时我觉得怎样，还想继续吗？ | 不能反过来为未经同意的行为补发许可 |
| 关系评价 | 我对这段关系整体有什么感受和期待？ | 不能由一次接触或一个次数直接判定 |

这是本书组织讨论的区分，不是量表或诊断工具。研究中怎样测量欲望、享受和心情，也未必与日常用词完全相同；后文会保留这个差别。

设想前面的两个人原先都想亲近。后来一个人想停下来，另一个人仍然很投入。起初的愿意是真实的，现在的停止也可以真实。不能因为第一句话成立，就把第二句话解释成出尔反尔；更不能把已经花掉的时间、晚餐或酒店钱算成对方必须继续的理由。

反过来，一次经历中有让人愉快的部分，也不意味着其中每个环节都被同意。**感受不是许可的追溯凭证。** 本书的伦理底线是具体、自愿、可以改变的选择；沉默、关系身份、过去愿意以及旁人对身体反应的猜测，都不能替本人作答。这里不宣称列出了任何司法辖区完整的法律标准。

还有一种较少被看见的压力：没有人强迫开始，但开始后必须持续表现得愉快，才显得没有伤害对方。于是“不太喜欢”“今天到这里”“刚才那部分我不想再试”都变成难以说出口的话。

我们不要求当场交出一份准确的体验报告。有人需要时间才知道自己如何理解这段经历。愿意听见后来不同的描述，不等于必须接受对方对一切事实的解释；但如果只能保留赞美，所谓沟通就只是让参与者给演出好评。

<a id="intimacy-frequency"></a>

### 次数很容易数，快乐却没有因此更容易理解

“关系应该更有激情”是一句抽象愿望。“这个月要比上个月更多”看起来具体得多。可具体不等于抓住了问题：次数增加，可以伴随期待，也可以伴随疲惫；频率相同，也可能是双方满意，或双方都不敢提。

一篇2015年的研究给这个区别提供了值得细读的例子。Loewenstein等人招募夫妻，随机让其中一组在90天里把性交频率提高到原来的两倍，另一组不接收频率指令。实际可用样本为64对、128人；参与者35—65岁，是已婚的一男一女组合，且筛除了部分健康状况、相关身体不适及围绕性的关系紧张。[B36](../docs/research.md#b36)

干预组的频率高于对照组，但平均并没有完成翻倍。论文没有发现预期的心情改善，享受评分较低；心情的负向结果随控制变量改变，纳入婚龄后未达到作者标注的10%显著性门槛。因而，**不能把它改写成“科学证明性生活越多越不快乐”。** [N36](../docs/evidence/B36-sexual-frequency.md)

更重要的是，研究者自己在讨论中收窄了问题：他们检验的是**被要求增加频率**的影响，不能据此判定自发选择的更多亲密究竟有何因果效果。外部指令可能改变动机，是作者提出的解释，不是被单独随机操纵并证实的机制。

这个研究对本书的意义，不是给出一个更聪明的次数，而是阻止一次偷换：把容易计数的行为，当成欲望、愉悦和关系质量的共同代理。实验也没有直接测定每次互动中的同意，更不能用它指导本来就有冲突、不适或其他未被纳入的人群。

**如果一个人说“我想要更多”，值得听的是他想多得到什么。** 是身体上的快乐，被主动邀请的感觉，不总由自己开口，还是一段不被工作打断的相处？这些不是相同诉求。次数可能确实是其中一部分，但它不该在问题还没说清楚时就成为唯一答案。

<a id="intimacy-mismatch"></a>

### 想要得不一样，不必先判一个人有错

“你不欠别人性接触”是一条必要底线，却不能自动结束关于关系的所有讨论。一个人反复体验到期待落空，也可能有真实的孤独、挫败或不被需要的感受。承认这些感受，不等于授予他索取另一个人身体的权利。

同样，“对方很失落”不能成为让不想参与的人负责提供接触的结论。**需要被认真看见，和需要被指定的人满足，是两回事。** 这也是本章愿意承担的取舍：我们宁愿承认某些期待无法兼得，也不把不情愿包装成维系关系必需的劳动。

再构造一段对话。甲说：“我们最近很少亲近，我总觉得只有我想。”乙回答：“你每次靠过来，我都担心又得继续；所以连拥抱也不太敢答应。”

这不是一个“甲次数太多、乙次数太少”的算术题。甲可能在意被需要，乙可能在意接触会不会自动升级。如果所有拥抱都被当成下一步的开场，乙失去的就不只是拒绝下一步的空间，也可能是本来愿意享受的拥抱。

他们可以讨论某次靠近是否就停在双方愿意的范围，但不能把这句话做成新的义务：“既然不用继续，你总该抱一下。”接触本身仍需要各自愿意。也不能用“先只抱抱”骗取机会，再临时施压。

愿意说清楚，并不保证两个人最终想要同一种生活。有时双方理解了彼此，差异仍然存在。能讨论的包括期待、关系安排以及是否继续这段关系；不能讨论成对方必须接受某种身体接触。某些选择会带来遗憾，不应假装只要沟通技巧足够好就没有代价。

这里也不把欲望较多的人写成天然粗鲁，把欲望较少的人写成天然成熟。两边都可能体贴，也都可能逃避问题；但体贴不能以交出身体自主为考题。

<a id="intimacy-planning"></a>

### 安排相处时间，不等于预订对方的身体

反对次数配额，不等于只有完全自发的亲密才真实。

轮班、照护、合住、出差，都可能让两个人真正想要的相处一直排不上。提前把某个晚上留出来，可以是在认真对待欲望，而不是把它做成任务。关键区别是：安排为相处提供条件，还是为结果设置验收？

| 事先可以讨论什么 | 留给当时的选择 | 容易偷换成什么 |
| --- | --- | --- |
| 一段不被工作占用的相处时间 | 要聊什么、怎样靠近，或只是休息 | 留了时间就必须发生某种接触 |
| 各自期待与不愿意的部分 | 感受变化时停止或调整 | 说过期待就不能改口 |
| 隐私、分工与必要的照护安排 | 当事人仍各自决定是否参与 | 帮忙做家务就获得身体回报 |

这些是原创的关系判断，不是由B36验证的干预方案。那篇论文在讨论中设想提供旅行、照护等条件也许与直接发指令不同，但**没有在该实验里检验这些替代安排**；不能借它宣布“约会安排已经科学证实有效”。

把准备与验收分开，也能看清劳动问题。一个人说“放松点”，另一个人却还记着门没锁、孩子会醒、明天谁收拾，那么所谓气氛可能依赖一个人继续默默管理环境。这与[坐下的人为什么仍没下班](09-constrained.md#constrained-cognitive)相邻，但在这里多了一层：照护和家务不是购买接触的筹码，接触也不是补偿不平等分工的报酬。

**可以认真准备，又不要求准备必须换来指定结局。** 接受这一点，并不等于人不能失望；它要求的是不把失望结算到对方的身体上。

<a id="intimacy-spectrum"></a>

### “耍起”不该变成另一种必须有欲望的文化

一本支持即时享乐的书，尤其容易犯一个相反方向的错误：不再要求人人克制，却开始要求人人热烈。仿佛性生活不丰富，就是不够开放；没有性吸引，就是还没遇到“对的人”。

AASECT关于无性恋者尊严与权利的立场说明，把无性恋及相关光谱身份视为有效的身份与取向，而非需要矫正的障碍，并反对以改变这些取向为目的的矫正做法。它也要求关注困扰来自何处，而不是只凭欲望多少贴标签。[F69](../docs/evidence/F69-sexual-health-and-asexuality.md)

这不等于本书可以替任何人判定身份。**性吸引、想不想进行某种接触、有没有某种行为、怎样称呼自己，应分别听本人怎么说。** 一段时间没有性接触，不足以替人宣布“你就是无性恋”；认同无性恋，也不授权外人安排其感情生活。

我们不把友情写成性关系的低配，不把没有伴侣写成等待完整人生，也不把独自理解自己的身体感受视为只有找到伴侣之后才有意义。对于愿意追求性快乐的人，它可以占很重要的位置；对于不愿意的人，不需要为了符合本书的“享乐”形象而创造这个愿望。

如果一个人对自己的变化或不适感到困扰，可以选择寻求尊重其意愿的专业支持；但“你让我不满意”和“你有待修复的疾病”不是同一个判断。本章不进行诊断，也不给药物、避孕或感染风险的个体方案。需要这些信息时，应另查适合所在地与个人情况的可靠医疗资源，不把本章当性健康百科。

<a id="intimacy-judgment"></a>
## 四、激情不必被管理，选择仍可被纠正

<a id="intimacy-objections"></a>

### 最强的反对意见：你是不是把亲密写得太谨慎了？

**“我想要的是激情，不是开会。”** 这个批评有道理：如果每次接近都被一张评分表包围，快乐很可能还没被描述，就先变成了管理对象。本章的表格用于分清概念，不要求人在相处时照表演出。我们也没有理由把强烈的欲望自动写成可疑，或把熟悉、信任中的默契一概贬为粗心。

但默契不能以永远不许纠正为代价。如果对方指出“你理解错了”，我们优先保留这句纠正，而不是保留发起者对浪漫气氛的解释。那可能中断一刻兴致，却比要求别人替气氛忍下去更符合这里的价值排序。

**“只讲自愿，会不会让欲望较少的一方永远决定一切？”** 对共同接触，任何一方不愿意都足以使它不发生；这不是可按贡献加权表决的事项。但关系的其余选择不因此全部冻结。欲望较多的人可以诚实表达期待，决定自己是否接受现有安排，也可以离开。不能把“你有离开的自由”简化成冷酷的逐客令；也不能把“我很需要”变成对方必须参与的依据。

**“一次不好，也许试多几次就好了。”** 可能有人愿意共同探索，也可能有人不愿意。关键不是本书替你预测下一次会不会更好，而是谁有资格决定是否再来一次。不能用未来可能的快乐，取消当下明确的不愿意；愿意再试，也不需要被旁人嘲笑成不够果断。

**“你反对考核，却还在教人判断关系。”** 是的，我们并不主张不思考。区别在于判断帮助当事人看清选择，还是替他们规定合格人生。本章没有最低频率、统一关系形式和必须完成的体验；它明确偏向快乐与自主，也承认这两个价值有时让某些愿望无法同时实现。

<a id="intimacy-end"></a>

### 亲密可以是目的，但任何人都不必成为工具

如果两个人都想靠近，不必等它能够促进健康、巩固家庭或者证明青春尚在，才让这个愿望得到认真安排。如果不想，也不必先制造一个足够严重的理由。

这不是“享乐之前先完成一整套正确作业”。恰恰相反：当某个人的身体不再负责替关系交卷，亲密才有机会被当作彼此选择的经历，而不是必须完成的证明。

**可以很想要，可以认真争取一个相处的机会；不能把另一个人变成这个机会必含的结果。** 这就是本章的“耍起”：不是比别人更大胆，而是更诚实地承认想过什么生活，也承认别人有自己的答案。
