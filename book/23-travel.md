# 23 · 旅行不必改变人生，也值得专门出发

**可以为了一个地方去一次，不必让它负责救回整个人生。**

想看一座建筑在傍晚怎样变暗，想听不熟悉的街头声音，想连续几天不在原来的房间醒来，这些已经是旅行的理由。不需要证明视野因此开阔了多少，更不需要回来以后成为一个全新的人。

但“出去一下”也不是一个完整愿望。同样的三天，有人想不断移动，有人想终于不用移动；有人想与朋友密集相处，有人想暂时没有人认识自己。目的地相同，不代表买的是同一种经历。

本章先讨论怎样辨认这趟旅行真正想保留的东西，再讨论路线、同伴、预订和落空。没有实时目的地推荐、价格承诺或交通攻略；未注明文学出处的示例均为虚构，具体条件须在出发前另行核实。

沿四条主线读：[愿望与有限的一趟](#travel-wishes) · [同行与安排](#travel-arrangements) · [攻略、观看与真实](#travel-looking) · [落空与已经发生的日子](#travel-aftermath)。想从一个分歧开始，可以先看[还不知道会喜欢什么，就不值得出发吗](#travel-discovery)，或[可能只来一次，怎么面对错过](#travel-once)。[福斯特小说的局部细读](#travel-forster)默认折叠，含第二章情节，不涉及全书结局。

<a id="travel-wishes"></a>
## 一、想要什么，与到了才发现什么

先辨认愿望，再给[尚未知道的喜欢](#travel-discovery)留位置，也回应[是不是在替没玩好找台阶](#travel-discovery-objection)。路程、住宿与只来一次的限制，让这些愿望进入同一个有限行程。

### 目的地是名词，愿望最好还有一个动词

“去海边”可能指游泳、看海、沿岸走路、待在房间听风，或者只是想离开熟悉的城市。前几种愿望对天气、位置、技能与设施的要求并不相同。

如果只比较“哪个海边评价高”，可能是在替一个尚未说清楚的愿望购物。可以先把句子补成“我想在那里……”：

| 愿望 | 行程应该优先保护什么 | 容易买错的替代 |
| --- | --- | --- |
| 在陌生街道上慢慢辨认生活 | 可停留的时间、步行条件、回住处的便利 | 不断换景点，始终没有时间待着 |
| 集中看平时见不到的作品 | 实际展出、开放与预约条件 | 只因建筑有名便默认里面有想看的内容 |
| 和朋友一起经历一件事 | 双方都愿意的活动、交流与各自空间 | 把“同行”理解为每分钟必须相同 |
| 连续几天少作决定 | 稳定的落脚点、简单安排、信息可靠 | 为追求最优选项每天重新比较 |
| 追求一段密集而兴奋的变化 | 真正感兴趣的内容、可承受的转场 | 把数量本身当成兴奋的保证 |

表格是本书的选择框架，不是目的地分类。它不要求每趟只能有一个愿望，只要求承认：当愿望冲突时，不能指望一份行程把它们全部满足。

你可以同时想看很多、走得少、住得便宜、随时回房间；可在一个具体地方，它们未必能够同时成立。删掉一个要求，不等于愿望被降低，也可能是终于保住其中最重要的部分。

<a id="travel-discovery"></a>
### 还不知道会喜欢什么，就不值得出发吗？

“先说清想要什么”也有一个危险：仿佛只有出发前已经列出的愿望，到了以后才有资格占用时间。可是，有些东西恰恰是在亲自碰到以后，才变成自己在意的东西。

看一个原创假想。小岚专程去一座虚构展馆看木刻版画，原定下午留在馆内。她没有想到，自己会在印刷演示前待很久：纸怎样着墨，同一块版为什么能呈现不同效果，突然比下一幅作品更使她好奇。她不是忘了旅行目的，也不必证明演示比版画更高级；一次观看正在改变她想继续看什么。

如果行程表只允许执行已有愿望，这份新兴趣就会被当作偏离。另一种安排则是：最想见的作品留出时间，其余停留允许由现场的反应决定。两者都不保证满意，但后者承认了一件事：**行程可以回应一个正在变化的人，不必只服务出发前写计划的那个人。**

这里不是把“发现真正的自己”再变成旅行任务。小岚也可能看完原定作品就离开，对演示毫无兴趣；那同样不是少完成了一项收获。你可以想接触尚不熟悉的内容，却还不知道最后喜欢哪部分。“想去认识一点东西”已经是一种愿望，不必先提交认识之后的答案。

这与全凭未知下注不同。开放与入场条件可以核实，费用和返程需要安排；不知道自己会被哪幅画吸引，不等于不知道能不能进去、怎样回来。另有同行者时，现场兴趣也要放进[已经答应的共同安排](#travel-arrangements)，不能由一个人的新发现取消其他人的一天。C03进一步区分[自己的反应未知与参与条件不明](03-novelty.md#novelty-uncertainty)。

<a id="travel-discovery-objection"></a>
#### 那不就是替没玩好找台阶吗？

再改一个前提：小岚到场才发现，专程想看的版画没有展出，演示却意外好看。这时可以同时说“我错过了最想看的”和“那段演示确实喜欢”，不必选一句来消灭另一句。若原本能查到展出信息却没查，后来喜欢演示，也不能倒过来证明准备没有问题。

更不能替她补上一句“所以这趟反而更值”。她也许仍然不愿为这样的结果付同样的路费；喜欢其中一段，与认可整趟取舍，是两个判断。反过来，整趟没有达到期待，也不要求把那段喜欢说成假的。

**没有预先想到的快乐可以算数，但不必替整趟旅行报销。** 承认偶遇，不是要求每次落空都兑换成成长，而是允许旅行包含尚未写进愿望清单的东西——也允许最终没有遇见。

### 地图上的两个点，中间不是一条免费的线

行程表经常只写到达哪里，却不写离开上一站需要什么。收拾东西、走到入口、等候、寻找方向、寄存、找吃的、重新进入状态，都可能占用这段时间。

看一个虚构的五小时下午：一点到六点，想去展馆、老街和书店。为方便说明，先假定这些条件已经核实；以下时间不是任何城市的实测值。

| 环节 | 暂定时间 |
| --- | --- |
| 起点到展馆、入场 | 40 分钟 |
| 看展 | 90 分钟 |
| 展馆到老街 | 35 分钟 |
| 逛老街 | 45 分钟 |
| 老街到书店 | 25 分钟 |
| 书店停留 | 40 分钟 |
| 返回 | 35 分钟 |
| **合计** | **310 分钟** |

五小时只有 300 分钟，这份表已经超出，尚未给吃东西、上厕所、迷路或临时停留留位置。问题不是旅行者不够自律，而是表格漏掉了真实经过的时间。

如果最想看展，删掉书店可能保护看展；如果最想在街上漫游，展馆也可以留到别次。不能只删每站的停留，把所有移动都保留，最后得到一份哪里都到了、哪里都没真正待过的计划。

这也不是鼓励把时间精确到每分钟。恰恰相反，计算在这里用于识别装不下的承诺，而不是要求现场像表格一样运行。**路线是有前后依赖的经历，不是一组可以随意相加的收藏夹。**

### 住得更远，便宜的是房间还是整趟旅行？

“每晚便宜一点”是真实好处，但不等于全程成本一定更低。位置还会改变交通、回程选择、携带物品、临时休息和与同伴分开的难度。

另一个虚构例子：一间住处比另一间每晚便宜 100 元，住两晚共少付 200 元。如果每天新增交通费 60 元，两天共 120 元，那么尚未计其他差异的节省是 80 元，而不是 200 元。假设每天还多往返一小时，两天就是两小时；这些是假设输入，不是当地报价，也不把时间强行折算成工资。

有人愿意用两小时换 80 元，有人宁愿多花钱少移动，都可以。关键是知道自己作的是什么交换，而不是仅凭页面最醒目的那一个数字判断。

也可能远处本身就是想待的地方。此时它不是“为了便宜牺牲位置”，而是另一个中心。不要拿所有人都去的区域，默认充当每个人行程的圆心。

### 紧凑不是原罪，慢也不是一种道德优越

有的人旅行就是想一口气看很多：不同建筑、连续演出、多种地貌、一个接一个的新画面。移动本身也可能带来兴奋。不能看到行程密集，就宣布对方“只会打卡”。

要区分的不是快与慢，而是是否愿意用这种节奏经历内容。紧凑行程中，短暂停留可能已经足够；深度停留中，反复走同一条街可能仍然有趣。两者都不必模仿对方的照片与叙事。

高密度安排真正需要面对的是依赖：第一站晚了，后面几站还能不能调整？一个人疲惫，其他人如何继续？最后一个环节取消，前面的花费和预订会发生什么？

喜欢高强度体验，不等于承诺永远不能改变强度。可以保留最想经历的两三个节点，让其他部分具有可删减性。具体保留多少，由真实时间和偏好决定，本书不规定最佳景点数量。

同样，慢旅行也不保证从容。若只是为了符合“会生活”的形象而强迫自己在一个不喜欢的地方坐很久，慢也成了表演。

**旅行的节奏不需要通过外人的品位认证。需要兑现的是你真正想经历的部分。**

<a id="travel-once"></a>

### 如果这辈子可能只来一次，“下次再看”并不是答案

劝人别赶行程时，一句“以后还会来的”很轻巧。可是，假期、路费、身体条件、同行的人，未必还会同时凑齐。对一个真的很难再来的人，错过并不是心态不够松弛，而是需要认真面对的损失。

因此，不能把“我想多看一点”全解释成贪心或攀比。假设有人从小想见的三件作品恰好分处不同地方，他愿意早起、走累一点，为的是三个具体愿望，而不只是完成三个点位。他不必先把自己改造成慢旅行者。

难处在于，**机会只有一次，能使取舍更重要，却不能让一天凭空变长。** 前面那份五小时装了310分钟的表，不会因为再来不易，就变成能够完成的安排。

比较也不能在两幅不对称的画面之间进行：一边是删掉一站的确切遗憾，另一边是所有站都顺利到达、毫不疲惫的理想版本。要比较的是两种真实可行的经历：多去一处需要从哪里拿时间，会失去哪段停留；少去一处保住了什么，又确实错过什么。

可以有两个不同的回答。一个人说：“我知道只能短看，但亲眼见到这三件事本来就是愿望。”另一个人说：“如果只是跑到门口，我宁可在最想看的地方多待一会儿。”只要不抹掉各自的代价，两者都说得通。没有必要把前者说成浅薄，把后者说成不会算账。

也别把所有声称“必去”的内容都合并成自己的愿望。别人按各自兴趣列出的十份清单，加起来不等于你欠这个地方的一百件事。知道一处地方存在，只是多了一个选项，不是多了一笔必须兑现的债。

**有些遗憾不会被更高明的攻略消除。承认它，比假装一趟旅行可以结清所有愿望更诚实。**

<a id="travel-arrangements"></a>
## 二、共同出发，不必共同每一分钟

同行、预订与临时变化相互牵连。这里把可以调整的兴趣与需要兑现、重新核实的条件分开，不将随性当作跳过准备的理由。

### 与朋友出门，不是签一份全程一致协议

朋友可以很合拍，却有不同的起床时间、食量、走路速度、预算与独处需求。这些差别在平时两小时的见面里不突出，连续几天可能就成了安排问题。

看一个虚构情境：小许想早起看展，小何想睡晚一些。若两人都把“同行”理解为从早餐开始全程一致，就只剩轮流牺牲；若先说清最想一起经历的是晚上的演出，白天便可能有别的安排。

小许可以独自看展，小何稍后出门，两人约定在都能找到的地方再会。前提是各自愿意、交通和联系条件合适，也没有把照料或携带共同物品的任务悄悄留给其中一人。这样的安排没有解决所有旅行关系，只是没有让一个起床时间替整段友谊作判断。

也可能小许最想要的正是和小何一起看那场展。那就不是找个集合点能替代的愿望，需要直接询问对方是否愿意陪伴，并接受答案可能是否定。分开活动提供选择，不会神奇地使两种偏好变成同一种。

“可以分头行动”只适用于各自具备条件、双方愿意并明确再会安排的情境。它不是自然区域、复杂路线或需要相互照应时随意离队的建议。城市里分开逛一会儿，与没有通信条件的户外队伍分开，是不同问题。

若每次分开都被理解成关系不好，共同旅行就容易变成连续的态度考试。反过来，如果当初说好一起经历某件事，到了现场却不沟通地改变，也不能只用“各玩各的”免除影响。

同行的意义可以是互相进入一点对方的兴趣，也可以是各自经历之后有故事可讲。共同不等于相同。

### 预约先解决依赖，再考虑填满空白

有些安排一旦错过，整趟就难以成立；有些即使不去，也不改变主要愿望。它们不需要同等程度的提前锁定。

可以先识别：入场资格是否受限，交通是否依赖固定班次，住处是否确定，取消其中一项会牵连什么。再看可选内容是否真的需要付出不可退改的承诺。

这不是预订策略的万能公式。临时购买可能更贵，也可能没有位置；提前锁定可能省心，也可能使变化更困难。退款、改签、接待条件和有效期限都应看具体提供方当时的条款，本章不推定存在免费取消。

喜欢做好攻略也不必被劝成“到了再说”。研究和准备本身可以是期待的一部分。只是读了很多，不意味着到场以后必须执行每一个收藏。

本书第 21 章讨论计划与自由。放在旅行里，最重要的延伸是：**提前弄清会卡住行程的条件，可以是为了让其他部分更自由，而不是为了给每段时间找任务。**

### 临时改变路线，不等于只凭兴致改变风险

普通城市行程里，临时换一家店和取消一站，往往属于偏好调整。自然区域则可能涉及天气、地形、通信、体能和别人掌握的路线信息，不能把两种变更当成同样的“随性”。

美国国家公园管理局的访客规划页面建议了解环境与警报、匹配能力和活动、准备备选方案，并让可靠联系人知道行程；如果安全条件发生变化，应考虑折返，而不是硬推。页面本身说明范围是日间或过夜公园活动，多日偏远地区行程需要额外准备。[F12](../docs/evidence/F12-trip-planning.md)

这里借用的是规划中需要核实的类别，不是把美国公园规则移植到所有地区，更不是提供户外技能教程。当前开放、天气、当地规定及个人适用性，仍需具体确认。

尤其不能把“挑战一下自己”用于跳过必要技能，也不能把有人在网上走过某条路线当成自己能够完成的证据。让旅途有刺激，可以来自陌生、参与与变化；隐瞒条件、失去返程能力，不是必须购买的刺激。

<a id="travel-looking"></a>
## 三、谁告诉你怎样看，谁决定怎样喜欢？

[攻略与反攻略](#travel-guide)都可能提供帮助，也都可能越界。接着看一个[文学场景](#travel-forster)，再分清[事实说明、展示方式与本人感受](#travel-authenticity)。

<a id="travel-guide"></a>
### 攻略可以替你找路，不该替你承认“我喜欢”

攻略最有用的一种作用，是减少不必要的不知情：某处有什么、怎样理解眼前的细节、哪些条件需要核实。它也可能节省反复选择的力气。跟随一条现成路线，不等于没有自己的生活。

但“有人说值得看”与“我看了觉得值得”，中间仍然隔着一次实际相遇。它们可以一致，也可以不一致。不了解背景时，可以补一点知识再判断；了解后仍不喜欢，也不必把不喜欢藏成自己水平不够。

反攻略同样需要接受这个检查。一个人说“不看网上推荐，只去我熟悉的地方”，可以是在分享经验；如果接着规定同伴不准看地图、不准去名气大的地方，便不只是提供选择，而是在取消其他选择。**把路线从一本书换到一个人手里，并不自动等于自由。**

这不是要求人人亲自查完所有资料。请导游、让朋友带路、选择有人安排的行程，都可以是本人想要的轻松。需要问的是：把一部分安排交出去以后，还能不能说某一段不合意；对方的熟悉，是否被扩大成对自己全部感受的解释权。

<a id="travel-forster"></a>

### 一位反对攻略的同行者，怎样错过了真正的停留

福斯特的小说 *A Room with a View* 第二章，把“有见识地旅行”写得并不体面：有人宣称懂得真正的意大利，有人等待权威告诉自己该赞美什么，也有人刚刚获得一点自由，便被要求用它照顾另一个人的感受。

这里使用的是文学场景，不是旅行者调查；下方细读基于所核读的英文数字文本，属于本书解释，不把人物的话直接认作作者主张。[F58版本与读取范围](../docs/evidence/F58-travel-and-guidebooks.md)

Lucy想去Santa Croce。同行的Miss Lavish自称熟悉佛罗伦萨，反对Lucy依赖Baedeker指南，许诺带她找到不同于表面游览的意大利。两人却一路谈起英国熟人和地产，随后迷路。Lucy提议问路，Miss Lavish不但反对，还拿走她的指南，坚持随意走。

如果只读到这里，很容易把故事概括成计划与冒险的对立。可是下一处细节把这个对立翻了过来：她们经过Annunziata广场时，Lucy真的被婴儿浮雕吸引，觉得从未见过这样美的东西；带路人却因偏离路线而拉她继续走。**一位反对照本宣科的人，在意外真的发生时，反而不肯把时间交给同伴正在喜欢的东西。**

这个落差是本书细读的重点。问题不只是有没有攻略，而是谁能决定哪些偶遇值得停。Miss Lavish还想给出境游客设考试，排除她眼中不够格的人；她所推崇的独特，并不意味着允许每个人拥有自己的反应。

到了教堂附近，她又追着一位想交谈的人离开，指南仍在她手中。留下的Lucy既担心找不到路，也不知道怎样辨认被推崇的作品。她确实需要信息，不是只要被劝“跟着感觉走”就够了。

但她在等待标准答案之外，也开始看告示、观察现场的人。她对Della Robbia婴儿形象的喜欢，并没有因为无法立即说出正确术语而不存在。后来她仍然请Emerson父子帮忙找Giotto作品；新鲜的观看没有让知识从此多余。

小说也没有给她安排一位永不越界的自由导师。老Emerson对Giotto的高声批评打断了另一群人的讲解，之后又为破坏他们的兴致不安、试着道歉。他有自己的欣赏方式，不意味着其他人的观看时间可以被取消。

接着，他希望Lucy理解并帮助不快乐的George。Lucy则建议替George找爱好，或换到阿尔卑斯山、湖区旅行。这里应保留两重距离：那些是人物提出的解释与安排，不是小说已经验证的心理方案；本书也不因老Emerson反对拘束，就接受他可以替Lucy分配假期中的情感任务。

这个章节容得下不止一个失误：指南依赖可能使人等待批准，反指南姿态也可能夺走同伴的地图；坦率能带来新的理解，也能打扰别人。我们从中提出的问题是：**你获得的是更多观看和选择的可能，还是只换了一位告诉你怎样旅行的人？**

### 所谓“像当地人一样”，也可能是一份游客表演

你可以喜欢常见景点，不必因“游客才去”而失去兴趣；也可以喜欢普通街道，不必把它发现成一块尚未被别人占领的私藏。

当地生活不是等待旅行者鉴定真假的样本。有人居住、赶路、工作、休息的地方，对你是新鲜，对别人可能是日常。一个地方没有配合你想象中的风格，也不等于它失去了真实性。

拍照、聊天、观看手艺，都可以是旅行的一部分；但人的住宅、工作和私人故事，不会因为你远道而来就自动成为素材。愿意与人交流，和要求别人为自己的旅行提供“地道体验”，是两种态度。

本书不规定哪一种游览更高尚。它反对的是用“我想真正理解这里”，替不受欢迎的进入、拍摄或追问开通行证。

**你可以认真看一个地方，不必把它变成自己的发现。**

还要允许它不按你的期待提供“地方特色”。居民可以使用现代设备，店主可以卖熟悉的商品，工作人员也可以只是完成一项工作。我们不应因为这些东西不够像自己想象的远方，就替对方宣布生活失去资格。这是本书对观看关系的主张，不是对某座城市现状的统计结论。

“不像商业表演”也不能直接变成“对外开放”。看见一扇开着的门，不等于收到邀请；看见别人工作，不等于可以要求演示一遍。相反，明确为访客准备的一场表演，只要说明诚实、参与条件清楚，也不必因为有人排练和收费，就被判为虚假。

你可以更喜欢日常观察，也可以更喜欢一场认真制作的演出。两种偏好应当各自说明，不必争夺唯一的“真”。

<a id="travel-authenticity"></a>

### “真实”究竟指什么？不要让一个词替所有问题作答

设想一家虚构的手艺展示场所：访客预约入场，制作者在固定时段示范，现场也售卖作品。仅凭“为游客安排过”，还不足以知道发生了什么。

| 你关心的“真” | 应具体辨认什么 | 不能由它自动证明什么 |
| --- | --- | --- |
| 说明是否符合事实 | 所称作者、年代、材料、工序等是否有相应依据 | 讲解热情、画面漂亮，不保证说明正确 |
| 过程是否为展示而组织 | 示范、排练、重现与日常工作有没有说清 | 有排练不等于没有技艺，未经排练也不等于信息可靠 |
| 自己是否真的被打动 | 当时喜欢、好奇、无聊或失望的具体部分 | 感动不能核实年代，无聊也不能推翻已核实的事实 |

这是本书的辨析，不是鉴定服务或行业调查。如果场所坦白说明演示是为访客安排的，你仍可能真切地喜欢一段技艺；若它把新制品宣称为古物，问题是事实说明，而不是“只要开心就好”。享受不要求欺骗，核实也不要求先表现得冷淡。

同样，旅行者的强烈感受并不能让旁人自动成为配角。“我从没见过这样的生活”可以诚实描述自己的见识范围，却不能替换成“这里的人一直都是这样”。一次短暂接触，尤其是为访客安排的接触，不足以概括所有人的日常。

我们不要求一趟旅行写出准确的社会研究，才能准许它发生。恰恰相反：可以承认自己只是来过、看过其中一点、对某些东西有了兴趣。**喜欢一个地方，不必靠宣布自己已经读懂它来证明。**

<a id="travel-aftermath"></a>
## 四、落空的愿望，与已经发生的日子

行程可以需要补救，也可以最终不值；旅后研究则不能替旅途中每一段经历定价。这里回到失望、回程和这趟是否值得，不要求结尾一定圆满。

### 不如想象中好，不等于必须立刻拯救行程

下雨、食物不合口味、建筑没有照片里动人、同行者疲惫，这些都可能使期待落空。承认不好，不需要先被劝成“换个心态”。

不过，补救也有不同方向。原来想在室外走，现在转到合适的室内场所，是换一种体验；因为第一天不够精彩，急着再买更贵项目来证明没白来，则可能让后面的选择背上前面的账。

一个备选方案不必同样盛大。它需要回答的是，现在实际还想要什么、还能承担什么。有时是换内容，有时是回住处，有时只是吃顿正常的饭。

如果服务确有问题，可以据具体事实与条款处理；本章不提供争议解决的法律结论。不要为了维持快乐叙事而否认问题，也不要把无可改变的天气，当成工作人员必须补偿的个人冒犯。

### 回来以后又普通了，不证明那几天白过

一项使用荷兰 2006 年调查资料的研究，比较了 974 名度假者与 556 名未度假者。调整所测协变量后，度假者出发前的情绪指标较高；旅行后，两组的整体比较没有检出显著差异。[B12 阅读记录](../docs/evidence/B12-vacation.md)

这不是把人随机分成“去旅行”和“不去旅行”的实验，也没有在旅途中密集测量每个人的享受。出发前的差别不能自动归因为期待；回家后的差别未显著，也不能证明旅途中没有价值。

论文还讨论了“非常放松”假期之后的短时变化，但没有据此确定每个人的快乐到第几天消失，更没有直接比较“每年一次长假”和“多次短假”的总收益。

这些限制恰好让问题更清楚：你希望一趟旅行提供的是当时的经历，还是以后很久的改变？两种愿望都可以存在，却不能拿后者没有发生，取消前者已经发生的部分。

也不需要把一切都改说成“至少留下回忆”。如果你不喜欢这趟旅行，可以说不喜欢；若确实喜欢其中两天，那两天也不必继续产生收益，才有资格被算作值得。

**一顿饭不用让你永远不饿；一趟旅行也不必让你永远不烦。**

### 回程也是旅行的一部分，不是被省略的片尾

到家还要多久，东西放在哪里，是否需要立即处理工作或共同责任，这些会影响最后一段经历。行程结束于最后一个景点，与结束于实际回到日常，不是同一个时间点。

如果有余地，可以不把最后一天装到只剩赶路；如果没有余地，也不必自责没有安排出完美缓冲。重要的是别把回程负担从估计里删掉，再把疲惫解释成自己不会玩。

纪念品、照片与旅行笔记同样如此。喜欢整理可以继续，不喜欢不必再制造一份待办。一张普通票根、一个自己还记得的细节，或者什么都没有保存，都不决定旅行的真假。

### 最强的反对意见：花了这么多，只为了当时开心，太奢侈了吧？

确实，旅行可能昂贵，也不是每个愿望都适合现在实现。我们不把“不出发”解释成胆小，更不会用“人生只有一次”替账单催款。

需要讨论的是：如果代价在本人能够承担的范围内，是否仍然必须附带成长、疗愈或人脉收益，才能证明这笔选择正当？

本书的答案是不必。一次确实想经历的远行，可以因经历本身值得而成立；同样的钱用于别的生活，也可以成立。不存在必须向别人展示的旅行回报率。

旅行可以改变人，也可以只是让人过了几天愿意亲自经过的日子。**不必成为人生转折点，才值得成为人生的一部分。**

<a id="travel-incomplete"></a>

### 还有一个反对：不追求完整，会不会只是在替准备不足找借口？

会有这种情况。没查开放条件而错过最想看的内容、答应同伴却没有预留必要时间，不能一律用“不完美才真实”粉饰。前面的取舍分析不是给所有安排免责；值得区分本来可以核实的条件、明知而接受的代价，以及现场才出现的变化。

但准备认真，也不会消灭所有意外与分歧。把遗漏全归咎于游客不够用功，同样不公平。更完整的判断应当允许两句话同时成立：“这一处准备确实不够好”，以及“这并没有让已经喜欢的那一段失效”。

旅行结束时，城市不需要被你看完，自己也不需要被这座城市证明。可以留下一些不了解、没去到、不喜欢的东西；不把它们全说成成长，也不把它们全记成人生亏损。

**耍起不是拿到“会旅行”的资格证，是在有限的一趟里，真的经过一些自己愿意经过的日子。**

如果专程是为了看天象，[夜空章节](29-night-sky.md)另谈月相与可见性，也保留一个重要区分：承认过程可能有价值，不等于抹掉具体目标落空的失望。
