# 24 · 好笑不必有用，也值得认真琢磨

**一句话可以只负责好笑，不必总结人生。快乐不是严肃内容之间的休息时间，它自己就能成为正文。**

幽默的吸引力常在一个很短的转折里：你已经按一种意思往前走，突然发现还可以这样理解。生活没有多出一件东西，原来的东西却换了一个角度。

本章既不把笑当成健康任务，也不把幽默缩成“不要冒犯”的规定。先问[好笑为什么值得认真对待](#humor-attention)，再从[短句里的转弯](#humor-expression)，读到[两场文学中的下午茶](#humor-scenes)：一盘三明治如何让台词当场露馅，一个关于时间的词语游戏如何把整场茶会困住。最后讨论[笑声与参与的边界](#humor-context)。

想直接读作品，可以从[消失的三明治](#humor-sandwich)、[词句换位](#humor-language)或[停在六点的茶会](#humor-time)开始；也可以跳到[知道结尾以后还看什么](#humor-return)和[为什么不必把好笑换成别的收益](#humor-attention)。

未注明作品出处的例句为本书原创说明，不是受众测试结果；作品部分为注明出处的情节转述与本书解读，不冒称名家译文或保证逗笑的公式。

<a id="humor-attention"></a>
<a id="为什么要这么认真读一件没用的事"></a>
## 一、为什么要这么认真读一件“没用”的事？

因为有趣不必等知识收益替它盖章。一场喜剧可以让人看见语言、阶层、礼貌和关系；如果有人只是为了看人物一本正经地胡闹，也不是次一级的阅读理由。

把幽默称为缓解压力的工具，可能是在描述一种用途；若只允许它以用途获得位置，又会把它变成工作间隙的维修。好笑可以尖锐，也可以琐碎，可以带来认识，也可以这次仅仅让你愿意再读一段。

本书所说的“耍起”，不只是安排一小段允许放松的时间。它也包括承认：**有些事情值得认真投入，恰恰不因为它们能兑换成更严肃的回报。**花心思理解一场喜剧，不必比快速看懂一条道理低一等。

这不等于所有段子都一样好，也不等于不能批评。我们仍然可以问：细节是否准确，铺垫是否有作用，人物是否只剩一个标签，反复出现的东西有没有变化。拒绝把快乐工具化，不是拒绝讨论作品的好坏；有关快乐是否是唯一价值的争论，另见[关于享乐主义的长文](../essays/11-pleasure-and-reality.md)。

<a id="humor-expression"></a>
## 二、一个转折怎样起作用？

<a id="一个转弯从普通陈述到可以看见的错位"></a>
### 一个转弯：从普通陈述到可以看见的错位

先看两句话：

- 我买了很多书，还没有开始读。
- 我家的书架已经很有文化了，目前主要在等我。

第二句没有提供更多购书事实，而是把“有文化”从人移到了家具，又把尚未阅读写成书架正在等待。读者先接受一个不太合理的拟人，再在最后认出熟悉的处境。

它是否好笑，各人可以不同。但至少能说明一个表达选择：原本可以直接说出的事实，被安排成一段需要读者补上最后关系的话。

“我不会做饭”和“我的拿手菜是打开外卖盒”也是类似的转移。前半句让人期待一种烹饪能力，后半句给出一个不属于烹饪、却属于吃饭流程的动作。它并非完全无关，所以可能形成落差；若后半句只换成一个毫不相干的名词，意外仍在，却未必有可以接起来的意思。

这不是幽默的完整公式。双关、节奏、表情、模仿、身体动作以及共同经历，都可能带来不同乐趣。本章只讨论其中一些可用文字看清的关系。

<a id="反转不只靠最后一句也靠前面让人等什么"></a>
### 反转不只靠最后一句，也靠前面让人等什么

看另一个原创例子：

“这次出门我准备得非常充分：查了路线，看了天气，最后决定不出门。”

前两项建立了准备出发的方向，最后一项却把全部准备转成取消依据。笑点如果成立，不仅因为“不出门”意外，也因为它仍然可以解释前面的查路线和看天气。

如果一开始就说“我决定不出门，之前查了路线和天气”，信息大致相同，阅读时的期待却不同。事实次序和讲述次序不必相同，讲述可以先让人走上一条路，再转弯。

不过，铺垫不一定越长越有效。如果为了藏住结尾，把无关背景堆得太多，听者可能还没等到转弯就失去兴趣。删句子时可以问：这一句是在建立之后需要被改变的理解，还是只是担心别人不知道自己准备得很认真？

也不是所有笑话都需要突然翻转。有时一开始就知道荒唐之处，乐趣来自它继续发展到哪里。

<a id="把一条歪理认真执行能长出什么"></a>
### 把一条歪理认真执行，能长出什么

“为了减少作决定，我给每个决定做了一张比较表。现在主要在决定先看哪张。”

这里不依赖某个陌生事件，而是把一种熟悉办法推到反过来制造原问题的位置。比较本想减少纠结，比较本身却成为新的纠结。

继续发展时，可以沿同一关系增加一层：“后来我选出了最省时间的表格制作软件，正在看教程。”新增的内容仍围绕省时工具吞掉时间。如果突然接入另一个不相关的抱怨，就不再是同一条歪理的发展。

这提供一种写法：先找一个普通目标，再看执行手段能否以夸张方式反过来破坏它。夸张需要让人认出原来的关系，而不是越大、越离谱就越有效。

同样，这个例子不是论证比较工具无用。幽默可以放大局部矛盾，但局部矛盾并不能代替完整事实判断。听完笑了，不等于已经接受一项普遍结论。

<a id="重复与回扣第二次出现时意思已经不同"></a>
### 重复与回扣：第二次出现时，意思已经不同

第一次说“书架在等我”，可能只是一个关于买书不读的短句。后来谈到买了运动器材却没使用，又说“现在全家家具都比我有规划”，前面的书架便获得了新的位置。

这个回扣借用的是共同听过的内容。没有听到前面的人，仍可能明白后一句，却未必获得同样的连接感。也因此，一个群体的内部梗被原样搬到别处，常常只剩一句旁人不知道从哪里来的话。

重复还可以建立预期，让下一次轻微改变产生效果。但重复本身也会耗尽新意。没人需要因为第一次笑了，就承诺第十次还同样好笑。

若反复出现的是某个人的失误，问题更不只是新鲜度。一次被共同接受的调侃，可能逐渐变成一个人摆脱不了的身份标签。记住一个笑点，与不允许当事人离开那个笑点，是两回事。

<a id="同一件小事可以从三个方向变形"></a>
### 同一件小事，可以从三个方向变形

以“刚收拾好的桌子很快又乱了”为材料，试着写三个版本。它们仍是原创说明例，不代表实测有效的写作规则。

**把小事说成大事：**“桌面整洁维持了四分钟，期间没有发生重大历史事件。”

整洁是小范围、短时间的状态，后半句却借来记录重大时期的口吻。反差来自描述尺度，不需要增加一个真实倒霉的人。

**把常见词按另一层意思执行：**“我把桌面上的问题都收进了抽屉。现在桌面没问题了，抽屉有意见。”

“问题”先指零散物品，随后变成人与抽屉之间的意见。物品没消失，表达却暂时把它们搬进了一场关系。

**换一个观察者：**“桌子大概以为我收拾它，是为了腾出地方放更多东西。”

这里没有突然的强转折，而是让桌子替你解释反复出现的行为。旁观者的推断和主人原先的意图错开了。

三句话可以都不合你的口味，也可以有一句让你愿意继续改。比较它们时，与其问哪句更高级，不如看哪一种声音更接近你想说的话：庄重地说小事、让词语换轨，还是暂时借一个不可能的观察位置。

如果改写成“我这么乱，简直是全世界最没用的人”，强度增加了，细节却变少了。它也许仍能在特定表演中成立，但并没有自动比前三句更有意思。**幽默的锋利，可以来自看得具体，不必来自贬得更狠。**

<a id="一本正经故意装傻明显夸张不是同一种声音"></a>
### 一本正经、故意装傻、明显夸张，不是同一种声音

同一句荒唐的话，可以说得非常认真，也可以提前露出夸张。前一种让听者慢慢察觉不对，后一种直接邀请大家进入一段不按日常规则运行的话。

在文字里，标点、称呼、句子长短与上下文会承担一部分语气；在当面交流中，停顿、表情和声音也会加入。把一句话截成截图，就可能删除了原来帮助理解的部分。

这不是说“只要知道我是开玩笑，就必须接受”。语气能够提示你正在怎样说话，却不能自动证明内容没有影响。明显夸张的嘲讽仍然可能伤人；认真说出的荒唐话也可能被当作事实。

因此，当别人误解时，有时需要补足上下文，有时需要承认自己说得不清楚；不能一概把问题归成对方没有幽默感。

<a id="humor-scenes"></a>
## 三、笑点已经知道，为什么还愿意看下去？

短句可以在最后几个字转弯，一场喜剧却还要让人物继续待下去。下面两场下午茶，不只靠不知道结尾来吸引人：台词、动作与物件也在改变关系。

<a id="humor-sandwich"></a>
<a id="一盘三明治台词还在讲礼貌手已经拆了台"></a>
### 一盘三明治：台词还在讲礼貌，手已经拆了台

王尔德的喜剧 *The Importance of Being Earnest* 第一幕，地点在阿尔杰农（Algernon）的客厅。这里不是先有人宣布“我要讲一个笑话”，而是摆好了下午茶，人物一边聊天一边吃。以下只讨论开场到姨妈来访后的局部场景，不涉及全剧结尾；人物初次出现时保留英文名便于查找，中文为本书转述。[原作与读取范围：F37](../docs/evidence/F37-comic-scenes.md)

首先有一个很具体的约定：黄瓜三明治是为姨妈布拉克内尔夫人（Lady Bracknell）准备的。负责茶点的莱恩（Lane）已经做好并端来，阿尔杰农检查时便拿走两块。来访的杰克（Jack）伸手去拿，阿尔杰农却拦住他，说明这些是专门留给姨妈的——舞台提示紧接着让他自己又吃了一块。

**如果只抄台词而删掉动作，这一处便会损失重要内容。**“为客人保留食物”的规矩由嘴说出，又被同一个人的手当场破坏。杰克指出他一直在吃，他的解释不是否认，而是把亲属关系变成例外：那毕竟是他的姨妈。

荒唐因此不止在“双重标准”四个字。我们看见规则怎样被生产出来：限制别人时讲用途，轮到自己时换成关系；理由随着需要移动，语气却依旧郑重。盘子上的食物在减少，对话中的体面还没有减少。

<details>
<summary>展开局部情节：等姨妈真的到了，盘子怎么办？</summary>

布拉克内尔夫人到场后提起答应给她的三明治。阿尔杰农拿起空盘，表现得十分惊讶，转而询问莱恩为什么没有准备。莱恩严肃地回答：早上市面上根本没有黄瓜，他去了两次，甚至拿现钱也买不到。阿尔杰农接受这套说法，并向姨妈表示遗憾。

此时读者不需要猜“到底谁吃的”。我们已经读到食物被端上来，也反复看见阿尔杰农吃。真正继续发生的是：明明存在过的食物，被一套互相配合的说辞解释成从未可能出现。

莱恩不是简单重复一句谎言。他加上跑了两次、现钱也买不到的细节，使借口获得了努力办事却遭遇客观困难的外观。阿尔杰农又把这套外观转述给客人。看这段，可以留意说法如何升级，而不只是等一个揭穿瞬间。

作品未在这里让姨妈追究到底，她表示没有关系，因为之前已经吃过。于是这场小小的逃避没有按“做错事—被抓住—受教训”的次序结束。读者知道的事，不必立刻变成每个人都知道的事。

</details>

这段提供一种不同于藏包袱的乐趣：**观众先看见，人物继续装不知道。**就像看一个人给正在漏水的桶写防水说明，吸引力可以来自解释越认真、眼前证据越不配合。

后一比喻是本书原创，不是王尔德的句子。把这场戏读成“体面如何给欲望找借口”，也是基于动作与台词的解读，不等于确认作者的唯一意图，更不说明观众赞同这些人物。

三明治还把抽象的规矩变成了可见的东西。每吃一块，可用的余地就少一点；到了空盘，借口必须换挡。道具不是替对话装饰客厅，它参与了对话能够怎样继续。

<a id="humor-language"></a>
<a id="不是乱说一句话调换位置关系已经变了"></a>
### 不是乱说：一句话调换位置，关系已经变了

再到刘易斯·卡罗尔的《爱丽丝漫游奇境》英文原作 *Alice’s Adventures in Wonderland* 第七章。爱丽丝（Alice）来到一张很大的茶桌旁，却被挤在一角的客人喊着“没地方了”。从这开始，眼前空间和待客话语就不合作。下面涉及本章局部情节，同样是本书转述。[F37](../docs/evidence/F37-comic-scenes.md)

一个看起来终于可以好好玩的时刻出现了：帽匠（Hatter）提出乌鸦与写字台的谜语。爱丽丝乐于猜谜，谈话却转去纠正她怎样表达自己的意思。她把“把自己想表达的说出来”和“自己说出的正是想表达的”当成一回事，其他人连续拿换位句来反驳。

原文用到吃与看、喜欢与得到、睡与呼吸。这些句子并非因为词序变了就自动可笑；关键是调换之后，关系未必仍成立。以喜欢和得到为例，能够喜欢已经得到的东西，不意味着总能得到自己喜欢的东西。相同词汇保持熟悉，关系改变带来偏移。

这段也不需要被包装成严格逻辑课。三个人轮流举例，本身就是人物相处的节奏：先有人抓住爱丽丝的表达，再有人继续加码，最后连似睡非睡的睡鼠（Dormouse）都补上一条；帽匠又把最后一条转回睡鼠本人的状态。句式在重复，笑点的位置却从语言移到了人物。

如果只概括为“这群人都在胡说”，反而漏掉了局部认真。**荒诞可以同时包含可靠的小判断和不讲理的大场面。**一个人说对了某个细节，并不表示他正在真诚帮助对方理解；挑错也可以被写成一场争夺发言位置的游戏。

谜语后来并未由出题者给出答案，帽匠和三月兔（March Hare）都承认不知道。这改变了爱丽丝原先期待的玩法：她以为有一条等待解开的关系，对面却没有承诺提供谜底。本书只就所读第七章作此判断，不断言这道谜语在作者后来的说明和其他版本里从未出现答案。

在虚构场景中，我们可以欣赏这种落空怎样延展谈话；在现实聚会里，别人也完全可以觉得浪费时间。欣赏一个不好相处的人物，和愿意成为他的客人，是两件事。

<a id="humor-time"></a>
<a id="时间停在六点让一句歪理长出家具杯子和后果"></a>
### 时间停在六点：让一句歪理长出家具、杯子和后果

爱丽丝抱怨这种没有答案的谜语浪费时间。帽匠不按抽象的时长理解“时间”，而把 Time 当成一个可以认识、交好、得罪的对象。英语中的 `beat time` 可以指打拍子，他却顺着打的字面意思说下去：时间当然不愿意挨打。

这一转弯有语言条件。中文“打拍子”与“殴打时间”并不天然共用同一个宾语，因此不能只给一段顺滑译文，就假装中文原本也有完全相同的机关。这里保留少量英语，是为了看见词怎样换轨，不是要求读者先会英语才有资格觉得好笑。

接下来，作品没有满足于一次误听。帽匠讲述自己在演唱后得罪 Time 的经过；从那以后，时间不再配合，钟点总是六点。我们正在读人物的讲述，不需要把它认证成整个虚构世界无例外的物理定律。

沿着这套说法，桌上的细节开始连起来：

| 场景给出的条件 | 它让什么后果继续出现 |
| --- | --- |
| 总是六点，总在喝茶 | 没有通常用于洗茶具的间隔 |
| 茶具用过了 | 大家沿着桌子换到下一处 |
| 继续绕桌换位 | 爱丽丝可以追问：绕回起点怎么办？ |

这个追问没有得到完整系统说明，三月兔转去要求讲故事。别替作品补一套闭合的时间模型：它给了足够多的后果，让你想继续追究，又保留了人物随时转移话题的不讲理。

随后他们确实为了干净杯子换位。叙述明确指出，这次主要得利的是帽匠；爱丽丝接到的位置反而更糟，因为三月兔已把牛奶弄进盘子里。**一句“大家挪一下”，并不意味着每个人都获得同样的好处。**桌子、杯子与座次让前面的规则落到了具体人的处境。

这是把荒唐写厚的一种办法：不是再添加十件毫无关联的怪事，而是让同一个奇怪前提继续影响动作、物品和关系。读者可以追着它走，也可以发现人物在哪一步不再愿意回答。

而这不是一场必须被解释成幸福的茶会。爱丽丝最终厌恶地离开；她最后看见的，是另外两人试图把睡鼠塞进茶壶。对场外读者而言，人物与语言的安排可能有趣；对场内角色而言，这场相处并不好受。文学让这两种位置同时可见，不要求其中一种取消另一种。

<a id="humor-return"></a>
<a id="知道结尾以后还能看什么"></a>
### 知道结尾以后，还能看什么？

如果好笑只能来自不知道下一句，重读便只剩一次失效的猜谜。但上述两段至少提供别的观看对象：三明治在什么时候又被吃掉，谁先提出规则，谁替借口加细节；茶会何时沿着词义较真，何时又突然拒绝继续讲理。

第一次可以追事情怎样发展；再看时，可以注意发展是怎样被安排的。它不保证第二次更好笑，只说明“结尾已经知道”不等于“文本已经没有可看的关系”。

这里也有文字与演出的区别。王尔德的舞台提示写到严肃、惊讶和吃东西，本书能依据这些提示分析动作与话语；却没有因此看过某次演员演出，不能给它补上一个几秒的停顿、观众齐笑的记录或某种必然有效的表情。

也可以用一个原创改写比较，看哪部分值得保留：

- **直接下判断：**他总给自己找例外。
- **只留对白：**这块蛋糕专门留给客人，你不能吃，我可以。
- **让动作参与：**他把“请勿取用”的牌子摆正，又用叉子修齐了一下蛋糕边缘。

第三句仍可能不好笑，但它把判断藏回一件能看见的事。“修齐”可以既像维护秩序，又像替取食找个体面名称；读者需要自己连接这两层。这里没有假装它是原作删改稿，更没有声称比原作写得好。

学习这种安排，也不必把每次聊天都当发表作品。你可以只享受别人写得巧，不生产段子、不主持聚会、不负责让全桌开心。欣赏者不是尚未升级的创作者。

<a id="humor-context"></a>
## 四、谁在一起玩，谁在替笑声付代价？

而当虚构场景换成真人相处，还需要另问一个问题：谁选择进入这个玩笑，谁只是被别人放了进去？下面的研究和关系讨论补上这个维度，不负责把前面的欣赏体验认证为有效或无害。

<a id="良性违背提供一个视角不是全世界笑话的总开关"></a>
### “良性违背”提供一个视角，不是全世界笑话的总开关

McGraw 与 Warren 的一组研究提出：某件事既被理解为违背规范，又同时显得可以接受时，可能引出幽默。他们用五项研究考察道德越界情境，包括不同描述、规范认同与距离线索。[B13 阅读记录](../docs/evidence/B13-humor.md)

这里的“良性”首先指参与者如何理解情境，不是作者或讲笑话的人替所有相关者宣布客观无害。实验里的虚构描述，也不是现实行为的许可。

研究一个重要结果是：觉得好笑与反感能够一起出现。它们没有被证明是一条刻度的两端，不是反感少一点便自动多一点幽默。

但这也不能直接告诉我们，一个人现场笑了，究竟是觉得有趣、紧张、想结束话题，还是不便拒绝。那些具体解释需要了解情境，不能从一个表情里读出全部意思。

研究的样本和材料范围有限，没有因此证明所有文字游戏、喜剧、模仿和日常调侃都由同一种机制充分解释。本章用它打开一个问题：**同一个转折，什么使一些人觉得可以一起玩，另一些人却仍在承担真实代价？**

<a id="一个笑话里至少有四个不同位置"></a>
### 一个笑话里，至少有四个不同位置

想象一个虚构聚会。甲提起乙一次迟到的糗事，丙丁笑了，乙也笑了一下。我们至少可以分开看：

| 位置 | 可能在意什么 | 不能替谁作决定 |
| --- | --- | --- |
| 讲述的人 | 表达是否有趣、现场是否热络 | 不能单独定义被讲述者的边界 |
| 被讲述的人 | 隐私、形象、关系、是否愿意再讲 | 不必替全场维持好气氛 |
| 旁边听的人 | 笑点、共同背景、是否理解发生了什么 | 笑了不等于了解当事人的处境 |
| 后来看到片段的人 | 剩下的文字、视频和自己的解释 | 不能假定拥有原现场的共同约定 |

这是一张关系分析表，不是心理测验。乙的笑可能真心觉得有趣，也可能并不想在当场打断。仅凭这一个动作，无法确定。

如果乙后来明确说不想再被提起，继续要求他证明自己当时“不是真的笑”，没有必要。后来的边界可以直接改变下一次做法，不必先赢一场关于表情的审判。

<a id="我们关系好不是永久授权"></a>
### “我们关系好”不是永久授权

熟悉可以提供共同背景，也可以让某些调侃被更准确地理解。朋友之间愿意互相开玩笑，本身是一种有价值的相处。

可是熟悉不意味着内容、场合、观众永远不变。原来只有两个人知道的糗事，被拿到同事面前讲，关系结构已经改变；自己愿意讲一次，与别人可以随时替自己讲，也不相同。

可以直接问某件具体事情是否能提，不必把询问想成每句话都先签文件。若已经知道那是对方在意、不愿公开的内容，就没有必要用突然开玩笑来测试底线。

别人说“不好笑”，也未必是在要求全世界禁止这一类笑话。他可能只是在说，这次他不愿意这样参与。把这个局部回应升级成“以后什么都不能说了”，反而关闭了更具体的讨论。

<a id="自嘲可以是表达不必成为入场费"></a>
### 自嘲可以是表达，不必成为入场费

“我方向感差得很稳定”可能是自己愿意讲的轻松一笔。它可以让别人知道这次的小失误，不必每次都郑重道歉。

但自嘲也可能变成一种被期待的角色：一个人只要想加入，就要先贬低自己；别人夸他时，他也必须立刻把夸奖拆掉。若只有不断把自己摆低，才能让现场舒服，那未必是本人想要的幽默。

对待别人的自嘲，不能自动接成更狠的评价。对方说“这张照片拍得好奇怪”，不等于邀请你列出他的外貌缺点。他拿自己的某个处境作材料，也不等于把同样处境下的所有人授权为笑点。

你当然可以认真喜欢自己的缺点被写成一个好句子。需要保留的是选择，而不是把自我否定变成证明合群的费用。

<a id="可以拿问题开玩笑不必拿求助的人当笑点"></a>
### 可以拿问题开玩笑，不必拿求助的人当笑点

一个虚构例子：朋友说最近计划总被打断。你可以一起笑那些层层增加的表格、永远跳出来的通知；也可以先听他究竟在烦什么。

如果他正在认真说明无法承担的事情，而你只回答“你就是想太多”，即使语气轻松，也没有因此完成一次幽默的帮助。你可能只是把他的难题改写成他的性格。

这不意味着严肃处境里不能笑。笑可以来自当事人自己，也可以来自双方都愿意暂时换个角度。区别在于，你是在和他一起看问题，还是用笑声把问题从对话里赶走。

本章没有证据保证幽默能够处理冲突、痛苦或心理症状。它讨论相处，不提供治疗方法。**笑声可以加入一次认真的交谈，不必取代它。**

<a id="幽默有时能拆掉权威也能替权威卸责"></a>
### 幽默有时能拆掉权威，也能替权威卸责

把冗长要求讲得荒唐，能让人看见一条规则本来可以被质疑。前面“为了省时而研究省时工具”的例子，就把看似正确的做法放回实际后果里。

但同样的技巧也能替权力减轻责任。一个必须认真回答的问题，被一句笑话带过；提出问题的人，反而被说成扫兴。这里好不好笑，与有没有回答问题，是两项判断。

因此我们不规定幽默只能朝哪个固定方向使用，也不把任何对象天然判为不可讨论。要问的是：实际指向了什么，依赖哪些事实，谁能够回应，谁必须承受。

可以嘲讽荒唐的要求，同时准确描述那个要求；也可以不同意一位人物的观点，而不编造他说过的话。**把事情说得好笑，不应成为把事情说假的理由。**

<a id="发出去以后上下文不会自动跟着走"></a>
### 发出去以后，上下文不会自动跟着走

给熟人看的梗图、现场的一句模仿和公开发出的段子，受众并不相同。公开文本可能被截取、转述，也可能离开原先帮助理解的背景。

这不是要求每句话消灭所有误读，那做不到。更可行的是，对需要事实前提的内容说清前提，对真人经历取得相应同意，不把私下聊天当成默认可公开的素材。

改编也应分清：原句来自谁，哪些是自己的变化，哪些只是转发看到的版本。不确定出处时，可以说没有核实，不把一个好句子硬安在名人身上。

“只是个梗”不能证明事实真假，也不能替一次未经同意的公开作解释。反过来，承认某句话是创作，并不降低它作为创作的价值。

<a id="没有人笑下一句不必更狠"></a>
### 没有人笑，下一句不必更狠

一个段子没有得到反应，可能是没听清、缺少共同背景、节奏不合，也可能就是不喜欢。继续解释可以澄清含义，但不能逼出感受。

如果为了挽救冷场，马上加大羞辱、暴露更多隐私或挑一个更难拒绝的人，目标已经从一起玩变成了必须赢得反应。

也可以简单收住：“这个没讲好，换个话题。”不需要将一小段沉默升级成社交失败，更不必强迫自己整晚负责活跃气氛。好笑是某些时刻发生的事，不是每个人必须持续供应的服务。

认真写幽默的人则可以修改：铺垫是否建立了预期，结尾能否接回前面，有没有无关解释，听者是否需要你没有交代的背景。修改是技艺问题；别人不笑，不因此欠你一次练习机会。

<a id="最强的反对意见顾虑这么多幽默不就没了"></a>
### 最强的反对意见：顾虑这么多，幽默不就没了？

如果要求每一句话都被所有人喜欢，幽默确实会难以存在。但本章没有提出这个要求。我们允许尖锐、荒唐、尴尬、黑色幽默，也允许有人不喜欢。

需要放弃的是另一种特权：讲的人可以尝试，被讲的人却必须配合；别人不笑就归为迟钝，别人受伤就归为输不起。

一种幽默可以带来争论，甚至让人重新看待自己的假设。它应当允许争论继续，而不是在遇到回应时退回“开玩笑你还认真”。

**好笑不必有用，也不必无懈可击。它只是不该以剥夺别人的回应权，来保证自己永远成功。**
