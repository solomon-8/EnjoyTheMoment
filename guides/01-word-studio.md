# P001 · 烂广告事务所：给一件破东西写一场发布会

<!-- playbook: {"id":"P001","category":"纸笔与语言","minutes":45,"budget":0,"company":"social","energy":"medium","card_ids":["J019","J022","J024"],"summary":"2—6 人，拿现有纸笔，把平常物件变成荒唐产品；有现成题目、完整轮次和不愿表演时的玩法。"} -->

**说人话：一只漏水杯、一张皱纸，也能有一本正经的广告。大家轮流一本正经地胡说，不推销真的商品，不评谁最有才。**

主局按 45 分钟封顶，包含当场写题和收拾；人已经在一起，或已进入同一个通话。需要纸笔，线上可以用各自的聊天草稿；无需购买物件。适合 2—6 人，愿意说话的人说，不愿意说的人负责写。这里的规则和例子是本项目设计的娱乐玩法，不是经过效果验证的团建方案。

## 十秒钟知道在玩什么

抽一张“物件”，再抽一张“奇怪限制”，给它取名，写三句广告，讲给别人听。下一位不是投资人，不负责挑错，只补一句荒唐的售后承诺。比如：

物件是“一把少了一颗扣子的伞”，限制是“不能说防雨”。产品就叫“天气谈判桌”；三句广告是：“开合之间，拥有一个小型屋顶。”“特别适合在门口犹豫。”“我们不改变天气，我们延长出门前的仪式。”售后承诺：“每遇一次晴天，免费获得一次没带错东西的感觉。”

**笑点可以来自物件、命名、一本正经的语气，不必来自让某个人难堪。**

## 开局前，只问这两句话

“想不想玩一个给破东西写广告的游戏？可以只写不念，十五分钟觉得不好玩就散。”

“我们今天是温柔乱讲，还是可以互相吐槽？真实朋友、长相、工作和收入默认不进题目。”

如果有人说“我不擅长”，不要回答“来都来了”。把身份拆开：一个人取名，一个人想用途，一个人念。也可以旁听，不为旁听者计零分。

不要临时拿别人珍视的东西当“破东西”。物件卡写的是虚构版本，避免把聚会变成某个人生活品位的批判会。

## 桌面上放什么

把下面两组各抄六条，纸折起来。也可以由一人念序号，另一人随意报 1—6，而不是下载随机工具。

| 物件 | 奇怪限制 |
| --- | --- |
| 一只总滚到桌下的笔 | 广告里不能说它原来的用途 |
| 一张撕坏了一角的贴纸 | 顾客是一群刚退休的龙 |
| 一个不装东西的盒子 | 必须强调它什么都不改善 |
| 一双左右颜色不同的袜子 | 产品发布在月球上的小卖部 |
| 一把只剩半边齿的梳子 | 宣传语里必须出现“周二” |
| 一块没有任何花纹的布 | 只能承诺一件极其小的事 |

例子是启动器，不是标准答案。不想抄题就直接看表：玩家选物件，旁边的人选限制。这样准备只需要几分钟，且不会因为抽不到好题一直重抽。

纸张有限时，一人一页分成四格即可。需要字大就用整页，不追求公平的纸张配额。写不方便的人可以口述给同伴，听不方便的人可以看文字；先确定参与方式，再开始倒计时。

## 一局如何走完

### 第一轮：把嘴热起来，不比赛

用同一个物件“空盒子”，所有人各想一个名字。留一两分钟，有名字就交，没有名字就说“盒子”。主持人接一句：“很务实，我们公司就缺这种人。”不要把这句话指向本人能力，只是承认简单答案也能继续游戏。

大家看一眼名字，任选一个继续编用途。比如“周末收纳器”，作用是把写着“不想做”的纸条放进去，关盖后不必读出来。这里不要真的要求参与者公开压力或秘密；产品介绍可以全是编的。

### 第二轮：三句广告

每人拿一个物件和一个限制，独自写三句，每句只负责一件事：

1. 它叫什么，给谁用。
   例如：“云朵暂存箱，专给没空抬头的人。”
2. 它有什么荒唐功能。
   例如：“打开后，里面依旧没有云，但你已经抬头看了一次。”
3. 它有一个怎样的小小缺点。
   例如：“阴天也照常营业，库存始终为零。”

写三句比“自由发挥”更容易交卷，但不是必须填满。只想出一个好名字就念名字。给准备设一个松的上限：约五分钟，不等全场都完美才开始。

### 第三轮：发布会

轮流念，建议每人不超过一分钟。其他人只做两种回应：“我最想留下的词是……”或者补一句售后。不要追问“这有什么用”，那会把游戏拉回商业答辩。

想加悬念的话，广告念完再让大家猜物件。猜不到就亮答案，最多两次猜测，不用拖到所有人都尴尬。不能说原用途的题允许文字描述形状、颜色，不禁止一切线索。

### 第四轮：联合产品

任选两个刚出现的产品，合成一个新产品。空盒子加袜子，可以叫“移动式周末”；梳子加布，可以叫“发型隐私保护罩”。两三人一起写一句广告就够，不再办第二场长发布会。

留下自己喜欢的那一张，其余纸张收走。没有赢家也能结束：“今天公司上市失败，笑话成功下班。”

## 不同人数，不同开法

**两个人**：不要假装评委齐全。甲选物件，乙加限制，合写一个产品，再互换。两轮之后选一句最想贴在冰箱上的话。重点是合作，不是轮流考住对方。

**三四个人**：一人念稿，一人负责售后，其他人猜物件。每轮换角色。有人连续想得快，可以请他负责念别人的稿，把注意力还给桌上其他人。

**五六个人**：分两组，每组先合作。这样不用坐着等五个人写完。每组展示两个产品便结束，别让“全员都要来一遍”吞掉晚上的其他活动。

**线上**：各自把文字保留在草稿，数三声一起发；不要实时盯着别人打字。只开文字也成立。消息截图和对外发布需要另问，不把加入游戏等同于同意出现在社交平台。

## 三种冷场，怎么救

**大家只写真实商品介绍。** 不必讲“要有想象力”。直接加一个小限制：“这件东西只能帮助人度过星期二下午的两分钟。”限制缩小后，答案可能反而更容易出现。如果仍不好笑，把目标换成“最诚实广告”，例如“这根笔会写完，但目前还没写完”。

**一个人包揽所有笑点。** 不要求他闭嘴，也不默认其他人快乐。改成每人只能添加一个词，串成全组广告；或者让爱说的人当播音员，稿由别人写。角色分工比“大家积极一点”更有用。

**开始互相嘲笑现实生活。** 主持人直接把题收回来：“产品可以惨，人不用惨。换一个完全不存在的顾客。”不必现场审判谁开不起玩笑；换题已经足够。受影响的人可以退出，不承担解释义务。

## 想再耍一轮，可以怎么变

选一种变化，不要全加。

- **反广告**：认真列出“这东西完全不适合谁”，但对象是虚构角色。给忙得脚不沾地的蜈蚣卖袜子，光退换货就能成故事。
- **一字之差**：把一个普通名称改一个字，比如“收纳盒”变成“收懒盒”，再解释它怎么工作。不要使用真实商标做欺骗性推广。
- **三件套**：产品名、使用说明、报修原因各由不同人写，最后连起来念。荒唐来自前后冲突，不是来自谁写错了。
- **无声发布会**：把广告摆在桌上，大家各画一个小图回应。对不想表演的人，这就是完整玩法，不是降级版。

## 什么时候这局不值得继续

如果桌上的人想吃饭、聊正经事或休息，不用为了规则再拖一轮。有人讨厌被限时写作，可以取消计时，或者换成看现成广告例子挑最喜欢的一句。

“没有才华”不是失败条件，**没人想继续才是散场信号**。不要把这套游戏安排成职场强制破冰，也不拿生成数量给人排名。散场后只保留参与者愿意保留的文字。
