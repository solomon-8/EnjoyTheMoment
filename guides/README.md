# 完整玩法：主张之外，亲自试一口

[← 首页](../README.md) · [核心论证](../essays/07-rest-is-not-work.md)

这里是配套实践，不是人生必修课，也不替代价值论证。所有玩法是原创编排，未声称经过用户效果验证；时间为预留上限，零元指使用已经拥有且有权使用的资源。邀请、往返与额外消费按各篇说明另行确认。

| 玩法 | 适合怎样的一次尝试 |
| --- | --- |
| [P001 · 烂广告事务所：给一件破东西写一场发布会](01-word-studio.md) | 2—6 人，拿现有纸笔，把平常物件变成荒唐产品；有现成题目、完整轮次和不愿表演时的玩法。 |
| [P002 · 画歪传话：画得不像，故事才开始](02-drawing-telephone.md) | 3—6 人交替写句子、画图和猜图，把传错当成笑点；给不画画、不识字或人数不足的情况留了完整替代玩法。 |
| [P003 · 临时编剧室：四张纸，把一个普通晚上编成奇遇](03-story-room.md) | 1—5 人用角色、愿望、麻烦和转折搭一个短故事；提供题牌、示范、接不下去的救场方式和独自版本。 |
| [P004 · 客厅小影展：不是找最好的电影，是找今晚想看的](04-living-room-cinema.md) | 用现有观看权限组一场自己的小影展；从选片僵局、同伴口味、片长到散场聊天，给出具体流程。 |
| [P005 · 三首歌电台：用自己的口味接管二十分钟](05-three-song-radio.md) | 1—4 人各带一首已有权限播放的歌，串成小电台；不比曲库、不强迫分享隐私，也不用公开播放或上传。 |
| [P006 · 桌面音效棚：用一张纸给一艘飞船配音](06-foley-studio.md) | 用纸、布、空盒等现有安全物件，为自己编的三十秒场景做声音；不靠软件，也不模仿危险操作。 |
| [P007 · 附近寻宝：把一条熟路玩成九格观察局](07-photo-hunt.md) | 在已知开放、方便往返的熟悉范围找颜色、形状与小细节；可拍照，也可只记在纸上，不追逐陌生人和危险机位。 |
| [P008 · 私人物件小博物馆：让抽屉里的五件东西开个展](08-object-museum.md) | 从自己有权使用的物件里选五件，写短展签、安排顺序、办一次可撤展的小展；不要求整理整个家或公开私人经历。 |
| [P009 · 四个人的小聚会：主办人也应该玩到](09-host-a-small-night.md) | 用已有空间和材料办一场不附带消费的四人小聚；提供邀请文本、分工、开场、换活动和准时散场的方法。 |
| [P010 · 桌面侦探局：三封送错的信，没有一个坏人](10-desk-detective.md) | 一份可以直接玩的原创逻辑小案，包含角色、线索、分级提示和唯一答案；独自推理或三人合作，不靠搜题。 |
