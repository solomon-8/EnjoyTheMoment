# 享受当下 · Enjoy The Moment

**耍起。把快乐当正事，把今天过到自己手里。**

一本以「耍起」为核心表达的开源生活指南：即时满足、感官快乐、新鲜感和非功利玩乐。<br>
不是等生活安排好了再耍，是生活里面本来就该有耍。

## “耍起”，是我们的核心，不只是封面上的梗

**人生不是一项只许增值、不许兑现的资产。** 我们偏爱把资源换成自己想经历的生活，而不只把生活换成更多资源。

“耍起”是本项目的核心表达，不冒充艺人原话或川渝文化的唯一解释；梗的语境见[有日期的来源](docs/culture-shuaqi.md)。我们要争论的不是快乐有没有副作用，而是：**当一段生活不让人更优秀，甚至让以后少得到一点，它还能不能被认真选择？**

## 我们站在哪一边

**同样负担得起时，我们愿意为更喜欢的味道多花一点，为期待已久的演出牺牲一些便利，为纯粹好玩留下一段没有产出的时间。** 不保证它后来会变成收入、健康或人脉，也不要求每个人都这样选。

我们不把“活得最长、攒得最多、看起来最自律”当人生的默认总目标。反对的是快乐永远候场，不是计划本身；改变的是价值排序，不是把安全建议逐条倒过来。

底线是：**自己愿意，他人同意，代价看得见，过程退得出。** [同意不等于赞许](essays/01-pleasure-is-an-end.md#pleasure-consent-scope)：牵动别人的安排要确认，私人快乐不必等待所有人满意。完整立场与愿付代价见[核心宣言](SHUAQI.md)。

> 今天不是明天的耗材。明天也不是今天的垃圾桶。

## 从一个真正的分歧开始

不必先认同“耍起”。挑一个你想反驳的问题，看看正文能不能回答你。

### [如果享乐确实会少赚一点，仍然值得吗？](essays/07-rest-is-not-work.md#rest-paid-evening)

**会少赚，不等于选错。** 想亲自度过的晚上也是所得，不必许诺以后补赚回来。

但一次与每个周末的累计代价不同，必要支出不能靠口号解决，自己的休息也不意味着别人必须随叫随到。

### [如果以后真的更好，为什么仍然可以选择今天？](essays/03-now-or-later.md#waiting-reliable-more)

**我们不只是在赌未来不会兑现。** 即使后来确实能得到更多，喜欢的生活怎样分布在日子里，也可以值得一次取舍。

但选择今天确实可能少得一些，不能改口说它总量更优；长期能力、保障与本人想要的集中投入，仍可能让等待胜出。

### [想要完整的刺激，为什么总被劝成五分钟？](essays/02-excitement-without-escalation.md#excitement-costs)

**有些快乐值得占用整晚，不只配塞进缝隙。** 小份是一个选项，不是愿望的规定尺寸。

但强度不是唯一方向，完整体验也不能让别人被迫承担代价。

### [把“人脉”换成“情绪价值”，就不再功利了吗？](essays/09-friends-not-assets.md#friends-not-a-service)

**没有利用价值，不等于没有相处价值。** 朋友可以一起享乐，却不该只剩快乐供应商的功能。

但非功利不是不谈费用，更不是拿友情取消别人拒绝的权利。

### [及时享乐，会不会只是及时被平台收割？](essays/10-pleasure-not-retention.md)

**想要不是命令，享乐不是服从。** 玩得久不等于更喜欢；怀疑一个指标，也不授予别人接管你的权力。即使真的更喜欢，也不等于已经答应这种安排。

但服务需要收入，主动设限也可能有用，不能把一切挽留都说成操控。

## 按问题找到完整论证

让 AI 协助阅读时，使用[阅读协议](docs/ai.md)或 [Skill](skills/enjoy-the-moment/SKILL.md)：先回应你的问题，需要活动时才推荐活动。只安装 Skill 不等于已经取得或读过书稿。

## 怎么读一张卡

每张卡写清楚六件事：

1. **现在做**：一个能开始的动作，不是一项人生改造工程。
2. **想得到**：希望体验到什么，不承诺每个人都有效。
3. **付出**：钱、时间、准备和可能的麻烦。
4. **换小份**：没钱、没空、不方便时的缩小版本。
5. **散场线**：什么时候可以停，什么时候不该硬上。
6. **性质**：这是价值选择、作者设计的试做，还是有来源的事实。

**这些行动卡全部属于原创试做，不是经实验验证的快乐处方。** 没有“幸福提高 37%”、没有多巴胺分数，也没有拿论文替你决定人生目的。方法和来源边界见[编辑标准](docs/editorial-policy.md)。

## 不知道选哪张？让电脑替你缩小范围

有 Python 3.9 或以上版本即可。**不联网、不上传记录、不安装第三方依赖**，从本地 Markdown 读取卡片：

```bash
python3 tools/pick.py --minutes 20 --budget 0 --company solo
python3 tools/pick.py --minutes 120 --budget 100 --energy high
python3 tools/pick.py --minutes 30 --budget 30 --list
python3 tools/pick.py --query 游戏 --minutes 60 --budget 0 --json --limit 3
python3 tools/pick.py --id J019 --json
```

筛选取的是卡片**主方案的预留上限**；想缩小动作，直接读“换小份”。抽到不想做的可以换，**随机结果不是命令**。

阅读页是同一份 Markdown 生成的单文件 `index.html`，下载整个仓库后可直接双击，离线也能搜索与读长文；外部出处链接需要网络。没有统计脚本、账号或浏览记录上传。生成与校验命令见[贡献指南](CONTRIBUTING.md)。

**想在电子书阅读器里通读？** [下载中文全文 EPUB](downloads/EnjoyTheMoment.epub)，或先看[不同版本的阅读说明](docs/reading-editions.md)。长文、章节、研究限制、配图和署名随书保留；折叠内容直接展开。EPUB 不含网页的筛选和随机按钮，外部出处仍需联网，已下载的文件不会自动更新。

## 与参考仓库的关系

受 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 的开源生活指南形式启发。参考仓库实际覆盖寿命、金钱、时间精力和人身自由，不只是长寿。

我们借鉴问题索引、分章卡片、明确代价和开放纠错的组织方式；不搬运正文，不继承其数据或健康结论，不代表原作者，也不把它塑造成“反对享受”的靶子。新仓库的不同在于：**把当下亲自感受到的快乐放在目标位置，而不是必须向未来收益解释的成本位置。**

参考版本、阅读范围和借鉴边界见[来源与致谢](docs/sources.md)。
