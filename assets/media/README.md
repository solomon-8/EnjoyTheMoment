# 音乐、电影与图解素材署名

本目录同时包含已有作品的数字复制局部与本项目原创图解，分别说明如下。已有作品不因仓库的 MIT 许可而改变原有权利状态。源文件获取与核读始于 2026-09-29，影片局部图像复核延续至 2026-09-30。

## 风味与服装原创图解

- `ice-cream-volume.svg` / `.png`：原创体积算例。100毫升原混合液分别增加50或100毫升空气，假设无其他体积变化；说明膨胀率与成品空气体积分数的不同分母，不是微观结构、配方或商品检测。详见 [F25](../../docs/evidence/F25-ice-cream-structure.md)。
- `clothing-color-relations.svg` / `.png`：原创抽象色块关系图。相同小亮色块置于不同背景关系，不临摹馆藏，不是服装版型、历史设计复刻或眼动/审美实验。详见 [F26](../../docs/evidence/F26-clothing-forms.md)。
- 两图的 SVG 为可编辑源，PNG 由同一源在浏览器渲染，供离线阅读页嵌入。图中文字之外，正文和替代文本保留主要含义，不依赖单独辨认颜色。原创图采用仓库 MIT 许可。

## 制作与材料原创图解

- `weave-crossings.svg` / `.png`：六乘六放大平纹结构，只说明交点上下交错；纵横颜色用于辨别方向，不是密度、线径、材料强度或边缘收尾图。不是 V&A 插图或 Sue Lawty 试样照片的复制。[F28](../../docs/evidence/F28-weaving-and-material.md) 记录教学与作者文字的不同来源。
- `zine-structure.svg` / `.png`：一张纸的八格、中部开口，以及成册后包含封面封底的八页阅读顺序。上图没有标源纸页序或文字朝向，不是拼版模板；下图不对应上图格子位置。不是完整裁切教程或尺寸图，也没有复制机构图解。[F29](../../docs/evidence/F29-zine-structure.md) 记录核读范围。
- 两图采用本仓库 MIT 许可，保留可编辑 SVG 与同源渲染 PNG。正文、图内文字和替代文本均说明边界，不依靠颜色单独传达信息。没有公开转载对应来源 PDF 或试样照片。
